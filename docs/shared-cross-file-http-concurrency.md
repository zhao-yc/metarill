## 身份及验收边界

宿主仍显式注入固定普通身份（写入997／读取998），不称为正式账号登录或Production/Web验收。独立包正式安全初始化被现有夹具限定在专属新空库；B77原四库／账号仍待授权，不能绕过其保护或复用已结束租约。本批使用既有Server-200隔离业务库的随机表和明确文件ID，只证明本行的生成HTTP事务范围，不替代B77。

## HTTP并发证明

七种模型沿用B79：四种所选ID／目标父键交叉、两种短主叶和一种固定派生目标，含软删／物理删。每模型五个父页面：国家、地区、主末端、仓库以及逻辑国家＋物理外键。每页分别执行一次正常提交和一次尾部回滚，共十个暂停事务场景。

生成DML及真实文件观察器之后、原事务提交之前，由测试观察器暂停。另一个HTTP客户端读取同一详情，必须仍返回已提交名称与原文件数组；旧文件可真实下载，未提交的新文件对不同读取身份必须401。测试线程不得看到写请求的Ambient事务，独立连接也仍只看见原提交引用。

同时在独立连接逐行NOWAIT竞争来源、实际分支目标和新文件行，精确3572；未选仓库仍可锁。真实UPDATE在持锁时等待到1205，事务释放后可实际切换状态并检查结果，再回滚该探测写入。超时只在非池化连接的当前会话设置，不修改服务器全局配置，不读取其他库的锁元信息。

释放暂停点后，成功请求必须提交新名称和文件引用，保护内容随之可读；尾部异常必须返回准确错误标记，全部自有来源／目标、文件及含墓碑引用快照完全恢复。两条路径均核验锁释放。提交用例通过一个真实可读副本保留旧文件引用后再恢复，不借上传者身份重新绑定历史孤儿文件，不改变原文件授权规则。
