# 跨表级联保存与辅助物理列

原国家→地区→城市等 crossTable 控件继续使用原页面、组件、布局、样式和实体 JSON。C# 生成器现为已证明的固定普通冗余目标链补齐各级 ID/名称保存；完整应用的其它用途仍有门禁，不据此宣布完整控件或 MySQL 首版完成。

## 结构来源与显式同步

Core 的 CrossTableStorageColumns 与既有 CascadeTreeStorageColumns 共用存储计划。全局 crossTable 定义中安全且不重复的 columnPrefix 派生缺失的各级 _id/_name，末级必须对应来源 _id；页面覆盖不能改变表结构。生成器、结构预览及基础存储使用同一规则，不写 config_column、不补页面字段、不执行启动或生成 DDL。

派生 ID 使用保留的稳定命名空间，用户不能自行声明。ID 沿来源叶子逻辑类型 string/int64；名称是可空字符串，继承字符串来源长度，整数或未指定长度使用50，无业务默认值。显式列优先保留，包括类型错误和虚拟声明；不能静默覆盖，不能证明时仍拒绝跨表写入。

旧应用须同版更新 Core/Data 和生成器，先预览并确认结构差异，再显式执行与核验，最后再生成和构建。实库旧表升级只增加缺失的可空列，旧行保留、名称为NULL；不自动回填历史名称。前端和原操作流程无需修改。

## 原保存语义

生成模型只在本页原叶子可读/可写时把全部隐式级 ID 加入对应 VO/DTO，名称只读；不增加列表或详情布局，不扩张其它隐藏字段。原完整实体回传允许只读名称 echo，但名称不被作为可信值写入。

新增、复制、默认值/BeforeSave 钩子之后，以及相关字段参与更新时，从合并后实体的最深非空 ID 反查完整当前路径，服务器重写祖先 ID 与名称，清空后续各级。只选根或中间级可保存。省略字段保留已合并旧值，显式 null/空字符串清除相应字段；若仍有更深旧 ID，则仍由最深值决定路径，原组件沿原行为显式清空后段。只有无关字段更新时不刷新旧受管名称，目标改名后显式重选才刷新；全局名称传播仍待完成。

ID 必须是精确的规范正整数，响应仍是字符串。用户伪造的祖先 ID/名称不能覆盖服务器路径。清空整条选择不要求目标 list；非空选择检查实际读取的各级目标 list、真实 Actor、项目、软删除和固定条件，不额外要求尚未访问的后续级权限。原来源动作权限保持，客户端不能选择内部 Import 标志。

## 同一事务的最终检查

各级目标以当前读 ForUpdate 获取，锁保持到正常事务结束；父上下文由同一固定链唯一推导。归一化后再次验证项目与页面父归属，钩子或路径不能改变来源范围。仅执行原 Mapper 的正常一次 INSERT/UPDATE，然后在通知前读取实际存储的受管字段与身份范围并逐项核对，数据库截断或触发器改写即整笔回滚，不追加修复 DML。

目标不存在、隐藏或跨项目祖先、撤权、错误父上下文、钩子越界和通知后段故障均不留下部分数据。真实独立连接 UPDATE 遇到1205，原事务完成后同一修改可成功；无需 PROCESS 或 performance_schema 观测授权。

短名称负例仅在自有 INSERT 的会话内临时关闭严格模式，并在同连接 CommandAfter 立即恢复；最终存储核验拒绝截断、通知前回滚，独立新连接复核会话及全局 sql_mode 前后相同，不修改全局设置。
