# V266 原单 VO 读取投影实库验收

2026-11-05 在 Server-200 MySQL 8.4.11 执行，固定 5d0811f6ed9be3483ce2e731a57eb57f5996ef27，正式轮次 8a72571ef8026b98。独立检出严格构建，核对 2,566 份源码和 156 份输出。测试显式预览并创建一张合成表，种入四条含 16 KiB 隐藏文本的记录，启动本机回环上的真实生成 ASP.NET Core 控制器，用固定普通身份执行接口。

| 入口 | 实际 SQL 及响应 |
|---|---|
| 原列表第二页 | 活动本项目行总数为 2，页长 1；捕获独立 COUNT 与分页 SELECT，确认 LIMIT 1,1。 |
| 原详情 | 同一行的 JSON 与列表行逐字相同，保留超过 JavaScript 安全整数的字符串 ID 和原详情备注。 |
| 原多选已选回读 | 按传入 ID 顺序返回，两组混入外项目或软删记录的请求均整组拒绝。 |

上述五个请求捕获六条实际数据库语句。数据 SELECT 仅取 id、name、remark，隐藏长字段、项目列和软删列未返回到投影，项目和软删条件仍由数据库执行。测试使用固定授权器验证生成控制器与数据库之间的范围和响应。完整登录、其他角色、浏览器和同条件性能继续按各自项目验收。

初轮 dd2393439eed6643 在 MySQL 建表预览阶段因旧离线夹具使用 id 类型别名停止。修正夹具为 int64，并加入对同一夹具的离线 MySQL 结构编译测试。固定复验的离线结果为 8 通过、1 实库条件跳过，正式实库 1 通过、0 失败、0 跳过。两轮均以新 SSH 和独立 MySQL 连接核验独占库、账号和所有权记录清除，本机临时凭据和工程已回收。

此轮仅补齐 [B97](../published-read-projection.md) 的原单 VO 实库证据。按用途分离 VO、非冗余及统计等其他计划，以及代表性同条件性能仍按 V09／V08 跟踪。
