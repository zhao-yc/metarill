## 固定图与查询范围

筛选只解释ID，名称仅回显；重复字段、未开放键、SQL文本和非节点对象拒绝。精确匹配或包含后代来自冻结元数据及原页级覆盖，客户端不能改模式。空对象表示无筛选，不变成空集合或树根。

精确匹配校验完整可读路径后只匹配该ID；后代按200个父键分批、1000条主键游标读取，包含选中节点，无候选500项截断。每条语句只投影固定id/name/parent，保持目标项目、软删及页面固定条件。坏根、循环、断链、游标错误及超过64层整体拒绝，不能返回部分后代。

列表、数量、统计、导出行范围和独立选择页共用异步Query，不落到字符串LIKE。普通页保留原同步Query输出。导出此批验证的是同一筛选行范围，级联Excel单元格的完整路径格式与名称导入仍未完成。

路径展示按页收集ID并批量缓存共享祖先，缓存只在本次调用内使用。不存在、已删、跨项目、页条件排除或坏链显示空路径，保留原ID；不返回部分祖先，也不把身份/SQL/取消错误吞掉。显示别名与真实字段重名时生成前拒绝；别名只作响应/原完整表单回显，不进入严格写DTO。

来源已授权的列表、详情、选择及筛选按声明字段执行固定目标范围，不额外要求目标list动作；候选浏览与独立路径接口保留原先已接线的两页list校验，非空关系写入仍沿目标list校验。没有动态目标、SQL或客户端项目授权入口。

## 同一读取快照

MySQL适配器显式开启RR，分批图、来源计数/记录、路径及分页统计共用一个快照。来源动作授权先于业务读取；Controller分页与统计共享外层快照，Service单独调用也有同一机制。嵌套业务事务先经适配器验证，弱隔离明确拒绝并标记外层仅回滚，不改变业务事务隔离级别。其他数据库未提供该适配能力时明确拒绝，不能静默降级。

原新增/修改/复制的响应另用当前读装饰路径，保持已验证的新名称，不回到准备阶段的RR旧快照。普通写事务的默认隔离规则保持。
