# V264 原 YZP 与 Metarill 上传类型面板布局对照

2026-11-05，Metarill 使用 V262／V263 固定 H5 产物（产品 6835be6），原 YZP 使用本机已有 HBuilderX Web 产物。两份产物分别通过独占回环地址提供，只读加载，不使用后端 API。ego lite 在实际页面中调用两份构建产物导出的 uni-app 原 showActionSheet。四档窄屏均通过实际点击收到“文件”选项的 tapIndex 1。

| 视口或阶段 | 原 YZP 与 Metarill 的相同测量结果 |
|---|---|
| 稳定 320×844 | 面板左右边界 6～314 CSS 像素 |
| 稳定 390×844 | 面板左右边界 6～384 CSS 像素 |
| 稳定 430×844 | 面板左右边界 6～424 CSS 像素 |
| 稳定 499×844 | 面板左右边界 6～493 CSS 像素 |
| 桌面 1000×844 | 面板居中，左右边界 350～650 CSS 像素 |
| 面板打开时从 1000 切到 390 | 窄屏规则已生效，切换瞬间 transform 仍含横向 -189 像素位移，左右边界 -183～195 CSS 像素 |
| 390 视口过渡结束 | transform 归零，面板及“文件”选项左右边界恢复至 6～384 CSS 像素，实际点击正常 |

两端的边界、transform、媒体查询、视觉视口宽度与偏移逐值一致。两份构建中的 16 条 uni-actionsheet 样式规则也逐字一致。V263 记录的 -183～195 像素在原 YZP 同样可复现，属于打开面板后切换视口时的原组件过渡。稳定窄屏中未出现同样裁切。按原界面保真要求，本轮仅登记证据，复验脚本在切换视口时应等待过渡完成。

浏览器验收空间已关闭，两个回环端口已独立核验释放。原始测量保存在项目私有目录，SHA-256 为 DD2FD846D68961940119F6A1DDFCCECC0114DBFE78EFD57AB3AD0F713FE22C7C。此轮只覆盖 H5 上传类型面板，V263 单列业务附件链，真机、其他角色与文件组合仍由各自项目跟踪。
