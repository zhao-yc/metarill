# 当前候选 Caddy HTTPS 与原桌面 Web 验收

日期 2026-11-08。产品基线 `5c8fcb823491e2e25029ffa40cb2cfdc851c0abb`。复用 [V627](current-caddy-release-v627.md) 的 210 份固定发布物。在 Server-200 用独占 Caddy 2.11.8／Compose 5.5.0 提供同源 HTTPS，后端仍为原 Linux Production 宿主，数据源为本轮平台和业务双库。

| 环节 | 已验证 |
| --- | --- |
| 证书及网关 | Caddy 提供本轮短期测试叶证书。严格客户端以正确主机名协商 TLS 1.3，服务端叶证书摘要匹配，默认信任及错误主机名均拒绝。命令行复验了原首页、静态资源、API 404 和私有配置边界。 |
| 原桌面浏览器 | 从专属 SSH 回环转发直连 Caddy。空白 Chrome 配置返回证书颁发者无效。独立信任配置以 1280×840 完成原表单登录、设备和项目选择、原菜单及确认退出。文档与 7 个同源 API 回执均为浏览器已校验的 TLS 1.3。 |
| 原 API 与数据库 | 命令行执行 12 个真实原请求，含登录失败、菜单、生成客户 CRUD、重启后原会话及注销。独立 SQL 核对两个失败来源和最后成功 IP，伪造的转发头没有入审计。合成客户已更新并逻辑删除。 |
| 三个会话与清理 | 两个命令行会话与一个真实浏览器会话均在 MySQL 读回为已注销。新连接核对网关和后台容器、TCP／UDP 端口、临时目录、双库、账号、所有权、Redis 及两条本机转发均已清理。 |

短期叶证书只预置于本轮独立 Chrome 配置，未关闭证书校验。两个临时浏览器配置、本机私钥工作副本及浏览器凭据已清理，四个系统及用户证书库均无本轮指纹。短期验收凭据和证书按项目另行私有归档。

本次为独占环境的实际 Caddy、桌面 Web 与原 API。实际部署域名及公开证书链、网关后的移动 Web 和独立 Full 浏览器业务仍按首版清单验收。
