## 逻辑路径与物理存储分开

R0来源继续只在最深所选层的ID位保存一个ID，各级相同数字ID按所在位区分。固定读取从末层向根联接，每层只联接一次，恢复逻辑祖先ID及当前名称；同一SQL表达式用于筛选、排序、分页前COUNT、SUM与有界导出。两棵独立跨表控件可各存一个选择，同时与普通List关联显示共存，不能把整张表误限为一个非空关系ID。

名称和祖先必须来自同项目、未删除且满足固定目标页条件的完整路径。目标缺失／软删／其它项目／父链损坏／固定条件不符时，保留来源行及本身所选ID，隐藏无法证明的祖先和名称。原父键前导零可规范回读；无效或越界父键不宽松转换成有效ID。逻辑字符串ID显式采用utf8mb4_bin精确比较，驱动值不经过浮点。

隐藏原始ID位只供存储核验，投影后移除，不扩大公开输出。多位同时有值、非规范／越界来源ID在COUNT、明细和统计中明确拒绝，不读取时修补，不隐藏错误行冒充成功。

## 固定目标范围

新增显式`CompileWithCrossTables`，旧`Compile`五参数方法签名、默认参数与无绑定门禁保持；已由现有Release程序集反射核对。绑定复制目标页层序，条件为不可变的类型化常量计划；校验目标页归属、真实物理字段、类型、项目／父键与额外查询声明。完整元数据中已声明的目标条件不能被遗漏或替换；值参数绑定，不能作为可执行SQL插入。生成调用者以后须从实际固定目标页建立绑定，不从HTTP请求取页面、连接、列名或SQL。

该数据层入口不建立身份或授予目标动作权限。原动作／来源页权限仍由上层真实Web或MCP身份与生成Service负责。全局／非冗余目标、派生名称、未知父上下文、嵌套级联联接、精确匹配及维护回填等未证明用途保持门禁；此次没有扩大公开生成支持声明。
