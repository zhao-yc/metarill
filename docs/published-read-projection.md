# B97：兼容原单 VO 的普通页 SQL 列投影

## 范围与实现

2026-10-28，基于 `0ee9d59` 开发。`PublishedReadProjectionCompilation` 只为既有普通强类型读取编译固定列集合，接入列表分页／不分页、详情及 type=2 已选确认。没有更换前端、路由、请求或响应结构，也没有接入按用途分离 VO 的 `ReadProjectionCompilation`。

物理读取集合为原 `page.Readable` 与主键，加上原 VO 的多值隐式名称、自树隐式叶名及跨表展示依赖的各层已存名称，按稳定字段 ID 去重排序、主键优先。跨表名称即使未直接出现在 VO，也可能参与已有 `DisplayText`，因此不能删掉；它不会因此新增响应属性。账号表继续使用原 `ManagerCredentialCompilation.ReadProjection`，不扩大凭据读取。

筛选、排序、软删除、项目和父级范围仍由原 Query／Scope 处理，不因未 materialize 某列而移除 WHERE／ORDER BY。统计、分页参数、选择顺序、200 项上限及失效项整体拒绝规则不变。列表依然返回原并集 VO，详情专用字段没有从列表响应中消失。

带派生关系的非冗余表继续走原固定读取计划；该辅助编译器明确拒绝替代这条路径。更新、删除、复制仍在原事务中 `ForUpdate().FirstAsync` 读取完整实体，钩子、观察器与写响应不使用窄实体替代。普通候选和维护锁读已有各自投影，本次不改。
