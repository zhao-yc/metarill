# V870 公开 Full 的中层及末层父范围 Excel

2026-11-10。公开 Full 扩展至 V869 已验收的中层和末层父范围。范围为 MySQL、普通非冗余来源、单条三层链、字符串 ID、独立物理候选及该链上的唯一逻辑父字段。支持追加和列表路径导出。按首列覆盖、详情导出、物理父范围和混合路径继续按原门槛。

| 核对项 | 实测结果 |
| --- | --- |
| 公开生成与原界面 | 701 个包文件两次生成逐字一致，与内部准备包对照的 23 份原 Vue、Controller 和 Service 逐字相同。公开能力清单显示中层可导入路径、末层只导出路径。28 项定向回归通过，零失败、零跳过。 |
| 中层真实路径 | 普通账号可追加完整路径、部分路径和空级联。空级联使用当前中层父 ID。根级短路径、伪造父字段和跨父路径分别被拒绝，跨父第二行失败后合法首行也回滚。 |
| 末层原导入列 | 末层 ID 从请求绑定。原模板接收名称和金额，固定的级联列仍不在导入表头。第二行试图提交该列时返回 400，首行随批次回滚。 |
| XLSX 与独立读回 | 两个父范围各导出两份实际 XLSX，选择列表同时含两侧 ID，每份文件仍只含本父范围记录。原 SheetJS 解析四份工作簿，中层回导四行，末层按原可写列回导两行。21 个原 HTTP 含 4 个预期拒绝，独立 MySQL 核对最终 12 行及稀疏层位。 |
| 安装与回收 | 69 份固定 Release 宿主。空库预览 16 项，预览后仍为零表，显式安装后差异为零。测试库、账号、所有权、Redis、转发、临时配置和存储均独立核清。 |

V869 的内部准备包证据见 [中层和末层实库验收](middle-leaf-parent-cross-excel-v869.md)。本轮完成公开生成及实际 HTTP／XLSX 复验。新开发提交全量 CI、正式浏览器和首版总验收仍按对应清单跟踪。
