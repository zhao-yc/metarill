# 当前候选的 S3 文件归属、回滚与重启验收

日期 2026-11-08。产品基线 `5c8fcb823491e2e25029ffa40cb2cfdc851c0abb`。复用 [V620](current-platform-files-v619-v620.md) 的合成客户元数据及 51 个完全相同的 Production 宿主文件。MySQL、Redis 和 S3 兼容容器均为 Server-200 的独占测试资源。

## 数据、权限和对象

| 核对 | 证据 |
| --- | --- |
| 原生成接口 | 三个普通角色分别拥有全部页面权限、只读权限和空权限，另有平台所有者。原 multipart 上传计划指定 S3 存储，保留服务端代理。公开附件凭正确的已发布项目提示可匿名下载，受保护附件需要实际来源页面和记录读取权限。 |
| 项目与数据 | 平台分库中的客户和文件引用都在业务库。共库场景使用实际同一个物理库，未发布项目配置指向独占空库。空库保持零表且公开请求被拒绝。 |
| 失败回滚 | 同一保存既修改备注又绑定未上传文件时拒绝。独立 SQL 验证备注、原文件引用和存储键逐值一致。独立 SDK 在回滚前后列出相同的两个对象，逐个读取并核对长度和 SHA-256。 |
| 删除 | 在业务记录仍引用附件时禁止删除。删除客户后，引用失效并拒绝原只读下载。应用删除文件后，独立 SDK 确认桶内 0 对象，再删除空桶并用新客户端确认桶不存在。 |

## 本轮结果

| 验收编号 | 组合 | 真实业务请求 | 独立 S3 探针 |
| --- | --- | ---: | ---: |
| V621 | 平台库与业务库分离 | 37 | 9 |
| V622 | 平台库与业务库共用，Production 宿主在原地址重启 | 39 | 9 |

V622 在重启后沿用原写者和只读会话，重新核对只读权限与原客户详情。四个真实 Web 会话在两轮各自退出，数据库读回全部失效。拒绝仍使用原 HTTP 200／R500 协议。

探针复用候选宿主的 AWS SDK。严格构建零警告、零错误，精确库存比较的 8 项门禁通过。两轮分别核零 MySQL 双库、账号和所有权记录、Redis 容器与配置、S3 容器与配置、回环转发以及本机运行时存储和私有设置。S3 兼容服务固定为本轮独占 SeaweedFS 容器。当前证据覆盖服务端 HTTP 与对象层，浏览器和实际供应商部署继续使用各自验收项。
