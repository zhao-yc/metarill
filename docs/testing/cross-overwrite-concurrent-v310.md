# V310 公开 Full 跨表覆盖导入并发验收

2026-11-06，Server-200，固定 082070c 和本次夹具。正规公开 Full 包从自身源码构建，共 44 张表。冻结 2,601 份来源、156 份测试输出和 1,279 份包文件。Release 严格构建零警告、零错误，22 项包准备及隔离门禁通过。

同一个普通账号通过原登录表单建立两个不同的真实会话。第三个连接先锁住已匹配的来源主键。两个会话同时提交原覆盖导入请求，一个提交名称，另一个在首行写入附件后由手写规则拒绝第二行。

| 验证 | 实际结果 |
| --- | --- |
| 锁读位置 | 六个模型均观测到一个连接停在来源匹配的排他锁读，另一个停在根级候选的排他锁读。临时账号仅观察自己的连接，回执只保留计数 |
| 提交与回滚 | 释放测试锁后，一个请求成功，另一个按预期拒绝。同一主键保留成功名称、原稀疏存储和原附件值。独立连接核对其他业务行和文件表的摘要一致 |
| 事务内观察 | 每个模型的单批及并发场景各观察到真实首行 DML 和一条同事务文件引用，合计 12 条回执。随后继续验证成功上传引用、原工作簿、撤权和重启 |
