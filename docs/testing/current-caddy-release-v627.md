# 当前 Linux 候选的 Caddy 同源部署验收

日期 2026-11-08。固定产品 `5c8fcb823491e2e25029ffa40cb2cfdc851c0abb`。在 Server-200 用 Docker Compose 5.5.0 启动独占 Caddy 2.11.8 与 Linux Production 宿主。远端逐份核对 49 个宿主文件、156 个原 H5 产物和 5 个布局与元数据文件。MySQL 平台和业务库、Redis 及网关资源均为本轮独占。

| 核对 | 实测结果 |
| --- | --- |
| 真实 Caddy 路由 | Compose 配置验证通过。内核监听表确认网关和后端都只监听指定回环地址。原首页及实际 JavaScript 资源的 HTTP 回包与发布摘要一致，未知 `/api` 请求保持 404。请求私有设置同名路径只得到静态首页。 |
| 原登录与可信地址 | 12 个业务请求的 HTTP 与原 R 包装均符合预期。使用三个回环源地址，伪造的转发头没有进入登录审计。独立 SQL 核对两个失败来源分别为 `127.0.0.2`、`127.0.0.3`，最后成功来源为 `127.0.0.4`。 |
| 原菜单与生成业务 | 经同一个网关读取原菜单，使用生成接口新增、更新及删除合成客户，字符串 ID 精度保持。独立业务库读回已更新和逻辑删除。 |
| 重启与注销 | 保持网关地址重启后端。原会话可读回更新后的客户，两个会话分别退出，旧会话被拒绝。独立 SQL 核对两个 Web 会话均失效。 |

首轮夹具在初始化退出。其私有设置由 root 持有，而候选镜像以 UID 10001 运行。复验改为让该账号只读私有配置，发布物只读，另挂本轮可写运行目录与临时目录，固定产品与 H5 字节一致。首轮独立核零后使用新资源复验。最终网关、后端、初始化容器位置、私有目录、双库、账号和本机转发均核清。首次 Redis 独立读回未返回结果，使用同一轮资源从新 SSH 补查后容器、目录和端口均核零。

本轮验证了真实同源 Caddy 和平台 Linux 发布物。回环 HTTP、独占合成资源及命令行请求是本轮范围，实际部署域名、证书和网关后的浏览器分别验收。
