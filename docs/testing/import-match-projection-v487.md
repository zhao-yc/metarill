## 查询变化

| 查询 | 生成的读取范围 |
| --- | --- |
| 关联候选反查 | 仅取目标 `id`。原名称、ID、附加条件和父范围筛选保持，仍最多取两条以判断不存在或重名。 |
| 物理首列覆盖匹配 | `FOR UPDATE` 最多两条，仅取主键和省略输入所需的旧联动字段。当前项目和已校验父键继续用于范围校验，由原服务端上下文提供。 |
| 非冗余跨表覆盖匹配 | 保留原逻辑当前读、固定联接、匹配条件及解析上下文。命中后的物理锁定与范围复核仅取 `id`。 |

标准更新仍读取完整实体。覆盖导入对省略字段、显式清空、重名拒绝和批次回滚继续沿用原处理。
