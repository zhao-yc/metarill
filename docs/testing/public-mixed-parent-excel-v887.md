# V887 公开 Full 的混合关系键父级 Excel

2026-11-10。以 30f99b75 加本次生成门禁为固定源码。MySQL 公开 Full 支持普通非冗余来源的单条三级级联，在来源表三层关系字段混用字符串和 bigint 时，仍可按同一条链内的逻辑父范围执行原 Excel 功能。六种混合排列均纳入。候选表使用原独立物理目标，层间外键沿用 bigint。

| 核对项 | 实测结果 |
| --- | --- |
| 生成与显式安装 | 72 项生成回归全部通过，其中新增 36 项覆盖六种排列、三个父级及追加／列表、覆盖／详情。公开 Full 两次生成的 959 份文件逐字一致，69 份 Production 宿主文件严格编译。独占空库预览、显式安装、安全初始化及重复预览零差异均通过。 |
| 原导入、导出与权限 | 同包六种排列各执行原三级追加、按物理文本首列覆盖、列表及详情 XLSX。两父范围同名记录各自命中，覆盖保留主键，跨父混选不进入工作簿。独立读 XML 后由原 SheetJS 再读。分页对各层均返回原字符串 ID，与 MySQL 读回逐值一致。普通仅查询角色在 36 个业务页查询成功，导出返回 403，零票据、零新增文件。 |
| 事务 | 根和中层跨父、末层私带固定级联列的第二行被拒绝。六种排列共 36 批返回 HTTP 400，独立读回首行新增或覆盖已全部撤销。 |
| 稀疏部分路径 | 六种排列逐一写入仅根、仅中、固定末级。18 个对应物理槽只写所选层，其他列保持 NULL，来源无名称缓存。覆盖保留原主键，省略路径时原值保留。分页恢复逻辑祖先，原 XLSX 保留补空层及完整路径。 |
| 独立复算与回收 | 两轮完整验收合计 360 次真实 HTTP、54 份真实 XLSX，临时库、账号、所有权、Redis、转发、私有运行配置和合成存储均独立核清。 |

部分路径的首次运行在第六种排列重新登录时触发 HTTP 429。该轮已清理并从完整验收统计排除。复验使用编辑和只读角色各一个原会话，两种会话最终均注销。

已有混合关系字段的元数据可按原流程再生成相应页面和后端。此变更没有新增 DDL，覆盖正式 HTTP 和 XLSX。MySQL 首版同条件性能继续按既定门槛验收。
