# V420 同父明细导入的结构查询对照

2026-11-06，使用 00a75339 的生成宿主和 Server-200 隔离 MySQL。原实现先固定表定义，再在同一驱动命令分别查询表引擎和列定义。候选在相同表锁下将这两条元数据查询合并为 LEFT JOIN。两种写法每张表均只发送一次驱动命令。

五种结构对照一致，覆盖原父表和明细、非 InnoDB 引擎、不存在的表、复合主键与计算列。每种写法各测 100 次，交错顺序并排除预热。原查询的中位数和 p95 分别为 9.50 和 20.91 毫秒，合并后为 9.06 和 22.04 毫秒。中位数仅下降 0.45 毫秒，尾延迟增加 1.13 毫秒，因此保留现有产品查询。
