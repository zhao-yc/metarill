# 跨表级联候选与路径读取

原跨表级联（例如国家→地区→城市）已有逐级选项和叶子路径接口。Metarill现在按固定模型接通这两个读入口，保留原uni-app组件、页面、布局、样式、事件、路由及正文；已证明固定链的保存及辅助物理列现按[写入合同](cross-table-cascade-write-contract.md)接通；固定已存名称展示按[展示合同](cross-table-cascade-display-contract.md)接通，筛选与导入导出仍继续接线，不据此宣布完整控件或MySQL首版完成。

## 原协议与固定计划

仍使用POST cascadeTreeOptions字段ID，正文为levelKey和selectedPath，各级ID键来自columnPrefix的驼峰形式。省略/null的selectedPath按原Controller转换为空对象，缺少当前层所需父ID时返回空数组，但仍检查当前层权限。候选是原id/name/value/text四字段完整数组，不添加自关联专用hasChildren，不截断宽层；实际验证5502项包含末尾ID。

路径仍使用POST cascadeTreePath字段ID与leafId。响应path中的每层保留id/name/levelKey，displayText按配置分隔符连接非空名称；SQL NULL名称沿原Map行为输出空字符串。空叶子返回空路径但执行全部涉及页面的授权。高位数字ID精确解析为int64，响应仍为字符串，不经浮点转换。

编译器冻结每层的普通冗余实体、唯一且无目标父参数的可读页、名称/父列及稳定排序。主键当前为id，名称为物理字符串，非首层父键为字符串或int64且声明关联上一层。层标识可含中文及连字符；字段前缀使用安全标识符并防止重复和JSON键冲突，末级前缀必须与来源叶子一致。页级覆盖仅影响本页，不借其它页或不明范围回退。

每个SQL仅投影ID/名称及必要父键，套用真实Actor、项目、软删除及元数据常量条件；目标list权限按当前级和实际祖先检查，根选项不要求尚未读取的后续级权限。来源页仍独立要求list。客户端不能提供表名、项目、SQL、排序或私有授权参数。未知/重复选中键、不一致祖先、缺失/越权/隐藏/已删除祖先整体拒绝，不返回部分路径。

表链是配置中的有限层级，不借自关联树的递归深度或500项候选限制；80层有限链与长分隔符已验证。自关联的既有兼容限制本批未改动。

## 快照与写入口演进

候选父链与路径逐级读取共享Data适配器的显式RR快照。实库在叶子读取后由独立连接迁移中层：当前请求保持旧路径，下次请求读取新路径，未依赖RAM模拟或健康检查。

审查并通过实库反例确认，原未接线写入仅检查叶子，单独提交countryId会返回200并实际写入一行。前序版本对有效跨表定义的全部已声明非系统级ID/名称生成统一拒绝守卫，覆盖新增、相关字段更新和复制；字段仍为空或无关字段更新保持原流程。该批临时守卫阻止开发阶段的部分写入，当时不代表跨表保存已实现。后续写入合同已在证明范围内以实际归一化替代守卫，未证明的组合继续拒绝；下述守卫验证数为前序冻结批次。根、中层、叶子、伪造名称及已有部分选择复制均拒绝且状态不变；无关更新可用。

原反例返回、独立持久化证据、失败TRX和清理收据保留，自有随机表已清理并另起连接核零。没有回写生产、旧YZP或未知对象，没有新增数据库观测授权。

## 更新与剩余范围

已有C#应用配套更新Core/Data基础源码和生成器，再生成相关Service、Controller及注册类并构建，保持现有IRuntimeAuthorization宿主接线，保护手写partial，不混用单个DLL。读取批次不新增业务DDL、回填或前端操作；后续自动物理列按写入合同预览并显式同步，不能跳过结构核验。

当前实库为三个独立普通目标的固定链；其它目标父范围、非冗余、同表读写合并、其它读取用途和全部原页面交互继续验收。固定独立目标链的自动辅助列扩展、各级保存归一化与部分选择已按写入合同补齐；其它写入组合、未证明的展示组合、筛选、Excel及全局名称传播尚未完成。完整管理Runtime A、初始化确认、原浏览器/真机、同条件Java/C#性能、MySQL完整首版和其它数据库待办保持，不合并main或生产部署。
