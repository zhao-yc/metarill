## 保留的原合同

- 保留原 `uni-data-checkbox`、复选／全选、列表下拉筛选、整实体回传、只读展示及页面布局；组件及样式未重写。
- 候选仍为 `findNameId{字段前缀}{字段ID}`，返回 `id/name/value/text`，ID 全程为字符串。
- 来源页查询、新增、修改的任一开放动作通过即可查询候选。目标绑定页不额外授予独立查询权限，也不把该页的其他 WhereSql 偷换成控件条件。账号角色安全表继续走专用协调器。
- 四段旧配置只用第三段条件、第四段排序；前两段不执行。兼容明确目标字面值与固定 JSON 配置，所有明确表／页声明必须一致；损坏或未证明的配置不回退宽候选。
- 原 `parentId`、对象或一层 JSON 对象文本的 `formParameters`、只读 `id` 数组保持。未传 id 查询完整有界集合，明确空 id 返回空集合；客户端不能传表名、SQL 或新查询键。
- 原全选预算为 5000 项；5001 项明确拒绝，不能用弹层多选的 200 项限制截断。实际存储仍受发布的物理列长度约束。

## 数据和事务

- 冗余模式存 ID 数组和已声明的物理名称数组；名称只在服务内派生，普通 DTO 不允许直接写缓存。未提交关系／依赖的普通更新不刷新旧名称。
- 非冗余模式只存 ID 数组，显式只读或自动名称数组通过固定读取计划实时生成；不建物理名称列，不在读取时回填。
- 新增、复制、ID／来源父／表单条件依赖变化都在来源写事务校验全部目标。校验读取真实默认值、原记录及手写钩子合并后的实体，使用实际项目、软删除范围及固定条件；锁定目标与实际来源父。未登记的手写依赖变化会拒绝。
- 完整集合一次失败则整笔／整批回滚，不保存有效的前半部分；非冗余写后名称使用当前读，普通多批补名使用同一读快照。
- 省略字段、null 与空数组保持不同。HTTP 数值长 ID 从原始 JSON 精确读取，规范化为字符串；重复、前导零、指数、小数、对象和非法数组明确拒绝。
- 原下拉按数组单成员精确相等过滤，`1` 不命中 `11`。JSON 数组文本不作为普通 LIKE 字符串处理，参数不得进入 SQL 结构。

## Excel

- 冗余复选沿原 ID JSON 数组导入导出；导入最终仍经过来源写事务的完整范围校验。
- 非冗余复选沿原名称 JSON 数组；按固定解析拓扑先处理物理表单依赖，再在来源 import 权限及同一事务内反查名称。重名、缺失、越界及尾行错误使整批回滚，不能借 create/update 或目标 list 权限。
- 非冗余名称导出在来源 export 权限和同一快照内验证所有引用仍在实际候选范围，并按数据库真实比较规则核对名字唯一回到原 ID。目标移组、删除或同名歧义时拒绝，避免名称导出再导入后静默换 ID。
- 名称反查／导出的唯一性校验当前逐项执行；5000 项候选和保存的通过不代表大批名称 Excel 性能已达发布要求，仍需同条件性能验收。
