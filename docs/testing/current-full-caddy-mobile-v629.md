# V629 独立 Full 的 Caddy HTTPS 与原移动 Web 验收

2026-11-08。固定产品 `5c8fcb823491e2e25029ffa40cb2cfdc851c0abb`。复用 V612 从两份相同的 681 文件生成包固定的 49 份 Linux 宿主，以及 V615 已验的 60 份原 H5 文件。合并后 109 份发布文件在发送前和 Server-200 解包时逐份核对 SHA-256。保持已有同源 H5 地址和原页面产物，Caddy 2.11.8／Compose 5.5.0 与后端只监听本轮回环，通过专属 SSH 回环转发接入。独立宿主从单独工作目录读取私有设置，发布目录只读。

先行轮次分别在初始化、匿名路由断言、本机转发监听校验和浏览器菜单操作处停止。复验采用与既有 Linux 验收相同的独立工作目录，补初始化子阶段、实际监听 PID 正反例和原菜单 `menu` 协议检查。最终按真实目录展开状态点击。未修改产品源码、权限规则或前端产物。

各轮独占库、账号、所有权记录、Redis、网关／后台／初始化容器、远端临时目录及端口均经新连接核清。首轮本机端口因原 Redis 转发工具的端口范围守卫未能自动检查，补用独立系统查询核清。本机专属浏览器配置、短期证书私钥工作副本和浏览器凭据均已清理。短期测试凭据按项目另行私有归档。

本轮补齐当前候选经隔离 Caddy HTTPS 的独立 Full 移动客户场景。实际发行域名、公开证书链、其它角色和复杂业务组合，以及首版总验收仍按 [MySQL 首版交付节点](../mysql-first-release-milestone.md) 核对。
