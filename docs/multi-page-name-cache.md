## 表级计划与原页面

- 生成期汇总根关系与各页已证明的多选名称缓存，按稳定列名排序。同一来源 ID 必须绑定同一目标表；同一物理缓存必须绑定同一目标字段。歧义定义在输出前拒绝，不静默选择一个页面。
- 本页仍负责原候选范围与目标页授权。候选全部通过后，同一次有界当前锁读投影所有缓存名称；按所选 ID 原顺序写缓存。即使本页只展示 ID，或整个来源表没有可见名称页，根缓存仍维护。
- C#列表字段映射按本页已证明名称／ID绑定，修正原先总读根名称的错误；原Vue列表和详情按ID／标题配置已挂载验证，原template/style及运行时资产未改。
- 每个 VO／DTO 仍按原页面决定：隐藏名称不加入输出或只读回显白名单，也不能直接提交。原弹层、页面、布局、样式及接口不变。
- 新增、更新、复制、null／空数组和登记缓存变化会同步同表缓存；无关系提交时仍保留旧副本，不借此自动回填历史数据。父范围变更仍先验证当前真实候选。
- 未登记的缓存／ID／父依赖变化拒绝；已登记名称也从候选重新派生。名称与文件引用留在来源事务中，任何后续失败整笔回滚。
