# 非冗余全局单值关系及普通联接

2026-10-31补充：B105已增加普通来源引用全局R1受管名称缓存的递归证明和完整包离线子集，见[新范围及未验收边界](global-cached-target-names.md)。本页B65物理目标正式证据保持原范围，不自动覆盖新缓存目标；全局R0实时派生仍未开放。

B65接通普通R0来源的List／SelectPage到显式全局R1物理目标，并允许普通R0中间节点的单值名称联到该共享物理终点。继续使用原选择器、原type=1弹层、页面、路由、整entity请求及中文导入导出合同；来源只保存关联ID，名称和其它已证明标量即时联查。

## 固定范围与权限

目标必须以`scopeKind=global`明确声明，表与页面明确发布到当前模型，真实目标页只接受固定条件。表、页、名称等多处声明冲突时拒绝，不通过删除项目列推断全局。允许目标保留项目列或原本没有项目列；来源与普通中间表必须继续绑定真实项目，来源父范围和目标固定条件均保留。

名称只允许非凭据物理字符串，其它输出只允许已证明的非凭据物理标量；文件、数组、JSON、二进制、派生缓存名称及全局R0目标继续拒绝。普通R0中间表的派生名称可以经自己的物理List关系到达全局物理终点，这不等于开放全局派生目标。全局字符串外键按二进制精确联接，避免相邻长整数ID隐式转换误联；普通非全局单值联接保持已有行为。

候选／已选查询要求来源和目标查询权限。普通单值保存及导入沿原来源动作权限、真实候选范围和事务校验，不增加目标查询权限门槛；真实普通账号只有来源编辑权限、没有目标查询权限时仍可提交有效单值ID。原type=1已选查询可按原规则继承来源查询权限，不能把它误当作独立目标查询拒绝场景。

隐藏、未展示的全局List默认值也必须进入同一真实候选校验；不能退回只查主键存在的通用COUNT而忽略目标状态。名称、分数等只读展示值由后端重算，整entity伪造值不能落库。平台`HttpRuntimeAuthorization`对全局目录的管理员限制没有放宽；下面普通账号证据来自独立应用真实Production/Web。
