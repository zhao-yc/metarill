# 非冗余跨表目标与固定派生名称（B53）

## 本次范围

来源表为非冗余模式（R0），crossTable各级可使用独立普通R0或冗余模式（R1）表。R0目标的名称可以是物理字符串，也可以是固定单值联接得到的字符串；固定层链可混用R0／R1。同一独立目标表可以承担不同层级角色，各级父键、条件、名称及SQL别名分别处理，来源自身重复参与仍保留门禁。

来源继续只保存实际所选层的一份ID，不落祖先名称副本。候选、当前路径、列表投影、筛选和写入校验都使用生成期证明的名称与范围；派生名称通过真实联接读取。每级项目、软删、固定条件及原页面授权继续生效，客户端提供的名称和祖先不能替代真实路径。

## 实现与原接口

生成器先验证物理父键、项目范围、固定条件、排序与单值字符串终点，再生成静态读取计划；不在请求中接收表名、字段或SQL。R0目标使用固定计划，R1目标保留已有强类型读取分支。R0当前写入读取加入原事务并持有目标与名称联接的共享锁；R1沿用原锁定分支，旧RR快照不能替代当前校验。
