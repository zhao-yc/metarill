## V450 原 HTTP 权限矩阵

| 明细页授权 | 新增 | 导入 | 导出 |
| --- | ---: | ---: | ---: |
| `is_query` | 403 | 403 | 403 |
| `is_query`、`is_new` | 200 | 403 | 403 |
| `is_query`、`is_export` | 403 | 403 | 200 |
| `is_all` | 200 | 200 | 200 |

- 四个账号用乙父键读取甲明细均得到原 HTTP 200／`R500` 和空数据。可新增角色提交与路由父键冲突的字段时得到 HTTP 400。
