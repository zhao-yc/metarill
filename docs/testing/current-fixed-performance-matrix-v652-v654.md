# V652–V654 当前候选 MySQL 固定性能矩阵

2026-11-08。C# 候选源码 `31cf5321`，三表基准镜像 `26b11b9ac071`。按原固定负载使用对应 Java 镜像，同父明细为 `e348fd6ca98f`，其余八类为 `ecd22231140f`。Server-200 MySQL 8.4.11，两端各 10,752 行同值种子、1 核和 1 GiB。两端按各场景核对共同索引。计时期间关闭逐语句 SQL 观察。
