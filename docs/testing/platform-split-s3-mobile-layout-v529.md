## 空附件按钮裁切

同一实际分库页面的空 `PUBLIC` 字段中，390 像素视口下按钮右边界为 410。可用表单行到 375 像素结束，内容区却因 `min-width: auto` 扩张到 421。临时仅给该表单内容区设置 `min-width: 0`，按钮右边界回到 364，按钮宽仍为 76。测量后恢复了原样式并验证坐标回到原值。

用实际 DOM 和同一组页面样式离线复放，再替换为原 YZP 构建的 uni-app 基础样式、全局样式、表单和附件控件样式。两组测量逐值一致，并复现实际 390 像素页面的按钮坐标。简化 DOM 的早期测量未复现裁切，以实际 DOM 复放为准。

| 视口宽度 | 两套构建样式的原按钮右边界 | 临时修正后的右边界 |
| --- | ---: | ---: |
| 320 | 410 | 294 |
| 390 | 410 | 364 |
| 430 | 410 | 404 |
| 1000 | 974 | 974 |

单位为 CSS 像素。1000 像素行是同一 DOM 的宽视口对照。产品样式等用户确认后调整。独立应用的移动 S3、实际移动设备、其余文件类型及整体发布门槛按 [项目进度](../project-progress.md) 跟踪。
