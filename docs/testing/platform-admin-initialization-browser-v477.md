# V477 原后台账号初始化的分库浏览器验收

2026-11-07。固定开发基线 `0a0f2444`，使用 Server-200 独占双库和隔离 Redis。平台与生成的独立业务应用分别运行在两个 Production 宿主。使用 HBuilderX 5.34.2026102909 从原 Web 工程导出平台 156 个文件、独立业务 52 个文件，两套后端各固定 69 个文件。私有构建副本只配置本轮 API 地址和业务构建 AppID。

HBuilderX CLI 使用 `open --path <独占工程绝对路径>`、`publish web --project <独占工程绝对路径> --webTitle <验收标题>`、`close --path <独占工程绝对路径>`。两个工程均核对 `导出Web成功` 日志和实际 `index.html`。ego-browser 在 1366×900 桌面 Web 视口使用原表单及按钮。
