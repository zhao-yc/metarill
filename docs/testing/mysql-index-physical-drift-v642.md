# V642 MySQL 同名索引物理差异验收

2026-11-08，以开发分支 `ff1a3858` 为修复前基线。普通结构同步原先比较索引的名称、字段顺序、方向和唯一性。同名的前缀索引、不可见索引或全文索引可以具有相同的这些值，导致预览误报零差异。

适配层用 `SHOW INDEX` 读取物理类型、字段前缀和可见性，继续按序号恢复复合索引顺序。普通逻辑索引要求可见的完整列 BTREE。同名物理定义不等价时沿用原索引冲突提示，预览不生成替换计划。未声明索引保留。原反查 JSON 及物理 DDL 快照指纹保持原合同。 [MySQL 索引目录字段](https://dev.mysql.com/doc/refman/8.4/en/show-index.html)

## 实际结果

| Server-200 MySQL 8.4.11 夹具 | 修复前 | 修复后 |
| --- | --- | --- |
| 同名 BTREE，`name(10)` 前缀 | 误报零差异 | 拒绝，要求独立迁移方案 |
| 同名完整列 BTREE，`INVISIBLE` | 误报零差异 | 拒绝，要求独立迁移方案 |
| 同名 `FULLTEXT` | 误报零差异 | 拒绝，要求独立迁移方案 |
| 普通可见 BTREE | 预览零差异 | 建表及新增索引各执行一条，复查零差异 |

两版探针仅替换 Data 程序集，连接同一轮四张合成表。独立查询 MySQL 目录核对索引属性，三张差异表的快照指纹前后相同。去掉相应元数据声明时，两版均保留已有物理索引并返回零差异。独占库、临时账号和所有权记录已由新连接独立核零。

Data 回归 1,602 通过、32 项按配置跳过、0 失败。新增四项回归在该计数中，覆盖三类差异与旧版结果集省略可见性列。平台、CLI 和独立 Full 宿主严格 Release 编译均为零警告、零错误。独立 Full 的 659 份文件与 V638 对照，只有三份 Data 运行时源码和包清单有变化。

已有独立项目通过受管运行时同步取得修复。已有不等价的索引由管理员审核后单独迁移。本次实库覆盖 MySQL 8.4.11。旧版只验证了模拟协议，最终 CI、更新后的完整发行包以及首版整体签收另行验收。
