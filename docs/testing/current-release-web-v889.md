桌面管理端首段脚本在表格可见性断言停止。随后在同一浏览器空间确认分页返回 HTTP 200、表格已显示并有 56 个操作链接，再用单个可见操作链接接续验收。未重放首次登录或表格导航。

桌面与移动编辑各有一次新增、更新和删除成功请求。独立 MySQL 读回核对两个普通角色、只读样本保持、两条更新后的软删记录，以及平台两次和独立 Full 四次原退出后零活动会话。六张截图的尺寸和 SHA-256 已逐份核对。Server-200 上四个独占库、临时账号、容器、网络和配置已精确回收并独立核验；本机转发、交接凭据及仅本轮的两个浏览器站点数据也已清理，浏览器空间已独立确认关闭。
