## 平台授权与目标事务

平台入口只接受实际平台Web管理员，原按钮授权、当前工作区、后台与项目归属均在源事务锁后重新核对；Agent身份、平台自身、Java模板及保留YZP项目拒绝。源端授权对象只由协调器签发，调用方不能构造或取得配置口令；原事务退出或重复消费即失效。写前、目标提交前重读源身份/当前目录/配置，源会话到期或权限变化阻止目标提交。

目标仅来自TargetDatabaseSessions服务端登记；业务数据库选项不从请求读取。MySQL适配器在实际事务读取服务器UUID、DATABASE()及大小写设置，检查预期库名。不同连接别名实际共库时，身份探测事务只有SELECT并先退出，随后复用源事务，避免两连接争抢源锁。异库只在独立目标事务正常返回后记录提交证明；目标提交失败不可改成成功。已证明目标独立提交而源只读锁清理失败时记录固定提示并返回真实成功，不声称目标回滚。共库源提交失败仍整笔回滚。

目标项目/后台归属不存在时，只补本范围的最小归属行，不复制明文初始化口令；墓碑、跨项目归属及同名冲突拒绝。角色、账号与会话加入同一目标事务，无DDL、无自动建表、无分布式事务。目标库须先通过结构预览和显式同步建立安全/Agent基础表。

## 尚待确认的Agent规则

仅撤Web会话不能使仍有效的Agent刷新凭证失效，即使目前没有活跃Agent会话。用户尚未选择同事务撤销授权/会话或存在授权时拒绝；当前代码遇到仍可刷新的授权抛出明确“规则尚待确认”，整笔回滚，没有把临时门禁当作最终产品规则。Agent模块读取grant表，Security核心通过IAdminInitializationAgentPolicy调用，遵循账号→grant→session锁序。已撤销/过期授权不复活，未知非Web会话继续拒绝。该决定不等于对真实账号执行重置的授权。
