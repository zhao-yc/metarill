# V445 同父 Excel 追加的报文预算

2026-11-07，基线 `2a98dfe7`。原七行合并命令对每个参数扫描一次完整 SQL，再把驱动重复替换参数的成本加到 UTF-8 报文预算。Mapper 的单行参数化 INSERT 已逐项核对表、列、参数绑定和父键，并计算过每个单次参数的保守字节数。

合并写入复用各行 INSERT 的预算，只扫描数据库标识、固定父候选和核验主键等重复参数。仍使用 32,768 字符、256 参数及连接报文上限与 256 KiB 中较小的字节上限。原 SQL、父锁、触发器处理、写后核验和超限回退保持原有流程。

## 实测

| 范围 | 结果 |
| --- | --- |
| 边界与 Data 回归 | 使用真实 Mapper 绑定核对 UTF-8 文本和重复参数，恰好到限通过，少一字节拒绝。Data 测试 1,577 通过，29 个依赖独立实库配置的既有用例跳过。 |
| 原导入 HTTP 与真实 MySQL | 13 次原生成 HTTP、24 组父候选对照、26 条成功物理记录。八行正常批次仍是首行独立、后七行一条命令。实际合并命令 32,074 字符、122 参数。 |
| 事务及回退 | 第 4 行父候选失效、第 6 行数据库约束、第 4／8 行缓存失配，均保留原错误行号并整批回滚。前序数据库错误优先于后段解析／必填错误。短批、无权限及自定义观察者按原路径处理。 |
| 命令预算耗时 | 用实测七行 SQL 形状、112 个单次参数、10 个可能重复的参数和合成值，在本机交错五轮，每轮各 2,000 次。旧算法中位数约 344 微秒／次，新算法约 26 微秒／次。只比较预算计算，Mapper 生成、锁等待、数据库执行和 HTTP 不在该计时内。 |
