即使没有缓存变化，C# 合同明细仍有约 6.2 秒 p95。后续需观测无变化回填的 SQL 形状和耗时，以及四并发时的数据库锁等待，再验证优化候选。该结果阻断维护性能及 MySQL 首版发布门槛。
