# 原账号页凭据与启用协议

本片仅适用于平台固定 `yz_manager` 表（6031906809708544）及原账号页（6031906822946816）。不增加账号页权限，不改变后台归属或角色协调规则，不复用旧 MD5 认证。

## 原行为与兼容决策

原详情模板保留密码必填、最多50字符，以及密钥、旧密码和“启用”控件。早期自举脚本过滤所有 password/salt 页面字段，造成原整表单与严格 DTO 不匹配。本片恢复原三个 PageColumn：1679698326770069506、1679698328187744258、1679698328317767682。它们引用原物理列，密码摘要存储长度仍255；不会新增物理列或自动执行 DDL。其他连接密码字段仍按既定边界处理，本片不恢复。

原源码的 is_disabled 语义并不统一：原页面默认1并标注“启用”，原 Agent 要求1，旧钉钉免登却把1当停用，密码登录未检查此值。本片按已确认的原页面语义适配：固定页面请求/响应/筛选/排序使用1启用、0停用；数据库仍0启用、1停用，Authentication、Bootstrap、每请求有效期检查不改，也不翻转既有账号行。显式null仍保存null，响应仍null，认证继续原物理null规则；普通应用同名字段不套用此转换。

## 写入和回显

- 新增缺少、null、空、固定掩码或预编码密码均拒绝；真实新密码为12至50字符。
- 更新省略 password 保持原摘要；显式null/空表示清空请求，但账号不允许无凭据，故明确拒绝而不是改成省略。
- 原详情及写入回执只返回固定8位 `********`，salt/oldPassword为空。只有已证明原页面 HTTP 更新精确回传该掩码时，边界将其转为 Optional 省略。直接 Service、MCP 或新增不获得这个特权。
- salt/oldPassword不进入可写 DTO；固定旧 HTTP 只剥离空字符串/null回显，非空明确拒绝，客户端不能控制盐或旧摘要。
- 真正 PBKDF2 由手写 YzManager.BeforeSave 在实际安全准备后的同一事务内执行。生成服务先验证新输入，钩子后再证明新摘要格式；缺少平台钩子的 BackendOnly 不能落入明文保存。
- 所有固定账号页面的列表、详情和选择回读 SQL 排除物理密码、盐和旧摘要；列表及选择回读不输出三个回显属性，导出所有模式排除它们。其他同表页声明凭据未获原页证明时，运行时明确拒绝且保留用途缺口；凭据不能作为范围、筛选、排序探针、关系候选或多选名称列，隐藏字段也不获得例外。原页可写控制、DOM、CSS、props/events及密码 maxlength=50 保持原样。

生成的 page-write-schema.generated.json / GeneratedWriteSchema 是旧客户端传输清单，刻意保留三个原控件字段，使空回显和非法非空值都到 C# 校验，不能静默裁剪后冒充成功。它不是持久化白名单或写授权。真正 DTO 仅允许 password 新口令，salt/oldPassword 不存在；Agent/MCP 从 LegacyPageWriteRequest 指向的严格 DTO 反射机器 schema，额外属性继续拒绝。页面权限和同事务安全守卫也不依赖传输清单。

旧客户端依赖读取或编辑真实 salt/oldPassword 的操作不再支持，服务器给固定提示；不返回秘密来维持这种旧用法。固定掩码不是密码，也不能用于登录。

## 跟进与验证边界

平台源、生成器和手写partial需一同交付，再由协调者正规生成；不要手改可覆盖 .g.cs。既有元数据不由启动覆盖，三个页面字段的存量配置需先核对，再通过原受权配置流程同步；本片没有自动修改数据库或既有账号。

离线测试覆盖真实生成程序集、原 Controller 归一、缺哈希钩子的实际 Create 拒写、本机事务回滚、FreeSql 实际详情 SQL 在 CurdBefore 截断且零 Open、真实 Vue3 与原 uni-data-checkbox、实际安全准备后的平台 partial PBKDF2/省略/null/掩码规则。脚本在独立公开输入副本重建，并对比物理结构无变化。本片未进行真实 MySQL 持久化、浏览器、并发或安装验收；角色 Runtime Gap 和平台自有 Custom 完整包门槛不因本片关闭。
