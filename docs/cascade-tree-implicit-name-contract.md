# 原级联隐式叶子名称响应

原 Java `responseFields` 对可见 selfTree 字段总是附带同前缀叶子 Name 和 DisplayText，名称不要求另配页面字段。C# 生成后端现已按此规则补齐原响应；页面、组件、样式、默认值和交互不变。

## 固定范围与写保护

只有本页可读、已编译固定 selfTree 的字符串/int64 `_id` 字段可以隐式返回同前缀 `_name`。名称必须是已显式声明或由共用selfTree规则派生的受管物理字符串列；虚拟列、错误类型和未知定义不借此扩大读取，实际缺列先显式同步。其它隐藏字段和不含级联字段的页面不获得该名称。重复的显式名称仍只声明一次，DisplayText 与任何物理字段重名时拒绝。

名称从当前来源实体的受管存储值投影，完整路径仍走既有目标图；不把名称刷新扩成每次读取都写库。新增、更新、复制仍由最终 Service 在原事务里验证并重算名称，省略保持、清空联动。原完整实体回传时，只把隐式名称加入固定只读 echo 白名单并忽略，不能据此写入；内部严格 DTO 继续拒绝该字段。

## 用途计划

列表、详情、选择的固定用途 IR 分别跟随本用途的级联 ID，补上该受管物理名称和计算路径别名。详情专用级联不进入列表/选择计划，错误定义和别名冲突保留 Gap。

此 IR 尚未整体接入实际 SQL/响应的用途裁剪，当前公共 VO 仍沿原页面可读并集；不能把本批当作全量 SQL 最小投影接线或完整应用验收。原账号和其它固定控件的专门读取合同保持。
