# 管理完整工程的原流程更新

日期：2026-10-30；起点 `3901e215270001b38152621104e0f9eb021ef7f5`，对应C05/C52。本批修改生成基础设施和本地助手验证，不改原页面、样式、元数据或数据库。

## 接入方式

`LocalGenerationUpdater` 在原FullApplication流程中增加明确的FullManagementApplication分支。普通清单新增字段为null时不序列化，原模式没有管理来源或管理专用路径放行。管理目标与候选必须各自通过完整受管归属核验、持久化业务来源核验和当前固定模块重新装配，来源描述严格拒绝未知字段。

普通/管理模式、项目、数据库品牌、命名空间或已绑定管理后台不能通过源码更新切换。未知历史模块版本不能由当前固定工厂证明时明确拒绝；本批没有自动迁移模块版本或数据库的能力。

`update prepare`及在线本地助手仍接收原单动作请求，管理后台只从已核验目标读取。配置范围包含脱敏原业务快照，页面范围包含固定管理工作台及其四份前端生成资源，运行时范围沿原清单。缺少依赖仍按原流程提示，不能静默扩大动作。

## 原子写入及保护

最终管理来源声明根据实际合并后的五份元数据重建摘要，作为第四份事务清单参与原备份/写入/回退；外层包清单最后提交。已有手写Service partial、AppID、私有appsettings继续保留。重复预览收敛为空操作。未知管理路径不变成通配写入权限。

来源声明写入后故障沿原事务回退；首次恢复中断时保留active现场，后续显式recover只依赖已确认计划、身份备份和旧文件，即使候选已移走仍可恢复。错误确认摘要拒绝，存在未恢复事务时禁止开启新任务。
