C# 在父锁返回到首次插入之间更短。首次插入至提交开始多 12.46～15.96 毫秒，COMMIT 多 3.69～12.39 毫秒，父锁返回到提交结束多 8.69～25.05 毫秒。父锁调用包含排队和语句执行，COMMIT 计时包含其在 MySQL 内的等待。分段尚未识别确切的锁释放时刻或 COMMIT 内各等待项。后续先针对最小权限路径的首次插入至提交开始区间分解实际缓存写入，候选继续验证失败行号、整批回滚和触发器语义。

两轮各 60 份证据和 12 个资源窗口已核对。独立新连接确认各轮双库、账号、16 个应用相关容器位置、独占 MySQL、网络、所有权、源凭据、数据目录和远端暂存根均已回收。产品代码无改动。独占诊断的结论用于定位，MySQL 首版继续受 V670 共享实例四并发正式结果阻断。
