# 业务按钮文件来源当前权限（2026-10-29）

本批继续 C18：业务按钮修改文件字段时，不能以请求开始时的文件来源授权或按钮授权代替当前来源读取权限。页面、样式、操作和接口不变；不增加超级身份门槛。

## 执行边界

- 生成 Service 已在记录锁前、实际更新前调用按钮当前证明。本批文件观察器只有在本次真正涉及文件字段时，才调用 `WithButtonFileCurrentAsync`。
- 文件用途当前读要求原 Session、原事务、原操作者，以及该事务中已经成功完成的相同页面/按钮证明。不能在文件或记录锁之后首次补规划安全锁，也不能另开短事务作证明。
- 按既有顺序复读已持有的项目、后台、grant、session、账号、角色和授权。首次当前读固定角色集合，后续可缩小，不能补取新角色锁；新增角色要求重新发起事务。原三参数读取合同保留。
- 文件来源权限和精确匹配值来自锁后真实身份；来源页面/表/项目/后台与发布绑定不一致时排除该文件来源。按钮通过不能赋予来源页面读取权。
- 平台及完整应用宿主只在封闭文件回调内使用当前文件身份。普通页面权限、按钮范围、身份访问器及 HttpContext 中的请求身份不变；跨 await、异常和嵌套回调后恢复原上下文。
- 文件观察发生在实际更新之后，沿用原写后允许离页规则，不使用新记录值重做写前筛选。引用校验、引用写入和业务记录共用原事务，后续失败一起回滚。
- 文件字段省略仍不改引用；普通 CRUD、复制、导入及物理删除继续原路径。本次仅为已有内部业务按钮来源增加当前文件用途证明。旧宿主未实现新方法时明确拒绝，不能退回请求快照。

## 验证及限制

新增合同运行真实认证、角色聚合、SqlRowStore、当前读协调器、平台授权器及文件观察器；只替入数据库传输。覆盖撤权、匹配值变化、来源重新绑定、成功引用与尾部失败回滚、错误主体/事务/按钮、缺少预证明、后期角色扩张、字段省略和旧宿主默认拒绝。完整应用仍须编译实际模板，并验证未接入协调器时不执行回调。

这不是 MySQL 的锁、隔离、死锁或真实回滚验收。正式 Web/OAuth/CLI、跨连接协调和同条件性能仍未完成。平台库与业务库不同连接时仍明确拒绝当前按钮证明，不能因此声明跨库完成。
