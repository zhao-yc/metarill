# 非冗余跨表的显式全局物理目标

本批B64接通R0来源的crossTable链中显式全局R1物理目标，保留原页面、组件、路由和部分选择合同。全局声明只决定该目标行的范围；来源仍属于真实项目，混合链中其它普通目标继续按项目过滤，候选／路径及重新选择仍要求真实目标页面权限。

全局目标必须使用`scopeKind=global`明确声明，并将表和页面明确发布到当前模型；目标页面只接受固定条件，不得把请求项目或父参数混入后再忽略。全局派生／R0目标、全局来源及其它未证明用途保持门禁。SQL项目省略只用于已通过共享证明的crossTable目标别名，普通标量联接保留原行为。
