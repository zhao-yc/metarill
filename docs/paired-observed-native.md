Java SIGTERM 的 JDK21 正常退出可为143，C# 必须为0；137、OOM、仍运行或错误退出都拒绝。退出状态仍不能替代真实 finalized 索引及全部请求文件。停止前核全部对象 ID／token，正常关闭失败仅允许核归属后的清理，保留的未完整副本不算采集通过。
