# V467 文件对象删除失败后的重试

2026-11-07 在 Server-200 的 MySQL 独占测试库验证，起点为 `6ba42a75`。原删除入口先提交文件记录失效，再尝试删除存储对象。文件系统拒绝时会报告对象清理失败，之后即使故障解除，使用原文件 ID 也无法再次清理，因为普通文件读取会排除墓碑。
