# V656–V657 当前发行包原 Web 配置与 Excel

2026-11-08。固定产品 `31cf5321`。平台及独立 Full 沿用 [V643 发行 ZIP](current-linux-archives-v643.md) 和 [V644 原 H5](current-release-web-v644.md)。本轮网关与正式宿主共 311 个文件逐份核对，使用 Server-200 独占 MySQL 8.4.11 和 Redis。平台分库、共库与独立 Full 均完成显式空库安装。实际页面经 Caddy 回环同源代理及本机 SSH 转发访问。

独立 MySQL 从新 SSH 逐值核对两条成功记录、实际普通编辑账号、长项目 ID 及零条失败批次残留。平台所连业务库无本轮导入行，原只读对照记录保持。独立核对导入文件两轮逐字一致及下载摘要。

V656 首轮保留为失败。原导出请求到达正式宿主后返回 HTTP 500，日志确认测试镜像继承的 `/data/exports` 位于只读层。首轮也遇到模糊表名的相似记录及移动布局缓存，按实际状态诊断，未把首轮零失败批次行推断为完整浏览器通过。V657 为私有导出根增加可写挂载，按 UTF-8 独立读取数据，并从真实移动布局加载原页面。复用两套原 H5、宿主 ZIP 和两份工作簿。

两轮独立确认同轮数据库及账号、容器、网络、私有目录和网关端口已回收。本机转发和临时登录资料已核清，Ego Lite 仅清理本轮两个站点来源，并结束验收空间。当前覆盖回环同源 Web 的固定浏览器业务，实际发行域名和整体签收仍按 [首版清单](../mysql-first-release-milestone.md) 验收。
