# 身份后台写协调器：基础守卫合同

本切片只交付首个记录锁前的准备信息和 Mapper 写前的默认校验钩子。它不是完整的身份后台写协调器，不关闭角色控件能力缺口，也不证明撤权或真实 MySQL 并发已安全。

## 生命周期与兼容

`RecordMutationPreparation` 保留原位置参数，并增加 `TargetId`、`ScopeValues` 初始化属性。更新、删除及复制传原目标主键；新增及导入外层尚无主键。准备范围只包含已编译的项目、后台、角色归属及固定页面中已证明的 parent/project ID 键，不包含角色数组、密码或整实体。显式提交 null 保留键和值，省略不补为 null；服务端页面父/项目绑定仍优先。

这些值仅是发现预锁范围的提示。宿主必须查询真实记录，并核对当前认证身份，不能把客户端指定的后台、项目或父 ID 当授权。

`IRecordMutationGuard.BeforeWriteAsync` 使用默认空实现，旧宿主只实现 `BeforeMutationAsync` 仍可编译和执行。生成器在手写 `BeforeSave`/`BeforeDelete`、关系授权及最终关系校验、必填与父归属校验后，实际 Mapper 写入前调用此钩子。新增、更新、删除、复制均覆盖；导入继续先执行外层准备，每行复用新增或更新，全部共用一个实际事务。导入外层在其首次父记录锁前传固定 parent/project 窄提示，不含逐行目标；不能据此声称逐行准备早于整批的首个父锁，也不构成完整批次预锁。准备和写前守卫任何异常均阻止后续 Mapper/观察者并回滚。

写前上下文仅提供固定范围原值、最终值、提交字段名及同一事务，不提供密码或任意实体。额外页面范围仅接收非敏感、`_id` 命名、逻辑 id/int64 且能沿稳定外键定位到已发布 long 主键父表的字段；项目固定为 `yz_project_id`。共用发布脱敏器的敏感字段规则，名称、密码、token、其他普通值或字符串伪 ID 范围均不进入新提示/快照。它们原有 SQL 过滤和普通生成行为保持，不因新可选守卫被禁用；`ScopeValues` 是明确的固定子集，宿主缺少所需提示时必须自行查询证明或明确拒绝，不能把缺失当作授权。除此之外，固定安全范围字段集合包括 `yz_project_id`、`yz_admin_type_id`、`yz_role_id`、`yz_role_ids`、`is_super`、`is_scope`、`is_built_in`。原值在请求合并和手写钩子之前捕获，最终值反映手写归一化。省略角色字段不能据此跳过检查：后续协调器仍须核对合并后的真实角色集合。上下文只读取值，不替代 Service 的 DTO 白名单、权限、关系、必填和文件事务。

## 后续协调器约束

后续 Runtime 必须在首个记录锁前按项目、后台的稳定顺序取得全部必要聚合锁，再以当前读重新读取操作人、会话、有效角色、授权和目录。MySQL 默认 RR 下，已有普通 SELECT 可能建立旧一致性快照；不能仅凭再次调用普通读取策略声称锁后撤权生效。写前发现真实范围不在准备锁集时保守冲突回滚，不逆序补锁。

本合同没有减少已发布导入、复制或删除能力。安全表启用批量写入时，协调器必须先核对真实开关，并在任何行写入前收集窄范围、统一排序锁定；不能以逐行补锁替代整批范围计划。当前平台 manager/role/admin 的导入和复制均未开放，该事实须在协调器实施时再次核对。普通应用的导入和复制本片仍保持可执行。

最终权限规则沿用用户确认的原 V8 页面编辑权限及真实目标后台归属，不额外增加超级身份门槛。Workbench 暂态管理员入口与手写角色钩子仍待后续同一协议恢复，不能把该暂态当最终验收。

## 下发与验证

ApplicationPackager 递归复制真实 Core 源码，独立 Host 使用 net10.0/latest 并引用该 Core；不需要新增单类模板副本。更新需将 Core 运行时与重新生成的 Service 同时纳入预览和应用。本片只修改生成器源头，不手改平台、示例或旧独立包产物；由主线统一正式再生。

真实敏感/非 ID scope 元数据反例仍按原合同生成，原 SQL 保留且新准备/最终上下文均不含其值；规范 long 外键正例则完整传递，并编译实际生成批次。新增 `GeneratedMutationGuardContractTests` 实际生成并编译程序集，执行真实 Service 方法，仅替代数据库传输，验证四种单对象入口、导入外层与逐行同事务、前后拒绝、Optional 省略与 null、手写归一化、旧守卫默认方法及无守卫普通应用。离线事务仅用于调用顺序和引用一致性，不能冒充真实 SQL 锁、RR 撤权或 MySQL 回滚验收。所有证据日志和 TRX 保留在私有 `.local/security-realm-write-evidence`，不提交运行产物。
