# V478 原后台账号初始化的分库移动 Web 验收

2026-11-07。以 `a742cde6` 为当前基线，逐文件核对并复用 V477 的 HBuilderX 5.34 平台和独立业务 Web 导出。两套 C# Production 宿主分别连接 Server-200 本轮独占的两个 MySQL 库，登录失败计数使用隔离 Redis。ego-browser 对两页采用 390×844 移动 Web 视口。

| 环节 | 实测结果 |
| --- | --- |
| 原移动入口 | 使用两套原移动登录表单。平台在原项目选择页切换示例项目，打开原后台类型列表，点击移动行进入独立详情。导航栏「更多」入口宽 60 CSS 像素，中心命中。 |
| 原确认流程 | 「更多」菜单选择「初始化账号」，看到原确认文案。取消后零写请求，确认后仅一次原中央接口请求，页面显示成功。 |
| 独立业务 | 旧会话刷新后的菜单请求返回 401，页面回到登录。旧密码拒绝，新密码登录后从移动「菜单」看到「客户」。两端从原「我的」注销。 |
| 物理核验 | 原账号 ID、姓名和档案保留，密码、角色正确重置。业务库有两条撤销记录、零活跃会话。平台库无目标账号及活跃会话。 |
| 回收 | 轮次 `db60c1c9e1c94f48` 通过。双库、账号、所有权记录、Redis、回环服务和临时凭据独立核清。仅清理本轮专用站点数据，验收空间已关闭。 |

验收中按 uni-app 实际渲染的可见行修正定位，在「更多」菜单点击时核验视口交集和命中点。独立菜单同时渲染隐藏与可见副本，按原移动菜单路由和可见项核对。整个用例只确认一次初始化。

验收覆盖固定移动 Web 视口，设备兼容性和 Agent 刷新授权规则分别见 [实施进度表](../project-progress.md)。
