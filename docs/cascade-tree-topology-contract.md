# 同表树换父级的完整分支校验

直接父级联与同表非父级联共用内部拓扑读取。保留原页面、样式、交互、候选与路径接口；私有结构参数不进入请求协议。

## 深度与事务

直接父控件在保存前拒绝选择已有64层的父路径，避免新节点成为第65层。正常Mapper新增、更新或复制之后、BeforeCommit观察者之前，创建及提交父键的操作还会在同一事务内检查当前节点的完整父链和全部后代。新位置的绝对深度加上子树高度不能超过64层；循环、断链或超深整体拒绝并回滚，不补写修复数据。省略父键的普通更新不增加此项拓扑遍历。

内部读取只投影ID与父键，保留真实Actor、项目及软删除范围；单独跳过页面常量条件，防止隐藏后代漏检，不向界面暴露隐藏节点或名称。选中目标的原权限、完整路径及页面条件仍照常校验。软删除记录不作为活跃子树成员。

受管ID与父键沿既有正整数及规范文本约定；本批不迁移或归一存量手写脏数据。后代遍历复用既有图算法，每批200个父键、每页1000条按主键游标推进，不受候选500项限制，也不返回截断后的成功。路径及访问到的后代使用当前读锁，直到调用者提交或回滚；没有新增数据库观测授权。
