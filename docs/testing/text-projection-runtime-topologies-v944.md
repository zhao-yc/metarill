# V944 新版 Linux 发行包三拓扑验收

2026-11-10。从 [V943 的 `0b65780c` Linux x64 双包](text-projection-linux-release-v943.md) 提取并核对 103 份宿主及元数据。Server-200 使用独占 MySQL 8.4.11 和 Redis，按正式入口依次验证三个拓扑。

| 拓扑 | 普通启动表数 | 显式安装表数 | 普通查询角色尝试写入 |
| --- | --- | --- | --- |
| 平台库与业务库分离 | 0／0 | 24／13 | HTTP 200／业务码 500 拒绝 |
| 平台与业务共库 | 0 | 25 | HTTP 200／业务码 500 拒绝 |
| 独立 Full | 0 | 13 | HTTP 403／业务码 403 拒绝 |

三个拓扑均通过显式和重复安装、真实登录、菜单、客户 CRUD、字段省略与显式 null、软删除、重启会话和注销。普通查询角色可分页并查看详情，写入拒绝后再读物理记录。分库模式按原规则核对账号与会话归属、业务记录及跨宿主令牌，六次跨宿主令牌请求均拒绝。

独立 Full 首次预览列出 13 项，预览后仍为空库。安装后重复预览为 0 项。三组均核验只读结构反查，四库索引部件数为 54／30／54／30，未发现非预期索引部件。分库和共库各核对 665 条布局配置，保留显式布局并通过原控件保存。独占容器、网络、库、账号及远端数据和凭据副本均通过新 SSH 独立核零。

本轮覆盖固定 Linux 宿主的安装和真实 HTTP 接口。桌面与移动 Web 浏览器、完整 CI 和同条件性能继续单列。
