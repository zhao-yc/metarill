# 原表格导入的安全错误提示

原 `chooseImportFile → requestJson/parentId → importDatas{pageId}` 流程和前端 DOM、props、事件不变。输入错误通过原 `R.msg` 展示，不要求前端解析 C# 异常或属性路径。

生成器在已发布中文标题的分支内，用现有 JSON 选项和该字段的边界类型先核验单元格。数值错误因此保留标题，而不会到整 DTO 反序列化时才只剩英文属性路径。保留原省略、空白清空、null、普通整型字段的字符串长编号、数组、布尔和常量转换协议。额外类型核验发生在服务端内存，不增加数据库查询；本轮未做性能基准。

`PageImportException` 只开放固定枚举工厂。输入提示示例为 `第2行，列「金额」：应填写有效数字。`。行号从导入 JSON 的第一条数据开始计数，不包含 Excel 标题行；已有有效行号不会被外层覆盖。行号必须为正值，尚未定位的数据结构错误不虚构行号。列名仅来自已发布标题；未知、重复的 Excel 标题不回显客户端原名称或原值。

日期、布尔、数组和常量错误也使用固定中文提示。关系只有明确的无匹配或重名才归为可修正输入；数据库、路径、驱动转换或其他内部异常不能被单元格 catch 转为输入错误。身份拒绝、权限拒绝和请求取消保持原异常传播。其他错误只保留安全的数据行上下文及完整内部异常链，不拼接 `error.Message` 到可展示消息。

| 宿主 | 输入错误 | 内部执行错误 |
| --- | --- | --- |
| 平台 | 沿原 HTTP 200 / R.code 500，R.msg 为固定行列提示 | 沿原 HTTP 200 / R.code 500，通用消息，服务端记录异常对象和 TraceId |
| 独立包 | 沿现 HTTP 400 / R.code 400，R.msg 为固定行列提示 | 沿现 HTTP 500 / R.code 500，通用消息，服务端记录异常对象和 TraceId |

可修正的输入不记录成服务器意外。日志保留内部异常和堆栈用于排查；HTTP 不包含 SQL、文件路径、连接串或内部异常正文。其他非导入接口的原错误分类不在本片全面重构。

原 YZP v8 非冗余导入在 `JavaService.appendNonRedundantImport` 中维护行号和当前中文列，异常经 `GlobalExceptionHandler` 返回 `R.msg` 并记录堆栈；旧冗余分支没有相同的逐行列包装，不能将这一行为泛称为所有旧入口都已有。本次 C# 修复保留可操作的行列定位，同时避免直接返回原内部异常消息。

离线验证执行真实生成 Import 方法，覆盖首行合法、次行数值/溢出/布尔/日期/数组/常量错误，中文列、未知/重复标题、JSON 行形状、null、空白、字符串长编号、内部异常、身份/权限/取消，以及关系无匹配/重名与驱动异常分类。ORM 与事务由明确离线代理记录，不证明真实 MySQL 回滚。

独立包通过真实打包、构建、回环 Kestrel、开发认证和私有测试控制器验证 HTTP 与 Console 日志；私有控制器只写临时包，产品路由不含探针。平台测试通过真实 ASP.NET 管线和 HTTP 客户端核对原响应习惯与日志，数据库及 ORM 均硬拒绝且访问计数为零。这些验证不等于真实导入数据库验收或浏览器验收。

已有项目须更新生成器、Core 基础工程与对应宿主错误映射，再预览并再生成，保护手写 partial。不涉及元数据、DDL 或历史数据回填；不可只更新模板而保留旧基础异常合同。原坏批次全回滚已有先前实库证据，新提示仍须在整合后重新导出、构建并通过原前端选文件操作确认，不把本片离线代理当作该证据。

本轮最终扩大生成回归100/100通过、0跳过；该集合已包含定向4项、DI相关合同及2项固定绑定导入整合，不重复相加。另平台无数据库HTTP/日志1/1通过、ORM/数据库访问计数为零。未执行共享数据库、DDL、浏览器或HBuilderX；新提示的原前端选文件验收仍由主线完成。

固定源父关系若在后续配置中启用导入，名称反查也复用同一OptionsScope：来源仍按import操作授权，目标list权限先于名称或ID匹配，目标父由服务器推导，不把来源page/index ID当作table ID；未证明的声明仍固定拒绝，不回落宽查询。该分支只读取匹配Id，未声明绑定的普通关系保留原合同。私有元数据启用两页导入/新增的实际整批编译及授权先于数据库Open测试用于验证此整合，不改变生产索引页CRUD全0，也不声称该组合已做实库验收。

范围说明：数据库逻辑模型接受binary并不代表DTO生成器已支持。当前GenerationModel.TypeFor明确拒绝binary，本片不增加byte[]或Base64字段生成，也不将不支持类型宣称已通过导入验收。
