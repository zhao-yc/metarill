# V279 Android 模拟器独立应用普通账号写入验收

2026-11-05，固定产品源码 `c5c2388`。沿用 V278 生成包，对照清单逐字核对了 389 个前端文件和 69 个宿主文件，设备验收后再次比对。使用独占 Android API 30 x86 模拟器及 HBuilderX 5.34。设备上的 APK 与本机标准调试基座 SHA-256 一致，架构为 x86。仅在本轮模拟器授予 `READ_PHONE_STATE`。

宿主记录登录、新增、修改、删除及退出各一次请求，各返回 HTTP 200。可访问节点、实际截图、HTTP 时序及脱敏核验结果保存在项目私有目录 `E:\git\metarill\.local\android-write-v279`。主要命令为 `D:\HBuilderX\cli.exe launch app-android --project E:\git\metarill\.local\android-write-v279\package\frontend --deviceId emulator-5556 --ui true`。

V278 的失败截图显示原生「加载中」遮罩覆盖新增表单，宿主写入请求为零。V279 使用 1080 × 1920 的独占 AVD，先用两张实际截图确认遮罩不在，再输入和提交。未能确定 V278 遮罩持续出现的原因。V279 首次确认框定位把取消控件当成确认控件，守卫在点击前停止，随后根据实际节点定位确认控件。宿主核对删除只执行一次。

验收后用独立连接核对 Server-200 的本轮 MySQL 库、账号、归属记录和隔离 Redis 均已移除。专用模拟器、转发、本机回环端口、三处模拟器数据目录及临时凭据已复核清理。
