2026-11-10。在 Server-200 的独占 MySQL 8.4.11 实例，沿用 V936 的 Java、C# `68af5319` 和 Redis 镜像、普通账号、共同索引、八行 XLSX、资源限额及默认排他父锁。InnoDB 和 binlog 继续逐次提交持久化。当前 `0b65780c` 的相关 Data 及生成路径源码无差异，独立 Full 的方法体对照见 [V943](text-projection-linux-release-v943.md)。本轮用于定位耗时，正式矩阵按 [V912](current-exact-mysql-performance-v912.md) 跟踪。
