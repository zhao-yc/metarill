## 实际验证

- 普通启动和显式预览保持空库。重复显式安装后 44 张表的结构差异为零，重复安全初始化保持原密码摘要。使用原三字段表单登录真实管理员及非超级普通账号，验证菜单、页面和候选授权。候选目标页撤权后原接口返回 403。
- 通过原导入接口提交完整、根级、中级、空值和共享分支路径，从独立数据库会话逐级核对物理 ID 和名称副本。超过 JavaScript 安全整数的 ID 仍以字符串精确传输。下载真实 XLSX，核对原三列或四列表头、顺序、数据及项目隔离，再将工作簿读出的值经原接口重新导入。普通新增、修改、复制也走实际生成入口。
- 全局目标改名后，物理缓存与原 XLSX 同步读出新名。旧名、同父重名与冲突的共享路径被拒绝，失败前后摘要相同。原维护接口在管理员授权下修复人为写旧的全局目标缓存，第二次维护报告零变化。
- 缓存 CHECK 在更新后段拒绝，业务与文件快照整体回滚。真实附件走上传计划、multipart、完成登记和受保护下载。首条导入行实际执行写入、文件引用已在同一事务中可见后，手写规则拒绝次行，独立连接确认业务、附件及引用的数据库状态回滚。复制、删除及撤权后的文件读取均按原协议验证。
- 宿主同址重启后原普通会话可用，注销后原会话访问返回 401。复核固定原包及执行副本，仅执行副本产生允许的结构历史。
