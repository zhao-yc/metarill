# 混合关系名称传播

状态：B31固定混合单值／多值后端、生成与独立完整包已完成（2026-10-23）。冻结源码 `c55b605da5a4`，1154个源码／测试／元数据／模板／前端文件。不是全部B20／B21或原浏览器验收完成。

## 已实现的固定范围

R1来源的物理名称缓存经过R0中间实体，读取最终R1目标的物理标量；中间实体只保存关联ID，不补物理名称。最终目标改名、删除，或中间实体切换关联ID，均能更新来源缓存和继续依赖该缓存的后续R1副本。同一目标的两个角色路径独立保留；普通多值物理名称与混合单值共用事务事件队列。

目录在生成阶段编译，宿主静态初始化后只执行不可变计划，不接受请求传入表名、字段、路径、SQL或排除项。反向计划从来源真实外键定位，不要求已删除目标仍能联接。每个输出保留自己的实际字段依赖，改无关标题不重算名称，另一条未触及关系的历史缓存不被顺带修复。

自动来源刷新在生成Service保存后执行，返回实际改变列补回原实体与VO；普通自关联本次写回执可得到当前名称。沿用原DTO只读边界，不向客户端开放缓存写入口。内部传播只写派生列，不调用消费者Service、业务钩子、页面动作或文件观察者；消费者页面无操作权也不应破坏已授权目标写入的一致性。平台固定配置派生缓存按稳定表ID保留专用协调器，避免重复挂载。

## 事务与维护

传播必须加入调用者现有事务，不自行提交。来源按主键分批128条当前锁读，目标当前锁读；执行前检查真实数据库、InnoDB、主键和依赖列物理结构。不用旧RR快照复制名称，不启动ORM自动DDL。缺失、软删目标清空名称，原关联ID保持，其他项目和软删来源保持。

维护回填复用同一当前读物化器；根缓存实际改变后继续进入统一队列更新下游。字段级循环在发布时拒绝。没有完整回填证明的来源整表不发布本自动子计划；多值数组缓存当标量中间值、全局目标、派生文件和其余复杂控件组合仍不在本批支持声明内。

死锁／锁超时交给原外层事务整体回滚并提示重试，不自动重跑业务钩子。测试只对本任务随机表用NOWAIT确认锁，不新增PROCESS或全局锁观测权限。
