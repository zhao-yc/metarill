# V525 原合同列表的联动筛选

2026-11-07，以 `9e4a9402` 加本轮四份源码与回归文件为固定来源。生成的原列表没有详情的 `formParametersName`。旧测试向未定义的键预置了数据，实页从该键读取时无法获得当前筛选值。

原 List 的分页及已选回读现在从本页筛选草稿投影已发布标量。详情和显式提供缓存键的宿主继续按原方式取值。初次录入或移除依赖字段都会使候选失效，旧请求不能覆盖新条件下的候选和标签。只传声明的字段，保留字符串 ID、缺失与显式 null 的区分。列表仍通过原「筛选」或「确定」提交，原布局、选择器和服务端授权沿用。
