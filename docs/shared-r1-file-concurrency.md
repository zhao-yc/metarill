## 专项目标

14 个普通／全局、四键、长短分支及派生名称模型，每个执行国家、地区、城市／短主叶、仓库及混合 owner 五父页：

- 先建立明确的 RR 旧快照，再由独立会话提交目标禁用、来源项目或实际父键变化、混合 owner 冲突。既证明旧会话仍见旧值，也证明另一连接已见新值；引用写入与物理删除准备必须当前读拒绝，原记录和含墓碑引用整笔回滚。
- 原引用观察器持有真实来源、实际父路径及相关文件的锁；独立 NOWAIT 精确 3572、真实写等待精确 1205，释放后实际写入并回滚。无关分支、未选节点及另一来源保持自由；物理 DELETE 后来源行锁仍须存在。
- 删除后实际父目标禁用或其祖先键失效时拒绝；合法上级变化不改 R1 物理父身份，无关分支变化也不能误拒绝。正例先完成真实删除与解绑，再用专用尾部失败回滚保留样本。
- 写入尾部失败、删除尾部失败及正常物理删除均通过完整自有表／文件／引用状态验证；精确随机样本按结构和内容两次核对后清理，并独立核零。
