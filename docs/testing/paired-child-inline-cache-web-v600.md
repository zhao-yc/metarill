# V597–V600 同父明细导入的生成应用与性能复验

2026-11-08。固定产品提交 `5476d253`，样本为原三表生成应用的同父八行 Excel 导入。Java 与 C# 使用相同合成业务值、索引和原页面路由。两端分别以普通角色执行原接口。

## 完整生成应用

- 严格构建含原元数据、页面生成代码及六份公开手写业务夹具的 Linux 宿主，核对 694 份源码清单和 54 个发布文件。
- 服务器镜像复用 V568 已核验的完整生成应用。仅替换来自公开产品提交、已通过 V596 数据层验证的 `Metarill.Data.dll`，其余 53 个文件保持原样。远端通过隔离探针逐项核验 54 个文件、运行时与索引预览。
- V598 在独占 MySQL 8.4.11 上完成 72 次真实原 HTTP 导入，两个宿主各 288 条明细逐值相同。原登录、普通权限、安装结构与索引也通过。独立核验 31 份证据、临时双库、账号、18 个容器、网络及独占 MySQL 均已回收。
- V598 依赖 SQL 注释识别快速路径，采样没有捕获该标记，且更新语句匹配未覆盖表别名。该轮只证明实际入口和最终数据，保留为诊断样本。

## 运行路径复验 V600

同一测试镜像、同一普通 Web 角色和数据库最小权限。复验 72 次真实原导入，两端各 288 行逐值一致。改按实际执行的 SQL 识别分支，采样不保存原始 SQL。

C# 侧 36 个成功事务均尝试直接权限证明。每批八次明细插入、八次缓存更新，其中七行执行两阶段核验，单次写入为零。对照 V599、V600 的账号初始化 SQL，运行账号均缺少源表 `TRIGGER` 可见性证明所需的直接权限。当前单次写入路径在这种部署下回到原两阶段写入。V596 数据层的降写入量只适用于已取得证明的数据库账号，V599 的负载结果对应最小权限默认路径。

本轮不调整应用账号权限或正式性能口径。后续将有、无证明的应用路径分开核验，继续压缩最小权限下的事务成本。V600 的 31 份证据和全部临时资源已独立核验。
