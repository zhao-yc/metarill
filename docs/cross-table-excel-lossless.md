# 跨表级联Excel无损生成接线

日期：2026-10-30；起点398565b，本任务同提交。对应B14/B100。用户2026-10-29已确认无损还原路线，原页面、按钮、样式和列保持。

## 实现

- CrossTableExcelPath按固定层数保留完整路径或尾空层，根“国甲//”、中层“国甲/区甲/”不会变成末级选择。旧短写只在固定链中可唯一解释的连续层段兼容；不同层或同级重名拒绝，不再按排序第一条回退。数字外观始终按名称反查，不当作主键。
- 查询只由生成期固定层号选择强类型目标，名称/父键参数化；R1用原CrossScope，R0用既有非冗余计划。导入查找及回读加入原事务当前读；后续仍由标准Create/Update核心执行对象规则、文件引用及实际存储核验。
- 每个路径返回全部级ID。CrossTableExcelRow先收集再合并，非空路径、显式祖先和共享槽冲突报错，不由JSON属性顺序覆盖。空值仍保留同行显式祖先及服务器父范围，省略控件不自动清空；关联依赖隐式祖先时按拓扑先解析产生它的级联。
- 路径导出补充隐式ID窄投影，在同一快照中按实际路径取名，并验证文本可唯一反查到原ID。相同路径在该次导出内缓存。只给实际路径导出增加快照，普通列表/统计事务行为保持。
- 生成计划沿原分隔符配置解析，未改空白配置的既有回退；共享路径/Excel文本规则能保留空格。固定跨表链不误套递归自树64层上限（70层仅为共享规则合同用例，不是70层完整应用验收）。名称包含分隔符、空白名称/首尾空白、路径空洞、层数错误或坏ID明确报错，未增加转义语法。
- 当前候选必须包含两个Core源文件；旧工程可以完整预览同步运行时，再生成并保护手写partial，不能只更新页面。
