# V740–V741 固定候选平台 S3、权限与回滚

2026-11-09，固定 de6da757。从与 V732 发行包、V733 Windows 回归一致的 2,945 份源码重新构建。只在合成客户夹具中增加公开和受保护两个附件字段。原 CLI 连续生成两次的 14 个归属文件逐字一致，手写 Service 摘要不变。两轮复用相同的 51 份 Windows Production 宿主文件和 7 份独立 SDK 探针文件。SeaweedFS、MySQL 测试库和 Redis 均为 Server-200 上的独占合成资源。

| 场景 | 原 HTTP 请求 | 独立 SDK 探针 | 核验 |
| --- | ---: | ---: | --- |
| V740 平台和业务分库 | 37 | 9 | 客户及附件引用位于业务库，普通权限和匿名公开路由、失败回滚、删除与四次注销通过。 |
| V741 平台和业务共库 | 39 | 9 | 真实共库，另一个已配置但未发布的库保持空库。原地址重启后复用写者与只读会话，权限和记录回读一致。 |

每轮三个普通角色分别具有编辑、只读和空权限。公开附件仅在正确的已发布项目可匿名下载，受保护附件按实际来源记录权限校验。用未完成上传的文件触发保存失败后，数据库备注、引用、存储键，以及独立 SDK 读取的两个对象字节和摘要均保持。删除客户并清理文件后，独立 SDK 验证桶内零对象并确认空桶已删除。两轮分别用新连接确认临时库、账号、归属、容器及配置均已回收，本机转发和运行时私有文件已清理。

准备阶段曾被隔离端口范围和独立探针的旧端点拦截，均未发送业务 HTTP 请求。第二次留下的隔离 S3 容器与转发已独立核清。探针重建后通过 6 项回环地址、8 项对象清单门禁，产品宿主字节保持一致。

本轮覆盖真实 S3 兼容服务与原 HTTP。浏览器、正式对象存储供应商和整体签收仍按 [首版清单](../mysql-first-release-milestone.md) 核对。
