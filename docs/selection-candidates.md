# 选择页配置候选

控件明细编辑器沿用原选择器交互，统一调用 `POST /api/admin/custom/config_column/select_page_options`。无参数或空对象保持旧单选合同，只返回 `type=1`；显式 `controlKind: "SelectPage"` 等价，`controlKind: "MultiSelectPage"` 只返回 `type=2`。支持原表单及JSON对象，不接受其它控件、数字、数组、null、重复键或额外请求字段。

候选只取真实网页登录管理员当前项目，页面和真实父配置表均须有效、未软删且属于该项目。客户端不能指定项目、后台连接或父范围。每项仍只有 `id/name/value/text`，不附带SQL、字段或控件明细；认证和权限没有放宽。多选不再借用有真实父scope的自动页面候选接口。编辑器按当前控件类型缓存，类型切换后的迟到结果不能复用。

2026-10-19，协调者真实HTTP用例覆盖单选默认/显式单选与多选分离、四字段、原表单、严格输入、页面/父表软删、父表跨项目和匿名/当前项目边界。仅通过原配置API建唯一临时配置表，受控测试行修改后恢复并统一删除聚合，没有创建业务物理表。完整API31/31、前端232/232均通过且零跳过；前端执行真实组件方法及迟到回调。该接口可列出合法目标页，不代表完整Multi字段、非冗余读计划、名称传播或跨端已经实现。
