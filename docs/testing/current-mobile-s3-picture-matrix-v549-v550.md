# V549／V550 独立应用与平台共库移动 Web 双图验收

2026-11-08，产品基线 `aef9b0cc`。两轮分别使用 Server-200 独占 MySQL、Redis 和 SeaweedFS S3，采用相同的两种普通角色与合成 PNG。平台分库同一修复的实测见 [V548](web-request-loading-v547-v548.md)。

| 验收项 | V549 独立生成应用 | V550 平台共库 |
| --- | --- | --- |
| 发布来源 | 从五表共享级联合成目录经正式 CLI 生成 735 份包文件，逐份核对 734 份清单项。私有副本设置 AppID 和同源 API，HBuilderX 5.34 导出 86 份 Web 文件，严格发布 69 份 C# 宿主文件。 | 复用 V548 的原 160 份 H5、69 份宿主，逐份摘要一致。 |
| 空库与真实身份 | 显式结构预览、结构应用、安全初始化。编辑与只读账号走原生成登录、菜单、列表及详情。 | 显式平台初始化，普通账号从原设备和项目选择进入示例客户详情。 |
| 移动 Web | 390×844。原控件上传两张图、一次保存并按原列表名称重开。两个角色均无需刷新，分别预览公开 12×8 和受保护 16×10 PNG。只读角色无编辑入口。原中国／华东／上海及仓库甲的级联显示保持。 | 同视口与原控件，两张图一次保存后重开，两种角色均无需刷新预览。只读角色无编辑入口。 |
| MySQL 独立读回 | 两条活动文件引用与实际对象一致，两个会话撤销，活动数为零。三个原级联物理字段和记录名称保持。 | 共库两条活动引用，备用库零表。两个会话撤销，活动数为零。 |
| 匿名访问 | 公开地址读取 313 字节 PNG，摘要匹配。受保护地址返回 HTTP 401，无图片字节。 | 公开地址同样校验 313 字节与摘要。受保护地址返回 HTTP 200／业务码 500，无图片字节。 |
| S3 与回收 | 新 SDK 请求分别核对 313／484 字节和 SHA-256，按准确清单逐项删除，桶空后删除。独立核清专属库、账号、所有权、Redis、S3 和回环端口。 | 同口径核对两张图与逐项回收，两个独占库、账号及其余资源独立核清。 |

合并 V548、V549、V550，平台分库、平台共库、独立生成应用均有同一产品修复后的移动 Web 双 PNG 与双普通角色证据。此专项关闭上述固定用例，文件类型、桌面与移动 Web 总体验收和最终 CI 继续由 [项目进度](../project-progress.md) 跟踪。
