## 统一结构合同

普通冗余实体表的 `MultiSelectPage`／`MultiCheckBoxDatabase` 仅声明物理字符串 `_ids` 时，关系存储计划补出固定名称数组缓存。名称沿原 `前缀_名称字段复数` 规则；根定义 `nameField=id` 不补名称。缓存为可空长文本，保存 JSON 数组，稳定 ID 来自表／来源／列名的确定性摘要。

结构预览、SqlRowStore、实体及生成查询从同一扩展入口读取列定义，不回写 config_column，不新增页面字段。页级目标或名称覆盖不能改变物理结构；完整生成仍逐用途证明目标类型、授权、范围及缓存路径，不因自动有列而开放未知关系。

显式同名列始终优先，包括大小写冲突、虚拟、错误类型及另有用途的业务列；错误配置继续拒绝。输入元数据不能声明保留的自动列 ID。非冗余、全局、功能／视图、虚拟或联接来源不自动增加物理缓存。原账号／角色／后台安全关系继续专用协调器，不为 yz_manager 增加角色名称物理列。

## 原页面与事务

- 原弹层、复选、全选、列表、布局、样式和接口保持。只为本页已开放来源补 JSON 数组 VO；来源隐藏时不下发自动名称，显式隐藏名称列也不因此获得读取。
- 缓存不进入可写 DTO。原页面整 entity 回传的自动名称仅作白名单回显剥离；服务端按真实候选重算。省略、null、空数组及精确字符串 ID 沿原合同。
- 新增、复制、所选 ID 和相关父／表单依赖触发时，复用同一 Service 事务、目标当前锁与文件引用事务。手写 partial 修改缓存或依赖仍需登记提交字段，登记缓存变化也重新派生，不信任手拼名称。
- 原多选名称搜索使用同一受管物理数组与元素谓词；自动缓存不新增搜索控件，数据库复选继续原成员选择筛选。

## 跟进顺序与尚未完成范围

已有正确显式缓存列无需新增 DDL。本次支持原先缺少辅助列的配置时，先预览结构差异，审核新增可空长文本列，明确执行并核验，再正规生成／同步运行时；禁止启动自动改表。新空库可在显式安装计划中创建缓存列。保留手写 partial 和私有配置，重新生成不能覆盖它们。
