# V885 公开 Full 的 bigint 逻辑父级 Excel

2026-11-10。以 ffcd80d3 和本次生成门禁改动为固定源码，MySQL 公开 Full 支持三级关系键均为 bigint 的逻辑父范围。适用条件为普通非冗余来源、一条三级级联、一个链内逻辑父字段，目标沿用独立物理关系。已有字符串 ID 组合继续适用。混合类型、全局和派生目标沿各自验收范围处理。

| 核对项 | 实测结果 |
| --- | --- |
| 公开生成和安装 | 36 项生成门禁通过，含新增的六种父级与导入导出组合。原 SheetJS 工作簿往返两项通过。两次公开 Full 生成的 729 份文件逐字一致，69 份 Production 宿主文件严格编译。两轮独占 MySQL 均通过空库预览 16 项、显式应用、安全初始化和重复预览零差异。 |
| 原协议与存储 | 根、中、末三级均走原导入路径。按物理文本首列覆盖三次，跨父同名各自命中，原主键不变；追加模式三次各新增一行。末级继续从请求读取固定父键，导入表头省略级联列。MySQL 确认三列均为 bigint，根、中物理槽为空、末级保留准确 ID、来源无冗余名称。原分页回传超出 JavaScript 安全整数范围的字符串 ID，与独立 MySQL 逐值一致。 |
