# 非冗余 selfTree 固定合同

本批接通非冗余来源表的固定自树关系。原页面、生成模板、级联组件的模板和样式保持；后端适配原节点对象、候选、路径、保存和 Excel 接口。B18 是汇总项，完整浏览器、来源父范围和更多组合仍按进度表分别验收。

## 存储和读取

- `tree_id` 为物理字符串／int64，只保存所选节点；`tree_name` 为只读派生属性，不进入数据库列、写 DTO 或可写字段。显式名称保持归属，缺省名称以稳定内部 ID 展开，不新建元数据行。
- 名称、父键均为已发布普通树表的非凭据物理标量；名称为字符串，父键为字符串／int64。目标必须有唯一、无父参数的可读页；项目、软删及固定物理条件作用于每个祖先。未知来源、重复声明、冲突目标、虚拟名称、派生范围继续拒绝。
- SQL 先读取来源授权范围中的物理所选 ID，分页后在同一读取快照批量解析图。叶子名称和 `treeIdDisplayText` 来自同一完整路径。失效、孤儿、循环或隐藏祖先只清空展示，保留原所选 ID，不丢来源行或回传部分路径。
- 名称单独授权时，所选 ID 只作私有读取依赖，不因此进入 VO；未授权完整路径也不附加 DisplayText。名称单独导出同样经过图校验，不增加 ID 表头。
- SQL 阶段的树名称占位只允许显式的内部延期图投影用途，普通读取编译不能静默以 NULL 代替名称。树名称作为筛选、默认／请求排序、精确匹配或跨表派生用途尚未证明，明确拒绝。

## 原筛选和事务

原筛选对象只解释所选节点 ID，名称不能成为匹配依据。精确／自身及后代集合在 SQL 分页、count、统计和导出之前生成，不能先分页再在内存剔除。读取快照覆盖来源和图，不把来源查询权等同于独立目标列表权。

候选和主动重新选择要求来源及目标对应动作；保存省略关系字段时不借机要求重新选择。普通新增、修改、复制及导入共用 Service 事务、当前目标／祖先行锁和最终存储校验，写后回执通过私有当前读返回，HTTP 没有 currentRead 或免授权开关。名称长度约束只作用于冗余物理列，非冗余派生显示不受原名称列长度限制。

同表后端已复验实际存储后的图和范围：自指／造环、隐藏祖先、64 层及后代深度、手写改父、数据库字符比较／金额舍入、非严格模式 ID 截断、尾部故障回滚及锁保持。它不等于同表完整应用包已经验收。非冗余实时回显也不等于已实现向冗余消费者的名称传播（B21）。

## Excel 与原页面

导入继续使用根至叶完整路径、逐层唯一反查和同事务锁；省略、null、空值及原覆盖策略分别保持。只授来源 import 时不另借 create/update 或目标 list。第二行坏路径回滚整批。导出真实 XLSX 使用当前完整路径；不可无损表示或失效路径明确拒绝，名称单列在路径失效时为空。

原表单继续回传整份实体，名称／DisplayText 可以回显。C# HTTP 边界剥离这些只读字段，严格 DTO、Mapper 和物理结构只接受真实可写 ID。没有通过改前端提交方式规避后端兼容。

实际挂载原生成详情和原级联组件时复现 Vue3 的 `$set is not a function`。仅将层级数组改为 splice、已有值属性直接赋值；组件 template/style 字节不变，生成模板未改。FrontendPackager 直接下发同一原组件，避免修平台副本而遗漏生成包。

## 完整包边界

完整包先开放“非冗余来源＋独立普通冗余目标树”的固定子集：字符串物理名称、两种所选 ID／父键、显式或自动只读名称、物理固定范围。来源和目标均须明确发布到包内项目／后台。

同表、来源父参数、其它关系控件混合、非冗余目标完整宿主、派生／非字符串名称、全局树、复杂名称联接和混合传播仍保留各自门槛。supportedControlSubsets 明确这些限制，不能只凭生成成功宣布全部级联可用。
