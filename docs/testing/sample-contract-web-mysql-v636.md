# V636 合同样板正式 MySQL 复验

2026-11-08。Server-200 固定独占 MySQL 与带认证的 Redis，Production Full 应用，源码 `ee015a97`。2863 份源码、156 份正式执行器文件及 973 份完整包文件逐字固定。严格构建及准备与租约回归 13 项通过。正式用例 1 项通过，零失败、零跳过，用例耗时约 68 秒。

| 核对项 | 实测结果 |
| --- | --- |
| 空库和身份 | 普通启动及结构预览保持空库，随后显式建表、初始化并用真实 Web 密码登录。普通角色只有按钮权限，无页面详情读取权限。撤回预览权限后再次调用被拒绝。 |
| 原按钮与直接 Web | 先预览，再改名。同一旧摘要经原中央按钮及直接处理接口均返回 HTTP 200／R500 和重新查询、预览提示。比对请求前后合同、关联业务表和附件引用快照，保持一致。受控的负金额规则失败撤销首笔真实更新。 |
| OAuth 和真实 CLI | 原三个动作可发现并完成设备授权。过期摘要返回 HTTP 409／`YZP_CONFLICT`，任务回读为 `unknown`。故障事务回读恢复，成功动作回读为 `applied`，重复请求编号被拒绝。 |
| 双宿主与重启 | 持有原按钮租约时，两宿主均拒绝，Agent 任务回读为 `unknown`。释放后两宿主恢复。验证 CLI 注销与再次批准、Web 与 Agent 经过宿主重启、最终撤权。 |
| 独立 MySQL 与附件 | 新连接读回 1 个客户、3 个合同、3 条有效文件引用。两个合同已处理，一个仍待处理，3 个合同金额仍为 10。真实受保护下载与原文件字节一致。 |
| 资源回收 | 独立 SSH 及 MySQL 核对同轮库、账号和归属记录均不存在。Redis 容器、配置、回环转发、CLI 临时凭据与合成文件已核零。 |
