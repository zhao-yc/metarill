# 跨表链包含来源表时的最终状态

保留原页面、样式、控件、候选/路径POST及保存接口。本批接入普通冗余固定链中来源表恰好参与一个目标层位的保存；根、中、末级均由元数据生成。来源重复参与多个层位、多个级联共享辅助字段等仍明确拒绝，不把本批范围扩称整个跨表控件已完成。

## 写前准备与写后核验

创建、修改、复制沿原Service事务、手写BeforeSave、写守卫及正常Mapper。已有来源行更新时，私有路径工厂可用本次已授权实体的名称与父键准备各级值，避免读取旧行误算自身名称。该覆盖不进入HTTP请求、候选或独立路径，也不以内存比较决定SQL范围。

正常一次Mapper写入后、通知前，以当前读重新取得实际来源存储及逐级路径，继续应用真实Actor、项目、软删和固定目标页条件；没有临时写入或修复DML。已存各级ID、名称及身份范围须与准备值保持；重选/复制还须与最终路径名称一致。存储截断、触发器改写或最终路径/范围不成立时整笔回滚。新建不能引用本次尚不存在的新自身。

来源名称、目标父键、目标Scope及固定条件字段编译为图依赖。只改依赖而省略级联ID时，复核实际路径但不顺便刷新已存名称；原crossTable显示仍拼接已存名称。父键变化同时影响已存祖先ID时，需通过原明确选择形成一致路径，不能静默提交错误组合。

数据库字符排序、DECIMAL舍入和NULL条件由最终SQL判断。测试中0.014落为0.01后范围失效必须回滚；0.015落为0.02可保存。普通冗余保存回显仍保留原实体值0.015，本批不擅自改为全面重读响应；独立会话直接检查实际存储为0.02，不能把回显值冒充库内值。

## 权限与事务

非空重选沿原各级目标list要求，清空无需新增目标list权限；依赖复核保留数据范围，不额外要求目标list。内部导入动作继续通过私有参数传递，不能由请求伪造。请求加入creating等私有标志仍按未知字段拒绝。

各级当前读和来源更新锁留在原事务直到通知结束；目标锁验证使用独立连接UPDATE取得1205，随后释放原操作，没有新增观测权限。校验失败不得进入通知；通知尾部异常也回滚原写入。
