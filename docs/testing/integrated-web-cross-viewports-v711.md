# V711 平台移动 Web 与独立应用桌面 Web

2026-11-09。以固定产品 cfdfb2fe 的平台、独立 Full Linux 包及原 H5 在 Server-200 实测，逐份独立核对 311 份载荷。平台 500 份、Full 389 份前端源文件与已验收的 H5 构建输入逐字一致。与 [V710 平台桌面和独立应用移动 Web](integrated-web-v710.md) 合并，两类应用均有桌面和移动视口的原页面业务证据。

| 界面 | 视口 | 浏览器实测 |
| --- | --- | --- |
| 平台管理端 | 390×844 | 原表单登录、选择 Metarill 工作区、从原「开发 → 表」进入配置列表、列表请求成功及退出 |
| 独立应用普通只读 | 1280×840 | 从原菜单及客户列表的「查看」打开只读详情，无保存或删除入口，正常退出 |
| 独立应用普通编辑 | 1280×840 | 原新增、保存、关闭重开、修改再次读回、删除及退出 |

平台分库、共库及独立应用分别通过显式安装后的表清单与索引核对。独立 MySQL 查询确认平台及 Full 的三次登录均已注销、测试账号零活动 Web 会话、两个普通角色生效、只读记录未变、编辑记录以更新后的值软删除。远端容器、网络、独占数据库和临时数据通过新 SSH 独立核清，本机两条转发关闭。浏览器清理范围限定于本轮两个回环站点。

桌面新增阶段首次定位只查 HTML button，实际 H5 节点为 uni-button。确认列表中没有该样本、浏览器没有业务写请求后，从同一浏览器会话继续并完成全部写入，未重放登录或已完成步骤。

本轮为受控同源 Web 验收。实际发行域名、公开证书、真实 Tiny Cloud 和其余业务按 [首版清单](../mysql-first-release-milestone.md) 独立跟踪。
