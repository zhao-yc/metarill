# R1 共享来源父页的文件引用（B91）

日期：2026-10-27。范围是普通 R1 来源、已证明的固定跨表共享组、五类父页及明确声明的普通／全局目标。页面、样式、原级联与文件组件、原接口和写权限保持原样。

## 实现

- 数据层 `RedundantSharedParents` 在发布时冻结来源实际物理父列、唯一目标角色、完整祖先链、目标页、项目条件、逻辑删除和固定常量；生成器与文件运行时共同使用。坏同伴、变化页覆盖、缓存名称充当父键、未发布身份及未证明全局角色继续拒绝。
- R1 使用来源行已经保存的物理父键。改变另一个末端不能把已有国家父键重新解释成 R0 的稀疏推导值；目标路径仍须存在、满足固定范围且使用规范正整数 ID。
- 文件引用登记、保护读取和删除前核验沿实际父路径执行。写入加入原事务并锁定来源、实际父路径和相关文件；只读沿既有一致快照入口。混合父页同时核对独立 owner 与共享国家身份。
- 元数据计划不保留外部可变目录，字符串／整数键按声明类型读取；后台页选择不代替账号权限。目标候选 list 权限与已绑定文件归属沿既有规则分别检查。
- 完整包必须同时通过共同元数据计划、原有生成／缓存／传播与原前端用途证明；没有取消其它能力门槛。

## 更新与回退

既有普通项目无需改物理父列或导入旧数据。需要本组合的项目应先核对元数据和结构差异，再将生成代码与公共运行时配套更新；原 partial 通过预览／更新流程保护。不能逐个手补页面或把 R1 改成 R0。存量不符合固定父范围的数据应先审查，不能借此次接线自动修正。

回退使用原提交的生成器及配套运行时，保留元数据、物理父值、文件及引用；未执行数据库转换或批量业务数据修复。

收尾冻结 `45f8850b4b1e`／1342 文件仅补充新增测试的 23 处中文注释；逐字移除这些注释后与 303a 原测试相同，所有产品文件逐字不变，最终生成测试项目严格构建 0 警告、0 错误。

文件完整 212／API 完整 83 的执行基线保留为 5c8d；最终文件运行时相对该基线仅改类注释，公共数据编译器相同。生成器另解除已完成组合的文件用途门槛并通过上述 Full 与正反例，本批没有将旧回归冒称新源码全量重跑。
