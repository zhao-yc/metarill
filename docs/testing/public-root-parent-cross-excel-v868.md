# V868 公开 Full 的逻辑根父范围级联 Excel

2026-11-10。基于 V867 的实库证明，在公开包的生成门禁加入逻辑根父范围。条件为 MySQL、普通非冗余来源、单条三层链、各级字符串 ID 和独立物理候选。来源父条件必须绑定该链的根层。公开支持追加导入与列表路径导出。中层和末层父范围、按首列覆盖、详情导出及其它未验组合继续保持原门槛。

| 核对项 | 实测结果 |
| --- | --- |
| 公开生成与原协议 | 公开 FullApplication 正常生成，能力清单报告父范围、路径导入和路径导出。693 份清单文件与包清单独立核对，再生成 694 份逐字一致。与 V867 对照的 20 份 Service、Controller 和原 Vue 页面逐字一致。 |
| 定向回归 | 严格构建下 25 项通过、零失败、零跳过，覆盖既有无父模型、根父正例及中层父、覆盖、详情导出拒绝。首次构建的 xUnit 分析器提示已修正，重复生成与实库用包字节一致。 |
| 空库与实库 | 固定 69 份 Release 宿主，Server-200 独占 MySQL 和 Redis。预览 16 项且保持空库，显式安装后零差异。普通账号执行 15 个真实请求，父范围外路径、私添父键和无效父 ID 返回三个预期 400。跨父末行失败后首行一并回滚。 |
| 实际 XLSX 和稀疏读回 | 分别按两个父范围下载 XLSX，选中 ID 包含两边记录，每份工作簿只含本父记录。原 SheetJS 函数解析并回导父甲三行。独立 MySQL 核对七行物理值及长 ID，逻辑根、中、末级各自只存对应深度的 ID。 |
| 回收 | 独立连接核对专属库、账号、所有权记录、Redis、私有配置及临时存储均已回收。远端 TCP／UDP 与本地转发均核验释放。 |
