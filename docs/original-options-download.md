# 原候选双父与无头导出下载兼容

## 固定双父值

旧 `findNameId<来源字段><列ID>` 数组入口新增可选 `targetParentId`，来源 `parentId` 独立保留。旧数组、原只读 `id` 与新 `/page`、`/selected` 共同调用已编译的 `OptionsScope`：分别核对来源父、目标父的真实记录、项目及软删状态，再执行固定目标页和控件范围。两个页面权限仍各自验证，不接受请求替换表、列、页面、SQL 或项目。显式空 `id` 只返回空数组；任何越界已选 ID 均整体拒绝。数组超过 5000 条继续明确报错，不能返回截断结果。

前端只应使用原页面已有的父上下文，或元数据可证明唯一且可读的目标父外键；多个候选父、隐藏依赖或未实现动态表达式仍是明确能力缺口，不能猜测索引到表的跨层映射。`formParameters` 保留原请求键而不解释任意表达式。本切片只修改后端合同，不更换原 zxz 组件、弹层、布局或事件。

## 原 openUrl 下载

原列表先经认证调用固定页 `initExport`，再用 `utils.openUrl` 打开 `/api/admin/sys/export/export?exportId=...`；新窗口没有 API 认证头。生成 Action 现在明确调用 `IPageExportService.CreateDownloadAsync`，只有通过原页导出授权且有界数据准备成功后才签发此次文件的下载凭证。接口响应仍是原字符串 `res.data`，URL 无变化。

- 凭证为服务端生成的 256 位随机值，只引用当前导出对象，不包含或接受物理路径、SQL、目标表、账号、项目选择参数。
- 无头下载有效期固定为两分钟，且不会长于文件自身 TTL。仅精确 GET/HEAD、唯一 `exportId` 参数、没有任何显式认证头的请求可用；额外动态参数、近似路径和错误动词不属于此例外。
- 显式 `loginStateId` 或 `Authorization` 头（包括空值和无效值）不降级，继续按真实有效账号及项目走原 `OpenAsync`。管理员也不能用别人的账号票据。
- 普通 `CreateAsync` 账号票据不具有无头授权。未实现新发行方法的自定义宿主默认明确拒绝，不能静默把全部历史票据公开。
- 这是短时 bearer 凭证，并非即时会话绑定；持有人在两分钟内可重复下载和 Range 读取，客户端注销不会自动撤销该短凭证。服务重启、TTL 到期或对象缺失后统一拒绝。URL 不应转发或写入业务日志。
- 平台及独立宿主同时接线；仍保留 `private, no-store`、`nosniff`，新增 `Referrer-Policy: no-referrer`，私有存储目录不作为静态目录发布。

## 验收边界

导出单元测试覆盖明确发行、普通票据拒绝、两分钟到期、较短文件 TTL、重启、未知票据、取消、账号/项目隔离、认证头和方法/查询窄例外。实际生成的独立宿主在 Server-200 随机独占表验证 `initExport`、原 URL 无头下载、无效认证头拒绝及超限不截断；仅清理本轮随机表。独立包纯 HTTP 测试另覆盖 Range、注销后的带头拒绝及短凭证仍可完成下载的明确语义。平台 HTTP 测试使用标准再生成的 demo 产物，验证完整导入/导出和同一下载边界，产物不手写、不随本切片提交。

关系导出目标页授权与独立目标父读取是另一个已证后端缺口，本切片不把下载接通当成该能力已经验收；紧接应复用已编译目标授权与 `OptionsScope` 修复。原页面完整浏览器、真机和首次安装也不由这些测试替代。
