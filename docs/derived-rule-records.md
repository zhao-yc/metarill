# 派生字段记录规则接线（C24，2026-10-29）

起点为 C21／C22／C23 的受限规则与真实生成记录合同。此前实体的非物理属性虽然存在，但普通 Mapper 不装载它们，默认 null 不能作为可写证据。本项让非冗余页面的必要派生规则值由实际固定读取计划装载；未装载仍明确拒绝，不允许客户端回显或规则表达式任意读取数据库。

## 读取与事务边界

- 生成时仅收集本页普通 Agent 更新／删除／复制只读条件、显式业务按钮显示条件及 VisibleWhenWritable 条件实际使用的派生根字段。复用既有非冗余编译器，物理实体、逻辑父范围、项目隔离、固定条件和当前动作的精确管理依赖全部预先证明；不增加 HTTP 可读列或借用页面 query 权限。
- 标量值来自一条有界固定查询，无 COUNT。多值名称沿用原读取器的分批补名，相关查询加入同一个 RR 读取快照；不把多条 SQL 宣称为单 SQL，也不声称其性能已等于旧实现。
- Agent 普通记录写仍在任务创建前检查；显式 Agent 动作与原 Web 中央按钮入口读取相同的服务端原记录。记录规则不消费客户端提交的新派生值。
- 业务事务中的 LockButtonRecord 保留原根记录 FOR UPDATE 和当前按钮授权，然后在同一事务补取派生值及名称当前读。没有真实写事务时拒绝；没有把原排他锁替换为共享锁。FreeSql 根查询与后续固定读取的真实 MySQL 并发行为仍需正式验收。
- 新实体显式实现 IGeneratedRuleRecord，内部一次性复制派生装载字典，JSON 值克隆；已装载 null 与字段缺失分开。该状态不是可反序列化属性，不进入接口响应。实体公开派生属性被修改也不能覆盖已捕获规则值；普通未装载实体仍拒绝使用 IsIgnore 默认值。

## 交付与再生成

元数据和既有页面、样式、交互、公开路由及请求／响应合同不变。本轮无需 SQL 或元数据迁移。生成项目应由原在线本地助手协调同步运行时及再生成后端；更新器候选必须带齐新 Core 合同和 Agent 消费代码，不能同时删除源码与归属清单来伪造完整包。手写 partial 继续保护，不能手改生成实体补装载状态。

已有无派生记录规则的页面保持原生成路径。回退时必须成套回退生成代码及同版运行时，不手动伪造装载字典；旧实体缺少证明时保持拒绝。
