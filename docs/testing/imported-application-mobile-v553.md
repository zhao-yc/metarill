# V553 反向导入独立应用移动 Web 验收

2026-11-08。以 `d50ed43e6853` 的公开 Full 生成器重建有项目列和无项目列两种独立应用。元数据和原始建表定义取自 V297 已通过原平台反查、保存及生成的两个样本，并核对原留存清单。此次重新执行的是生成、结构同步和应用验收，原平台反查与配置保存沿用 A14 已有证据。使用原 uni-app 模板，验收副本只配置临时回环地址与 DCloud AppID。

| 项目 | 结果 |
| --- | --- |
| 生成和构建 | 两包各核对 655 项生成清单。每包前端组件和路由检查通过，HBuilderX 5.34.2026102909 各输出 50 个 Web 文件。两个独立 Production 宿主均通过严格 Release 发布，各 69 个文件。 |
| 移动浏览器 | ego-browser 实测 390×844。每个模型通过原登录、菜单、移动列表、详情和复制确认。各发出两次登录、一次复制和两次退出。复制后列表显示原行与复制行。 |
| 普通账号 | 真实普通角色能请求列表和详情，页面不出现新增、保存、删除、复制或可编辑文本输入。仅撤销页面查询权，保留导航授权。独立真实会话再请求列表得到 HTTP 403，原浏览器会话完整刷新后菜单和业务数据均消失。 |
| MySQL 读回 | 各核对原两行保持、只新增一条复制行、新主键超出 JavaScript 安全整数范围、源表结构摘要保持。含项目列模型验证跨项目行不可见且复制件写入原项目。无项目列模型可查询同一源表的第二条记录。各三条会话已注销、零活跃。 |
| 回收 | 两次使用独占双库、临时账号及 Redis。分别从独立连接核对库、账号和所有权记录消失，Redis 容器与私有目录消失、转发端口释放。完成轮按两个精确来源清理浏览器临时状态并结束验收空间。 |

准备轮因引用已关闭的浏览器空间提前结束，未执行业务请求。完成轮有项目列模型在复制和只读检查后发现，仅改哈希路径未发出新的菜单请求。恢复同一浏览器空间后使用不同查询参数触发完整重载，实际验证新菜单请求并保留原复制请求计数。无项目列模型直接采用完整重载流程。两处均属验收脚本修正。

本记录覆盖移动 Web 复制、只读与同会话撤权。桌面 CRUD、Production 重启沿用 V293、V294 和 V297。小程序与 App 单独跟踪后续兼容性验收，首版其余数据库组合和整体性能仍按 [MySQL 首版节点](../mysql-first-release-milestone.md) 跟踪。
