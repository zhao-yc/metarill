# V443 原平台配置页 Web 验收

2026-11-07，以 `ff7b780d` 为起点，使用 HBuilderX 5.34.2026102909 构建的原管理端、Metarill Production API 和 Server-200 的独占 MySQL 平台库、业务库及 Redis。真实后台管理员通过原登录页登录并选择项目。两个合成配置页共用 5,014 个有效候选，另设一个已删除候选。初始选中项位于后页，目标 ID 超过 JavaScript 安全整数范围。

## 原表单兼容

首轮桌面页成功加载 50、100 条候选，并以 `%_'` 精确找到合成目标。点击保存后，原表单把长度只有两位的 `page_size` 拦为超长，未发送更新。原 Java 的三个配置页面 VO 使用字符串，C# 原先将同一字段作为 JSON 数字返回。

生成器只在原平台 `config_page` 的三个固定配置页 VO 中按字符串写出 `pageSize`。实体、MySQL 整数列和写入 DTO 保留整数，写入继续接收数字字符串和显式空值，省略字段时保持原值。复验复用同一份原 Web 产物。
