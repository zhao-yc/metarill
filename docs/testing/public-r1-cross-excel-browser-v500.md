## 构建、复验与回收

使用 `D:\HBuilderX\cli.exe publish web --project 临时前端绝对路径 --webHosting false`。首次 CLI 返回后实际日志显示缺少 cap-widget。按公开包锁文件执行 `npm ci --offline --ignore-scripts` 后重新导出，检查成功日志与 index.html。Web 产物使用本机回环代理供 ego-browser 访问。

Server-200 独占 MySQL 8.4.11 和 Redis。首轮 `3738802071dd4fd4` 完成显式安装与种子，测试执行器的 HTTP 就绪检查错误使用上下文管理器，未进入浏览器。该轮独立清理通过后修正执行器。复验 `17efbaa64c8b07e7` 通过，显式应用 44 张表，结构复查零差异。桌面截图首试受窗口最小化影响，恢复同一浏览器窗口后留图，未重放导入。移动轮在页面切换后重新固定视口，再按实际原菜单和共享祖先状态定位。

两轮均在新的 SSH 连接核对库、账号、所有权记录、Redis 容器和配置不存在。本机宿主、代理和转发已退出，回环端口释放，临时凭据已删除。仅清理本轮回环站点存储，ego 空间与临时 HBuilderX 工程已关闭。正式回执和截图保留。

原移动列表没有 Excel 按钮。复验截图仍可见窄视口附件按钮右侧裁切，属于 V424 已记录的原布局问题。本次关闭桌面 Excel 与移动级联保存读回这两项。附件操作、其他模型和角色的完整双视口矩阵、并发及性能继续分别验收。
