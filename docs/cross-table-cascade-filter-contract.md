# 原跨表级联来源筛选

原JavaService的crossTable分支从末级向前找最深非空ID，对来源实体对应的已存级ID列执行eq；不反查目标，不展开后代。C#按此协议接线，原uni-app页面、组件、模板、布局、样式和正文不变。

## 固定计划及精确输入

生成器在全局/本页定义、物理辅助列和普通冗余固定链被证明后，标记该页跨表筛选并生成私有静态键计划。HTTP仍在原叶子键下提交层级对象，例如filters.placeId.countryId；各级名称只回显。只采用最深非空ID，不采用祖先和名称不会增加谓词或被用作SQL。未知/重复成员、已采用ID的非标量、注入、负值、浮点或int64越界拒绝；空对象/null/空白沿原空筛选，通用旧请求边界仍把空数组作为无筛选。

字符串来源列保留ID原文，包括前导零；整数来源列精确解析为long，不经过浮点。所有来源列在生成期冻结，所有值由FreeSql表达式参数绑定；客户端不能提供列、表、SQL、项目或匹配模式。原独立外层辅助字段键没有因本批自动开放。

纯跨表筛选是同步来源eq，静态键计划在类型初始化时构造，不在每个请求解释元数据；混合selfTree页仍保留其异步目标图边界。原模型/DTO/页面配置不被回写。

## 范围、历史数据与共用入口

page/count/statistics和page中的selectedIds交集共用同一Query；type=2确认继续按原固定来源页完整回读并保留请求顺序，不把确认正文扩大为新筛选接口。来源Actor、项目、软删除、页面常量和父范围始终先约束Query；来源撤权仍拒绝。目标list撤权、当前目标隐藏/删除/改名不改变历史已存ID筛选，不额外查询目标。

本批真实XLSX沿明确的标量列表投影验证相同筛选，实际下载并打开核行；使用验收专用下载路由解析内容，不替代正式下载鉴权。跨表路径单元格的导入导出仍待完成，不能把标量导出证据当作该功能完成。
