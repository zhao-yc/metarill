# V864 固定独立 Full 的真实 OAuth Agent MCP 边界

2026-11-10。使用产品提交 86775982 生成的公开 FullApplication，逐份核对 661 个生成文件和 51 个 Release 宿主文件。Server-200 独占 MySQL 空库和 Redis。首次预览 13 项，显式安装及安全初始化后零差异。

| 核对项 | 实测结果 |
| --- | --- |
| 真实设备授权 | 原密码登录后台所有者，经原设备码、查看、批准和令牌兑换签发 Agent。服务端签发项目、持久授权项目及已消费标记一致。 |
| 正常能力与 MCP 的边界 | 同一个授权在常规 Agent 能力目录有新建、更新和删除能力。通过真实 MCP 握手只枚举当前页的列表、详情。两项读取结构与实际列表、详情通过，读取保留同一长字符串 ID。 |
| 写入拒绝与隔离 | 创建、更新、删除、复制的结构及显式确认调用各四项全部拒绝。未发布页也拒绝。伪造项目头返回 HTTP 401，同一令牌随后仍能在获准项目读取。 |
| 撤销与清理 | 原 Web 撤销授权后旧 Agent 令牌返回 HTTP 401。三次独立 MySQL 读回核对样本未变、任务账本为零、授权已撤销和两个会话注销。独占数据库、账号、所有权、Redis、私有配置及转发经新连接核清。 |

30 个 HTTP 请求包括 6 次成功工具调用、9 次预期工具拒绝和 2 次预期 HTTP 401。前置检查将会话核验的分隔符对齐为 SQL 结果的逗号，随后才启动实库。固定包与产品代码保持原版本。

本轮使用单项目公开独立包及真实 OAuth 协议。受信验证地址使用合成配置。平台双发布目录及实际浏览器授权操作分别按对应场景验收。独立包普通 Web 权限及 DTO 写入证据见 [V863](fixed-standalone-mcp-schema-v863.md)。
