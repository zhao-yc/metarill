# V683 固定候选桌面管理端与独立应用移动 Web

2026-11-09。用 `c2eddf71` 的两份 [固定 Linux 发行包](fixed-mysql-release-candidate-v676-v678.md) 和两份 H5 在 Server-200 的独占 MySQL 8.4.11、Redis、Caddy 上验收。平台 H5 使用 V682 原产物。独立应用 H5 从同一份 Full 发行包重新导出，在临时工程中使用已确认的 AppID 及本轮同源回环 API 地址。相对 V682 独立 H5 的 389 份构建输入，仅 API 地址配置一处不同。原页面、标题和操作沿用。进入浏览器前通过 HTTP 核对两个网关实际返回对应首页。

固定 311 份载荷在运行前后逐份核对，含 98 份后端宿主、5 份元数据及构建配置、平台 H5 156 份和独立应用 H5 52 份。平台分库、共库及独立应用的实际表数为 24／13、25、13，独立应用结构预览保持空库，显式安装后全表与已发布目录一致。

| 界面 | 视口 | 浏览器实测 |
| --- | --- | --- |
| 平台管理端 | 1280×840 | 原表单登录、选择 Metarill 项目、加载原菜单、退出 |
| 独立应用普通只读 | 390×844 | 登录、从原菜单打开客户详情，字段只读且无保存／删除入口、退出 |
| 独立应用普通编辑 | 390×844 | 登录、原客户新增、重开读回、更新、再次重开、删除及退出 |

跨站后浏览器工具重置了模拟尺寸，首次等待 390 像素菜单失败。同一任务空间恢复 390×844 后续验并记录实际视口。MySQL 独立检查平台及独立应用的三份会话均已注销、两个普通角色生效、只读样本保持、编辑记录的最终内容与软删一致。浏览器清理两个独占站点并关闭本轮任务空间。独立新 SSH 核对本轮临时库、账号、容器、网络、文件及配置已回收，本机两条转发关闭。

本轮为固定发行包的受控同源 Web 验收。实际发行域名、公开证书、更多角色组合及真实 Tiny Cloud 单独跟踪。MySQL 首版的性能阻塞见 [V681 正式结果](fixed-release-maintenance-copy-v681.md)。
