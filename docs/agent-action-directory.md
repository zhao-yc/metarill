# 显式 Agent 业务动作目录与记录门禁

2026-10-28，C18 的离线子集；三个原样板业务流程及正式调用验收仍待完成。

## 发布条件

只有真实注册的 MVC 方法显式标注 `AgentActionAttribute(id,name,buttonId)` 才能成为 `action:标识` 能力。该方法必须只有一个 POST 路由、一个严格对象 JSON DTO；禁止直接使用 Entity、字典、集合或原始 `JsonElement` 作为动作正文。声明本身不替代 Web 入口与 Service 的真实鉴权。

宿主冻结按钮、页面及表的归属。按钮必须是原 `actionType=1`、同项目/同页面/同表，并且 `sql` 配置与真实路由在移除 `/api` 后逐字一致；外链、查询片段、向上路径、重复按钮及重复能力标识不会自动取第一条。未实现的方法、无效声明和没有生成记录入口的普通表动作不进入目录。标准生成能力继续保留原协议。

确认来自原按钮 `isNeedConfirm` / `confirmMsg`。普通 `Normal` 与 `AlwaysVisible` 只检查自身按钮权限，不能统一增加页面 query/update 门槛。`VisibleWhenWritable` 额外检查实际页面更新权限；本批仅开放无只读表达式的子集。非空只读表达式及其它未证明的可见规则先从业务目录排除，仍是未完成项，不能宣称已兼容全部按钮可见规则。

单能力详情和调用只检查目标能力的当前权限；目录列表逐项过滤。平台与独立应用原有无权异常均进入过滤，旧授权器不支持按钮时不会退化为页面权限。

## 真实请求与记录范围

生成器为有业务按钮的控制器增加 `GeneratedPageAccessAttribute`，固定页ID、表ID、真实实体、Service及 `ReadButtonRecord{pageId}Async`。记录读取入口仍执行已有项目/父/页面固定条件、逻辑删除及该按钮自己的精确数据范围。本批未放宽这些查询，也未增加允许客户端挑选范围的参数。

普通表动作的 `RecordIdField` 默认 `id`，只能唯一绑定到实际 DTO JSON 属性、明确的路径参数或查询参数。标识与父上下文只接受整数/字符串；同名多来源、重复查询值和非正整数记录ID均在业务前拒绝。JSON 属性别名保留；请求按宿主 MVC 相同 JSON 配置反序列化，随后核对实际绑定名，避免校验记录与控制器读取记录不同。schema 同时声明必要的正文记录ID与父上下文。

调用前再次验证能力与真实 MVC 方法/路由/HTTP 方法一致，使用当前 scope 内唯一的生成 Service 执行实体读取。缺少/重复 Service、缺少发布绑定、实体为空或当前权限不足都不能作为记录证明。功能表沿用无记录范围的专用分支；本批未将该分支的离线实现写成完整实库验收。

该门禁发生在台账登记前，不能替代业务外层事务中的锁定、当前权限复核、摘要复算及标准 Service 写入。原三个手写流程仍需补齐并正式验证。

## 确认与任务分开

标准读取仍不登记写任务。所有 `operation=action` 的真实调用均必须提供请求UUID并先登记任务，包括原 preview 这种无需确认的动作；需要确认的按钮另要求明确确认头。输入、能力、记录或确认拒绝时不登记任务、不进入业务。结果不确定时沿用原任务查询/回读提示及禁止自动重发规则。

CLI 现有实现已经为业务动作分配请求编号，不需要改变用户命令。调用服务端 preview 动作会执行请求并登记任务；CLI 的本地 `--preview` 仍只输出拟发送内容，不执行接口、不登记任务。本批只增加真实回环 HTTP 回归来固定这个区别。

## 跟进与验收边界

- 首次接入和已有应用跟进均需要同步本批 Core/Agent 运行时并再生成有按钮的 Controller，补齐手写 Controller/DTO/Business；生成标记与对应 Service 必须成套发布。旧包缺少标记时不会自动开放动作。
- 本批不需要修改元数据、数据库结构或回填，不修改前端页面、样式、交互及手写 partial；重新生成仍使用原保护机制。
- 离线目录/严格参数/台账验证使用真实 MVC 发现、中间件及任务存储，只有实体读取结果与数据库传输使用测试替身；这不能代替实际生成SQL、数据库唯一索引、事务锁或并发验收。生成模块另直接编译并执行真实物理/非冗余/派生记录查询，检查生成绑定与真实SQL。
- 原 preview/complete/rollback 手写流程、摘要的跨语言一致性、真实锁后权限和文件事务、OAuth/CLI 正式业务调用、全部可见规则及跨业务库组合仍待完成。不能把本批目录子集记为 C18 整项完成。
- B98 的独立冻结产品/执行器和租约范围不因本批源码改变；新范围未获授权前不执行，不将旧租约用于新代码或新样本。

验证结果与原始失败记录见同任务的[实施进度表](project-progress.md)及私有 `.local/global-source-20261028/action-directory`。本批无远端对象创建、数据库写入或生产部署。
