# V686 固定候选 MySQL 提交阶段复核

2026-11-09。使用 `c2eddf71` 与 [V685](fixed-write-server-phases-v685.md) 相同的应用镜像、原路由、普通账号、共同索引、存储设备和持久化设置，在新的独占 MySQL 8.4.11 增加服务端阶段与文件等待采集。保持 `sync_binlog=1`、`innodb_flush_log_at_trx_commit=1`。各端请求交错，采集 SQL 在 HTTP 计时窗外执行。记录语句类别、嵌套阶段及等待区间。

8 次首检后共完成 230 个诊断请求。各端 24 次修复逐次验证 132 个缓存值，复制各端 13 对记录的 ID、备注及软删除均独立读回。两端种子前后相同。所有 178 个提交的阶段与等待历史覆盖对应窗口。每笔都匹配到服务端 `waiting for handler commit`，均未匹配到已采集的提交线程直接等待。27 笔提交与后台 InnoDB 文件同步时间重叠。
