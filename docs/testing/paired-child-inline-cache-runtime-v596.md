MySQL 8.4 的当前业务事务已固定父子表结构。独立证明连接核对数据库、实例、账号及直接元数据权限。需要足以查看源表触发器和双方列定义的权限。源表有触发器、CHECK、外键、计算列、自动更新时间或涉及缓存的索引时保持原路径。候选只处理同排序规则的 utf8mb4 VARCHAR，按实际父锁下的值检查缓存列宽度。运行时不会授予额外权限。[MySQL 触发器目录可见性](https://dev.mysql.com/doc/refman/8.4/en/information-schema-triggers-table.html) · [MySQL 库级权限目录](https://dev.mysql.com/doc/refman/8.4/en/information-schema-schema-privileges-table.html)
