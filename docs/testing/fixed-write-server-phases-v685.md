# V685 固定候选原写入的服务端 SQL 分段

2026-11-09。候选 `c2eddf71`、C# 镜像 `b44963c4e907`、Java 镜像 `ecd22231140f`。在 Server-200 使用独占 MySQL 8.4.11，与原测试使用同一镜像、存储设备和持久化参数。确认 `sync_binlog=1`、`innodb_flush_log_at_trx_commit=1`、`innodb_doublewrite=ON`。原共享实例保持原配置。两端按同一普通身份和共同索引，单并发交错发送原 HTTP。

八次原维护预检后，完成 48 次逐次修复和 182 次复制七步请求。每次修复重新置旧并逐值验证 132 个缓存值。复制每端 13 对合成记录，源记录与复制件的不同备注、独立 ID 和两条软删除均经物理读回。前后种子相同。每个请求在计时前后读取独占实例的 Performance Schema，确认历史范围覆盖完整窗口，仅归档语句类型及数值时间。按时间区间合并重叠事件，防止一条多语句命令的嵌套范围重复累计。
