# 自关联级联候选与路径读取

本批补齐原 `yzp-cascade-tree` 的自关联树读取入口，保留组件、页面、样式、事件及请求结构。它是完整级联能力的一个切片，不能据此宣布写入、筛选或完整应用包可用。

## 原协议

生成页继续使用 `POST /api/admin/auto/{表}/{页}/cascadeTreeOptions{字段ID}`，正文为 `levelKey: selfTree-层号` 和 `selectedPath: { parentId }`；根级parentId为空文本。响应为原 `R.data` 数组，每项保留字符串 `id/value`、`name/text` 和 `hasChildren`。

路径地址仍为 `cascadeTreePath{字段ID}`，正文只传 `leafId`，响应为 `path: [{id,name}]` 与 `displayText`。空叶子返回空路径，但仍检查权限。ID数字不经过浮点转换，兼容高位字符串ID；未知请求字段、重复parentId、非标量/非正整数及无效层号拒绝。

## 固定编译与查询

元数据及非空页级明细覆盖决定固定目标；读取不解释客户端表名、排序或SQL。当前仅接 `selfTree`、普通冗余物理表、主键id、字符串名称、字符串/int64父列及blank根模式。目标需要唯一且名称/父列可读、无父参数的普通页面；来源父参数、非冗余、跨表、特殊安全服务、歧义目标及额外查询范围继续留明确缺口，不回退宽查询。

来源页和固定目标页均要求list权限，Service复核真实Actor。每次查询使用目标页固定常量、真实项目及软删范围，未明确全局的目标必须有项目列。候选和每跳路径只读取id/name/parent三列，hasChildren仅投影父键；隐藏业务列及条件依赖不进响应。

同一次读取事务内逐层查询；非根候选先确认完整可读祖先链。不存在、越权、软删、被页条件排除的祖先、循环或超过64层均整体拒绝。候选只读当前层，最多取501项检测溢出；当前切片单层超过500项明确报错，不返回截断列表。此上限仍是未完成兼容边界，不能把大树、全部并发或性能标为验收完成。
