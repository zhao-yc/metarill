# V927–V928 当前发行候选分库恢复

2026-11-10。以 V897 实际平台 ZIP 的 3,058 份源码为依据，复用 V925 严格构建的 Windows x64 Production 宿主，产品提交为 `68af5319`。逐份核对 51 个宿主文件、11 份与历史恢复夹具一致的元数据以及五个执行辅助文件。两组顺序在 Server-200 运行，分别使用独占合成源和目标。

| 轮次 | 实测结果 |
| --- | --- |
| V927 跨实例本地附件 | 两个 MySQL 8.4.11 实例的 UUID 不同。源停止写入后，从平台 24 表、业务 13 表恢复至目标空库，核对六类逻辑目录和数据。隐藏源附件路径后，原接口可读取 35 字节受保护附件和 32 字节公开附件。匿名读受保护文件、无页面权限及普通只读账号写入均被拒绝。 |
| V927 旧会话和授权 | 在隔离目标确认旧 Web 和 OAuth 凭据可用后执行处置。故意传入错误计数时整笔回滚，正确计数撤销 3 条活动会话及 2 条授权，重复执行为 0／0。旧 Web、Agent 访问、刷新和待批准设备码均拒绝，新登录和 OAuth 签发通过，源数据与授权目录保持原值。 |
| V928 分库 SeaweedFS | 在同一 MySQL 实例以独占四库恢复同样的 24／13 表。源、目标使用各自的账号、Redis 和 SeaweedFS。目标空桶按原键恢复 2 个对象，共 73 字节，独立 SDK 核对库存及 SHA-256。关闭源 S3 后，改变逻辑地址会拒绝两个旧引用。恢复原逻辑地址并使用目标凭据后，公开附件和受保护附件均正常读回，三条 Web 会话注销。 |

两轮共 75 个原 HTTP 请求，V928 的 13 次真实 SDK 操作及 11 项离线检查通过。恢复后的业务文件及引用仍归属业务库。两轮分别从新连接核清独占 MySQL 资源、账号、Redis、SeaweedFS、私有配置、临时快照及八个本机转发端口。

验收覆盖同版 MySQL 跨实例本地附件恢复，以及同实例分库的 SeaweedFS 恢复。跨版本及实际供应商版本桶仍按 [MySQL 首版交付节点](../mysql-first-release-milestone.md) 的证据边界跟踪。
