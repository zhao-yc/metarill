# V556 单步公开上传丢失 S3 写入回执后的回滚

2026-11-08。固定修复前基线 `3174ec55` 和本次文件运行时补丁。原单步公开上传在收到 S3 成功响应后才登记事务回滚清理。若对象已写入且响应丢失，原 HTTP 仍返回业务错误，MySQL 回滚计划，而已写对象缺少清理入口。

单步上传在发送 S3 PUT 前登记回滚，条件创建请求带有私有随机标记。只有数据库确认回滚时才通过 HEAD 核对固定桶、对象键和标记，再用返回的 ETag 发起条件删除。旧对象的字节即使相同，标记不一致也不清理。条件冲突保留对象和原业务错误。Amazon S3 的 HEAD 与条件删除合同见 [HeadObject](https://docs.aws.amazon.com/AmazonS3/latest/API/API_HeadObject.html) 和 [条件删除](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-deletes.html)。
