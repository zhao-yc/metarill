## 复现与实现

V547 中，写者保存并重开详情后，请求无挂起，运行时已记 `hide`，原 uni-app Toast 的 Vue 可见属性为 false。浏览器处于可见状态，过渡类最终已移除，原加载节点仍是 `display:block`，遮罩继续存在。浏览器记录三次 showLoading／hideLoading 配对告警。写者只读刷新后完成两图预览，旧问题保留。

共享请求的 Web 遮罩改为独立持有 DOM 节点。复用 uni-app 原透明遮罩、面板、图标与文字样式。最后一个相关请求结束后直接移除所属节点。独立的提示继续走各自原入口。公共请求的延迟显示、串联、并发、取消和超时规则沿用。生成 Web 应用经现有前端资产装包取同一份运行时。已有部署更新并重新构建 H5。

## V548 验收结果

- 新回归先在原代码中失败，修正后请求专项 35 项、前端全套 365 项及 C# 前端装包 19 项通过。
- 原 390×844 移动 Web 实际显示 140 像素面板、原加载文字和可拦截的透明遮罩。写者上传两张 PNG、保存一次并重开，确认遮罩移除，两个角色均无需刷新即可完成公开 12×8 与受保护 16×10 预览。只读角色无编辑入口，两账号原界面注销。
- 浏览器初轮的保护请求全局计数捕获了并发缩略图读取。确认 12×8 公开图已打开后接续完成，通过实际原图来源、浏览器解码尺寸和点击后的保护读取核验。两次保护预览各新增一个成功读取请求。未重放上传或保存。
- 独立 MySQL 核对业务库两条文件引用、平台库零对应记录和两个会话撤销。匿名公开 PNG 摘要相同，匿名受保护地址无图片字节。两张 S3 对象分别用新 SDK 请求核对摘要和长度，按准确清单逐个回收并核对桶空。双库、账号、所有权、Redis、S3 容器和本机端口均独立核清。
