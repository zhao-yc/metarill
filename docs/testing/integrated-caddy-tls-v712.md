# V712 固定候选双端 Caddy HTTPS

2026-11-09，固定 cfdfb2fe。复用 [V711](integrated-web-cross-viewports-v711.md) 已核对的同一 311 份 Linux 宿主、固定元数据和原 H5 载荷。Server-200 的 MySQL、Redis、Caddy、宿主及测试数据库均为本轮独占。

| 核对项 | 平台和独立 Full 的结果 |
| --- | --- |
| 回环 HTTPS | 两个 Caddy 仅监听各自的 TCP 回环端口。各自使用正确主机名、TLS 1.3 和显式信任的短期证书，实际服务端叶证书摘要匹配。默认信任和错误主机名均被拒绝。 |
| 静态和反代 | 原首页及 JavaScript 摘要一致，未知 API 与后端直连响应逐字一致，平台为 HTTP 404，独立 Full 为 HTTP 401，请求私有配置同名路径只得到静态首页。 |
| 原认证与业务 | HTTPS 同源原 API 拒绝错误密码，正确密码登录后返回原菜单。平台管理员和独立应用普通编辑角色分别完成客户新增、详情、更新、分页、删除及退出，保留字符串 ID 和省略字段与显式 null 的区别。 |
| 数据库核对 | 平台分库、共库及独立应用的显式安装清单分别为 24／13、25、13 表。独立查询确认两份记录软删及两次 Web 会话注销，旧令牌再访问被拒绝。 |
| 测试资源 | 独立新 SSH 核清容器、网络、数据库、临时账号、远端证书及私有文件目录，两个回环端口均释放。短期证书与临时凭据单独私有归档。 |

首轮停在将两端未知 API 一律断言为 HTTP 404 的测试断言。旧资源独立核清后，复验分别对照同一后端直连的实际错误响应及原 H5 回退边界。产品与载荷逐字一致。

本轮为严格命令行 TLS 和真实 API 验收。原浏览器桌面与移动业务见 [V710](integrated-web-v710.md) 和 [V711](integrated-web-cross-viewports-v711.md)。实际发行域名、公开证书链和该环境中的浏览器仍按 [首版签收](../mysql-first-release-milestone.md) 核对。
