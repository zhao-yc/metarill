# V965 同合同明细合并缓存读写的本机 MySQL 复验

2026-11-11。在 Windows 独占回环实例运行 Oracle 签名的 MySQL 8.4.11 免安装包。探针仅替换连接和实例身份核对，仍使用 V960 冻结的数据层 DLL、生成文件及同一批业务断言。运行账号限于本轮合成库，触发器由该私有实例的独立测试管理员安装。请求经过原生成 Controller 与 Service，身份由测试夹具提供。

| 核对项 | 结果 |
| --- | --- |
| 正常八行导入 | 首行沿用原路径，后七行合并为一条 30,142 字符的驱动命令。后七行各有一次父候选读、一次目标缓存锁读和一次物理回执。插入计数合并到锁读，额外独立取计数为零。 |
| 缓存和首错 | 缓存相同、插入后不可见、父候选变化、缓存写后失配、首错后零后续写入、无导入权限拒绝、整批回滚均通过。两种异常复合主键拒绝进入快速路径。 |
| 字符集与边界 | UTF-8 到 latin1 实际赋值保留字节和尾空格。不可表示字符按首行拒绝，批次零写入。短批次与自定义观察者继续通过原回退路径。 |
| 证据与回收 | 17 个生成 HTTP 请求、24 个父候选判定、17 项计划核对及 34 条物理记录通过。从新进程核验专属实例停止、回环端口关闭和独占数据目录消失。 |

MySQL ZIP 已按 Oracle 公布的密钥指纹核验分离签名。 [MySQL 归档签名说明](https://dev.mysql.com/doc/refman/8.4/en/checking-gpg-signature.html)

V960 产品补丁保留在隔离目录。此轮覆盖 Windows 本机 MySQL 的功能验证。Server-200 正式实库和 Java／C# 同条件性能继续验收，当前发行包的性能状态见 [V958](current-release-child-performance-v957-v958.md)。
