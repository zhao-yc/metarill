# V722 固定候选跨实例恢复与会话撤销

2026-11-09。使用产品 `cfdfb2fede0defc7af53d485aa207db834e5cd4c` 严格构建的 51 个 Windows x64 Production 宿主文件。恢复夹具与 V633 的元数据逐字一致，其中客户页包含两列合成附件。两个 MySQL 8.4.11 实例均位于 Server-200，各有独立 UUID、平台库、业务库、账号、Redis 和回环转发。

| 环节 | 结果 |
| --- | --- |
| 停写、导出与恢复 | 源宿主停机后，用源库级账号分别导出平台 24 表和业务 13 表，SQL 在远端进程内传递。目标库级账号导入独占空库。六类结构目录、数据语句及源复导出逐项核对。 |
| 原业务与文件 | 目标使用自己的目录，源附件路径在目标访问期间移开。真实普通只读账号读取客户和受保护附件，匿名可下载公开附件。两份附件字节和 SHA-256 匹配。无权限访问、匿名下载受保护附件和只读写入均被拒绝。 |
| 旧凭据与负例 | 隔离目标复用快照的旧 Web 会话、Agent 访问及刷新。停机后故意给出错误预期，撤销事务在提交前被拒绝，目标活动记录、既有注销时间及重放历史通过新连接读回，源端不变。 |
| 正式撤销与恢复访问 | 事务撤销 3 条活动会话和 2 条授权，重跑为 0／0。旧 Web 会话、Agent 访问、刷新和待批准设备码均被拒绝。新 Web 登录及 OAuth 设备流成功，完成退出和撤销。 |

两端完成 50 个原 HTTP 请求。最终独立 SQL 验证目标活动 Web／Agent 访问会话和可用授权均为零，已有重放记录保留。两套 MySQL、Redis、回环转发、私有目录和合成文件均已清理并独立核验。

本轮覆盖同版本 MySQL 的跨实例、本地文件及活动会话快照恢复。历史 [S3 对象恢复](current-split-s3-backup-restore-v631.md) 与实际发行环境的对象版本另行核对。恢复操作入口见 [MySQL 首版安装与恢复](../mysql-first-release-install.md)。
