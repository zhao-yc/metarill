# 索引工作台与结构同步边界

索引管理沿用`POST /admin/custom/config_table/index_config`与`save_indexes`。读取返回`configTableId/configTableName/tableName/columnOptions/indexes`，新增`detail.revision`及`R.map.revision`；保存发送同一版本（payload revision或X-Metarill-Metadata-Revision请求头），冲突返回业务code=409并保留草稿。宿主注册Scoped `IndexWorkbenchBusiness`，控制器由现有AddControllers发现。

只允许已认证当前项目管理员使用，Agent授权身份不能进入设计保存。读取和保存统一按项目→表→列→索引→从属字段锁序建立事务；先校验完整批次，再进行任何写入。空数组显式清空当前表托管配置，省略/null不代表清空。非空索引ID只能引用当前表托管索引，从属ID不能跨索引移动；新节点由服务端分配。索引名称不区分大小写唯一，类型NORMAL/UNIQUE分别使用yzp_idx_/yzp_uk_前缀，每表最多64个索引，每个索引1至16个字段。字段序号必须为唯一正整数，按其排序后归一为10、20等。方向只接受ASC或DESC声明。

ux_*等非托管配置不在页面编辑集合中，删除或替换托管集合不会触及它们；并发版本仍覆盖表、列、全部索引与从属记录。系统字段同样必须在元数据显式定义，旧UI省略configColumnId时按当前表物理列名映射到真实ID。虚拟字段、联接字段及Title/Tab布局控件不能用于本表物理索引。客户端无法指定项目、审计信息或SQL。

保存成功只表示平台元数据提交；不会连接业务库执行DDL。物理变更必须经过结构同步预览→执行→核验→记录，驱动可连接不等于已验收。首期DDL仅支持ASC：启用的DESC索引在编译预览阶段明确拒绝，不能静默按ASC执行。工作台保留DESC声明供后续适配，但当前不可将其同步为物理降序索引。TEXT/JSON/BLOB、组合键字节长度等数据库约束仍需结构预览与真实目标库核验，不承诺任意声明均可物理建索引。

isEnabled=0不参与目标结构编译；禁用或删除配置不会自动DROP已有物理索引。新增启用索引可以产生ADD INDEX计划；已有同名索引若唯一性或字段顺序不同会拒绝预览，必须单独制定迁移方案。重命名配置可能新增新名索引，旧物理索引仍保留，不应将其误认为物理重命名已完成。当前索引快照未表达方向，降序适配需要同时扩展反查、差异、DDL和真实验收。

普通config_index/config_index_column页面的新增/修改/删除/复制/导入写入口必须由元数据关闭并再生成，不能绕过完整聚合校验。字段删除/改为虚拟或联接字段需要遵守引用一致性，任何数据库DDL均不能在保存工作台时自动执行。

验证只使用指定metarill_test随机项目和唯一ID；真实用例覆盖创建、修改、禁用、删除、非托管保护、跨表/跨索引拒绝、系统列映射、旧版本冲突、并发写入及写入中途故障回滚，同时核实未创建对应物理业务表。前端仅增加版本payload及修正物理删除提示，没有改变编辑交互；未声称已完成各端设备验收。
