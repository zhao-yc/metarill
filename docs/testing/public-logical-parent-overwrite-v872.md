# V872 公开 Full 三级逻辑父范围首列覆盖

2026-11-10。公开 Full 接入 V871 已实证的三级逻辑父范围首列覆盖。范围为 MySQL、普通非冗余来源、单条三层链、字符串 ID、独立物理候选及该链唯一逻辑父字段。表级首个可导入字段为物理文本列，且没有额外联动解析上下文。详情导出、关系匹配键和其它未验组合继续按原门槛。

| 核对项 | 实测结果 |
| --- | --- |
| 公开包和原界面 | 两次生成 708 份包文件逐字一致，25 份原 Vue、Controller 和 Service 与准备包逐字相同。源 Service 的生成差异仅三处固定重名提示。33 项定向回归通过，零失败、零跳过。 |
| 首列覆盖和稀疏读取 | 原普通账号从根、中、末三级按名称覆盖。跨父同名各自命中，省略级联保持原叶 ID 和主键，中层允许父内换叶。当前父无匹配时按原语义新增。 |
| 重名提示及回滚 | 根和中层的同父重名定位到第 2 行「名称」列并返回 400，首行新增一起回滚。两类跨父路径及末层私添固定级联列同样整批回滚。26 个真实 HTTP 含 5 个预期拒绝，独立 MySQL 核对最终三行。 |
| 原 XLSX 和升级 | 原 SheetJS 解析三份实际 XLSX 并回导同一主键。旧 Full 只更新页面被拦截。配套同步配置、运行时及生成文件后，Core 和 Service 一致，手写 partial 保留，更新后的宿主严格编译。 |
| 安装及回收 | 69 份固定 Release 宿主。空库预览 16 项且保持零表，显式安装后差异为零。独占数据库、账号、所有权、Redis、临时配置和转发均独立核清。 |

既有 Full 更新时先生成配套候选，按原更新器同时预览配置、运行时和生成页面，再确认应用。不涉及额外数据库变更。V871 的通用重名 500 保留在 [内部验收](logical-parent-overwrite-cross-excel-v871.md)。本轮验收为真实 HTTP 和 XLSX，正式浏览器与最终 CI 按各自清单跟踪。
