# 普通 Agent 记录写入预检

2026-10-29，基于 `6cf4306` 的本任务修改。C22为局部交付，不能代替MySQL首版或正式身份验收。

## 行为与范围

对照原 `YzpAgentCatalog` 的 `RECORD_WRITES`，只对普通 Agent `update`、`delete`、`copy` 在任务登记前读取真实原记录并判断页面只读条件。创建和导入没有单一当前原记录，保持各自原入口；普通 Web 请求不经过这项 Agent 中间件预检。原业务按钮继续独立沿 C21 门禁。

生成控制器通过 `GeneratedAgentWriteAccess` 固定项目、页面、表、真实Entity和Service类型及读取方法。同程序集、唯一MVC来源、唯一Service和精确方法签名无法证明时不发布记录写能力。元数据中不可解释的条件同样不能默许写入。该标记不是外部授权凭据；请求仍必须通过当前页面操作权限、实际MVC路由/方法和逐次确认。

生成的 `ReadAgentRecord{pageId}Async` 复用实际写入的Scope，包括项目、物理/逻辑父范围、页面固定条件、软删除和精确管理值；使用本次写操作的权限，不借普通query权限补权。任务前预检不获取写锁。派生精确管理另传 `exactLocking:false`，原普通写Scope默认仍要求真实事务；没有放宽实际修改中的锁、对象规则或当前权限检查。

条件只读取真实生成实体中已发布字段，按冻结的物理名和JSON别名绑定。客户端回显字段不作为判定依据；尚未装载的派生属性明确拒绝，不以默认null或false判为可写。本次复用C21受限解释器，没有扩大表达式语法。

## 原接口与错误

更新/删除保留原 `[FromBody] JsonElement` 和严格DTO标记，预检只读取原 `id`。不使用严格DTO重新反序列化整实体来误拒详情回显，实际归一器继续负责字段白名单、省略和显式null。复制仍使用实际路由long ID；父上下文只从实际query绑定读取。重复键、错误大小写的旧id、非标量、指数文本、溢出和非正ID在读取前拒绝。字符串长整数继续使用宿主原JSON转换器。

只读或不可访问原记录返回403，参数错误返回400；均为原R外壳及结构化Agent错误，`outcome=not_applied`、`recovery=fix_request`、`retryable=false`，没有任务记录或业务执行。任务登记后的错误继续保持既有unknown/查询任务协议。

预检与真正写入之间存在时间间隔。它不能代替业务事务中的当前状态、权限和锁校验，也不承诺解决状态在两个阶段变化的完整矩阵。

## 接入与回退

已有应用需从同一候选成套更新运行时，并重新生成页面控制器和Service。仅替换运行时而不再生成的旧控制器缺标记，其Agent更新/删除/复制能力会停止发布；读取、创建、导入及原Web路由继续各自既有合同。不能为了旧包继续发布而跳过证明。

本次生成内容会改变Controller/Service及归属摘要；手写partial只保护不覆盖，前端页面、样式、组件与模板无需修改。没有表结构、DDL、数据回填或手写迁移。先在独占候选预览差异并构建，再应用；回退要成套恢复原运行时与匹配生成产物，不混用两版。

更新器必须同时带齐新合同、`AgentRecordWriteBinding` 和 `AgentRecordValues`；同时删除源码与包清单也会拒绝，目标保持不动。

验证结果由本轮私有目录 `.local/agent-record-readonly-20261029` 的日志/TRX和再生成回执记录，完成后同步进度表。实际生成/严格编译三种模型，截获FreeSql准备执行的SQL与参数后在打开连接前终止；这能证明固定SQL和参数，不能证明MySQL事务、锁或真实角色权限。

真实MVC/中间件/任务存储用例与实际完整包的真实生成Service分别验证任务前拒绝、旧正文及客户端回显；身份结论、ORM传输和任务库传输使用明确离线夹具。受限复合条件页面生成另见[C23](composite-readonly-generation.md)；正式Production身份/OAuth/CLI、实库及多实例并发、未装载派生条件和性能仍待，不扩用B98等已经结束的租约。

首轮真实生成检查发现派生范围默认锁定会在任务前拒绝，已按上文显式无锁修正；另一处测试将原字符串父键误断言为long，按实际逻辑类型修正。保留首轮失败，不将其计为通过。
