# V925 当前发行候选分库 S3 文件竞态与撤权

2026-11-10。以 V897 实际发行候选平台 ZIP 的 3,058 份固定源码为输入，按产品提交 `68af5319` 构建 Windows x64 Production 宿主。独立验收副本加入两个附件字段和对应的页面配置，两次生成的 14 个文件逐字节一致。正式前后核对 51 份宿主文件、11 份元数据和 7 份独立 S3 SDK 产物。Server-200 使用本轮独占 MySQL 平台库和业务库、Redis、SeaweedFS，全部样本均为合成数据。

| 核对项 | 实测结果 |
| --- | --- |
| 绑定先等待 | 绑定返回 R200，删除返回 R500。业务库保留有效引用，受保护下载和独立 SDK 的对象长度及 SHA-256 一致。 |
| 删除先等待 | 删除返回 R200，绑定返回 R500。客户备注与空附件保持原值，绑定整笔回滚。独立 SDK 读取被删对象返回 404，原有两份附件仍在。 |
| 实际行锁 | 两组均先观测一条、再观测两条同库等待连接。同一文件行的 `FOR UPDATE NOWAIT` 均返回 MySQL 3572。 |
| 普通读者撤权 | 平台库撤销页面查询权限后，读者原会话的详情和受保护下载均返回 R500。编辑者仍能下载原字节，业务库快照和两份 S3 对象保持原值。 |
| 数据归属与回收 | 合成文件和引用均在业务库，平台库对应记录为零。两条引用随记录删除失效，四个 Web 会话注销。应用删除后 SDK 确认空桶并核验桶已删除。独立检查确认双库、账号、所有权、Redis、SeaweedFS、运行时私有配置、临时存储及两条转发全部回收。 |

58 个真实 HTTP 请求包括 38 个业务成功、15 个预期拒绝、5 个文件字节校验。独立 SDK 的 10 项离线检查和 24 次真实操作全部通过。首轮转发端口与固定探针约定不一致，在探针发出 S3 请求前停止并核清资源。复验只对齐回环端口、增加已用租约保护，使用新范围和同一产品及探针。Web 端外观本轮未参与验收。

本轮为 V04 补充当前候选的分库文件竞态和撤权证据。其余组合及发布门槛见 [MySQL 首版交付节点](../mysql-first-release-milestone.md)。
