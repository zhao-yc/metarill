# V527 受保护附件保留原文件名

2026-11-07。产品基线 `367da7f2` 加本轮 H5 附件组件和测试变更。C# 宿主与 V526 相同，仍用 `c205c325` 冻结的 69 份 Production 文件，附 11 份元数据及 16 份示例客户生成文件。HBuilderX 5.34.2026102909 导出 160 份 Web 文件。

V526 已确认浏览器通过原卡片下载了正确的 ZIP 字节，但文件名变成了 Blob 的临时标识。H5 的 `uni.downloadFile` 把响应转为 Blob URL，`uni.openDocument` 打开这个 URL 时无法传递原文件名。本轮在可下载的二进制文件上，仍走原接口和会话头取得同一 Blob，再把已解析的原文件名传给浏览器。图片及可直接打开的文件继续走原预览，App 和小程序的路径不受 H5 分支影响。
