# V865 固定平台 MCP 双发布目录与分库权限

2026-11-10。固定产品 86775982，逐份核对 51 份 Production 宿主文件和 11 份元数据。Server-200 独占 MySQL 平台库、业务库及 Redis。两库确认空库后执行原显式初始化。

| 核对项 | 实测结果 |
| --- | --- |
| 平台发布页正向对照 | 真实平台管理员可描述项目配置页的更新请求，ID 必填并明确要求确认。实际 MCP 详情读到原平台项目。 |
| 普通 Web 身份 | 演示项目普通读者的真实登录通过。可描述业务详情并从业务库读回超过 JavaScript 安全整数的字符串 ID，同一页面的更新结构被拒绝。 |
| 真实 OAuth Agent | 平台管理员经原设备码和原网页审批接口批准演示项目。令牌及持久授权均绑定演示项目。Agent 可描述并调用业务列表、详情，即使常规 Agent 目录具有写入能力，MCP 的四种写入结构及确认调用仍拒绝。 |
| 实际发布页跨项目 | 对正向对照中已经成功读取的平台配置页，演示项目 Agent 请求列表、详情、更新结构和实际详情均被拒绝。将请求头切换到确实存在的平台项目返回 HTTP 401，同一令牌回到获准项目后仍能读取。 |
| 分库与撤权 | 配置页和真实授权记录只在平台库，合成业务记录在业务库。三次独立 MySQL 读回核对两个项目样本摘要、业务行及两个库的零任务状态。原撤权后旧 Agent 令牌返回 401，两个 Web 会话和 Agent 会话均已失效。 |

46 个真实 HTTP 请求含 9 次成功工具调用、14 次预期工具拒绝和 2 次预期 HTTP 401。独占双库、账号、所有权记录、Redis、临时配置和回环转发通过独立回收检查。审批经真实 HTTP 完成，原授权浏览器交互证据另见 [V841](fixed-management-oauth-web-v841.md)。

C15 的独立 Full 普通 Web、独立 Full OAuth Agent 及平台双发布目录在同一固定产品上均已验收。证据分别见 [V863](fixed-standalone-mcp-schema-v863.md) 和 [V864](fixed-standalone-mcp-agent-v864.md)。
