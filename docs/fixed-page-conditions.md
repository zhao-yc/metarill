# 页面固定条件

本轮将原页面 WhereSql 的固定物理标量条件接入 C# 生成链路，保留原页面、样式、交互、请求与导入导出协议。平台及已有项目元数据没有改写，不能为生成成功删掉尚未支持的旧配置。

## 支持范围与执行

例如 `group_id=@parent_id AND status IN (1,2,NULL) AND name LIKE '可见_%' AND amount>=0`：父范围继续来自已验证的真实父记录；项目身份来自服务端 Actor；其余固定条件在生成阶段验证字段与类型，静态计划装载后复核一次。请求只执行参数绑定，不解释配置 SQL。

支持物理标量上的 `= <> > >= < <= LIKE IN IS NULL IS NOT NULL` 与 AND 分组。字符串中的 AND、逗号和双单引号保持字面量；LIKE 保留原模式语义；高位整数不经浮点转换。`=NULL`、`<>NULL`、`IN(NULL)` 保持SQL三值语义，不改为 `IS NULL`。

| 入口 | 范围 |
| --- | --- |
| 分页、数量、详情、统计、选中回读、XLSX | 同一固定条件加原身份、父归属与请求白名单筛选 |
| 关系候选、分页、已选项 | 执行目标页固定条件；附加条件须逐项被目标实际执行 |
| 新增、编辑、复制、导入中的关系值 | 在原事务当前读中核对目标候选，不能借名称解析选中被排除的目标 |
| 编辑、删除、复制与覆盖导入的原记录定位 | 原页面固定范围内定位，不能修改范围外旧记录 |
| 已授权写后回执 | 私有事务入口保留对象ID、身份和父范围；允许记录因新状态离开筛选页 |

页面常量用于查询范围，不作为新增默认值或额外保存后条件。范围外同名旧记录不参与原首列覆盖；沿用原范围内新增行为，不越范围覆盖。后行失败仍回滚整个导入批次。私有回执入口不能由HTTP参数选择，也不额外授予列表或详情权限。

非冗余表只把必要物理字段加入隐藏依赖；不会自动加入VO或Excel。其数量接口也消费相同计划，首轮实库发现的count漏传已修复。单选/已支持冗余多选仅接受目标页已执行的相同规范条件项，不能把来源更窄条件替换成宽目标页；多选原有排序、名称、父与存储门槛保持。

OR、函数、原生代码、lqw、语句、未声明字段、错误或越界字面量、派生/JSON数组/凭据条件以及新增账号、跨对象、表单变量仍拒绝。原项目与父变量只接已有等值绑定。未支持条件在整批输出前失败，不忽略它继续生成。原生SQL和其它数据库尚无本轮验收结论。

## 验证与升级

真实正式生成Controller、MySQL和实际XLSX分别验证冗余及非冗余模式：列表/count/统计一致、原LIKE及NULL语义、范围外详情/选中/写入拒绝、目标候选及名称导入限制、保存后离页、新增不强制匹配常量、复制/删除、范围内覆盖后离页、范围外同名不覆盖及整批回滚。该专项使用固定服务端测试身份，不代表真实登录、原浏览器或真机验收。

独立应用包分别验证有/无文件与有/无页面条件四种组合：从包内源码restore/build，原页面副本一致，本地更新及重复更新稳定，手写partial保持。多选范围正反例另执行实际生成编译；未将它称为全部多选条件的实库并发验收。

没有DDL、回填、元数据或前端变更。已有C#项目更新生成器后，先生成候选完整包，再通过原在线助手预览和受管更新，同步本轮Data运行时及生成Service并重新构建，保护手写partial。末尾可选计划维持旧源码调用兼容；不承诺旧二进制与新生成Service混用。回退须成套恢复原生成器、运行时及生成物，保留更新日志；Java V7/V8工程无本轮迁移动作。
