# V871 三级逻辑父范围的 Excel 首列覆盖

2026-11-10。固定 b739fd06 的生成器，三页共享同一非冗余三层跨表链，分别绑定根、中层和末层父范围。原表级首个可导入列为名称。707 份清单文件逐份核对，69 份 Release 宿主严格构建。Server-200 独占 MySQL 和 Redis。空库预览 16 项且仍为零表，显式安装后重复预览为零。

| 核对项 | 实测结果 |
| --- | --- |
| 匹配和省略 | 两个父范围各追加一条同名记录。根、中、末三个入口分别省略级联并更新金额，原主键和原物理叶 ID 保持。另一父范围同名记录保持原值。 |
| 父内调整与冲突 | 中层允许在同一父内换叶，主键保持。在无匹配的原叶父范围，首列覆盖按原语义新增。根和中层已有两个同名候选时均拒绝，末层仍可唯一命中。当前宿主将两次重名拒绝呈现为通用 HTTP 500，待完善可修正提示。 |
| 实际工作簿 | 根、中、末三份 XLSX 仅导出对应父范围记录，原 SheetJS 分别解析并回导。末层回导沿原模板仅提交可写列。三次回导均核对同一主键。 |
| 三种事务回滚 | 根、中层第二行跨父，末层第二行私添固定级联列，均返回带行号的 400。独立 MySQL 确认三个批次的合法首行也回滚。 |
| 资源核验 | 26 个真实 HTTP 含 5 个预期拒绝，最终三行独立物理读回及注销通过。独占 MySQL 库、账号、所有权记录、Redis、转发及私有配置已独立核清。 |

本轮使用内部准备包。公开 Full 的首列覆盖门禁及同包实库复验仍待完成。公开追加和列表导出的证据见 [V868](public-root-parent-cross-excel-v868.md) 和 [V870](public-middle-leaf-parent-cross-excel-v870.md)。
