# V564 同源网关、真实登录和 IP 审计

2026-11-08，固定源码 `55001214`。平台和独立应用分别严格发布 69 份宿主文件。公开 Full 包核对 656 份清单条目及外层清单。平台在 Server-200 独占平台库和业务库显式初始化，独立应用用另一个空库完成结构预览、执行及安全初始化。两轮分别使用独占 Redis。

本机受控同源网关将原 `/api` 请求转发给 Production Kestrel，并用实际 TCP 对端地址覆盖客户端自报头。两轮各执行 26 个原接口请求。

| 场景 | 两端独立核验 |
| --- | --- |
| 地址 A 的失败与锁定 | 首 10 次失败写入 Redis，重启宿主后再失败 10 次，触发 30 分钟锁。再次重启后，正确密码仍被拒绝，失败计数维持 20，剩余锁期限继续递减。 |
| 地址 B 的真实登录 | 与 A 共用同一网关。真实密码登录、菜单加载及注销成功，旧会话访问菜单被拒绝。独立 SQL 回读账号的成功登录 IP 和注销后的会话。 |
| 非受信直连 C 与伪造地址 | 直连错误密码被按实际对端 C 记录一次。伪造地址和网关自身没有失败计数或锁。 |
| MySQL 审计 | 每端 22 条失败事件，其中 21 条属于 A、1 条属于 C。分别核对 1 条已锁拒绝、2 条带锁标志、2 条已知账号错误及 1 条已注销会话。 |

首轮平台的 26 个 HTTP 请求通过，独立 SQL 的中文比对未通过。只读诊断用同一 MySQL 管理客户端复现 `latin1` 文本比较返回 0、UTF-8 字节比较返回 1。最终夹具按实际字节核验同一内容及原数量，产品源码保持固定。首轮和双端正式复验的独占库、账号、Redis、转发、所有权记录及临时凭据均已回收，并从新连接核验。实际部署网关、TLS 及浏览器验收仍按首版清单执行。

同一固定提交的 API 全量回归最终 235 项通过、49 项实库条件跳过、零失败。首跑缺少隔离检出的前端解析依赖，两项原 Vue 请求合同失败。按锁文件从缓存还原依赖后原样重跑，两个用例均通过。
