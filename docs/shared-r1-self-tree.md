# R1 物理自树缓存与混合级联（B93）

2026-10-27，起点 `58255d5`。本轮补齐 R1 来源的物理自树叶子缓存，将它接入现有统一名称传播与维护计划，并逐项证明原完整应用用途。前端页面、样式、原级联组件和操作流程保持不变，真实平台配置未改动。

## 实现范围

- 固定 `selfTree` 定义编译为精确的来源外键、目标名称与 `_name` 缓存列 ID。目标名称可为普通 R0／R1 实体的物理 `name` 或自定义 `caption`；展示路径仍按原树读取器动态返回，不将整条路径存入叶子缓存。
- 生成阶段一次编译，运行时复用统一关系传播和维护事务。目标改名、逻辑／物理删除驱动缓存更新，不递归执行消费者 Service 钩子；回填继续使用原维护按钮及 HTTP 接口。
- 普通自树、双自树、同表书签、自树／跨表／多选混用、普通／全局共享跨表加独立自树，按来源键及父键四种类型组合分别证明。共享跨表父页按各自实际物理父键判断，自树同伴不能被当作跨表分支。
- 完整包同时检查隐藏自树。无效覆盖、未发布项目／后台、派生或全局自树目标、虚拟缓存、错误路径、附加查询与未证明的自树父参数继续拒绝；已有 BackendOnly 不由可见同伴替隐藏坏定义放行 Full。
- 原有辅助列带 `isJoinColumn=1` 而未填写路径时，由固定自树定义证明其归属；若声明路径则必须精确匹配。普通关系的路径校验不放宽。
