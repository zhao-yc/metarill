# 同表非父级联的最终状态校验

当 selfTree 的树表就是来源表、级联字段又不是树父字段时，保存来源记录可能同时改变被引用路径。Metarill 现接通这一原页面模式，保留候选/路径接口、页面、组件、样式与交互，仍使用固定目标页、真实 Actor、项目、软删除和元数据条件。

## 写入顺序与真实数据库语义

默认值、手写 BeforeSave 与关系准备之后，既有写入守卫照常执行；只执行正常的一次 Mapper 新增/更新，再在同一事务里读回实际存储行及完整当前路径，之后才调用 BeforeCommit 观察者并提交。复制和导入使用相同入口。最终检查失败整笔回滚，不增加临时写入、通知后补写或事后修补脚本。

选中当前已存在节点时，名称准备使用规则处理后的当前实体；最后仍以数据库实际行判断可见性、路径和名称。新建时不能关联本次尚未存在的新自身或让选中路径依赖本次新建节点。数据库的字符排序规则、DECIMAL舍入、NULL与页面条件都由既有SQL范围判断，不用内存比较或旧行快照猜结果。

关联ID及项目归属在落库后必须保持预期；创建或改父时也核对父键没有被存储截断。显式关联提交需要名称与最终叶子一致，不能把另一节点或被截断名称当成功。最终校验只读，不在授权守卫后补写字段。

## 图依赖与权限

级联ID、受管名称、树父键、节点名称、项目/软删除和目标条件字段的依赖在生成时固定。更新依赖时会复核现有非空关联，即使本次没有提交级联ID；只改变普通非依赖字段不新增此项校验。省略ID时保留原受管名称，DisplayText仍显示实时路径；显式重选/刷新、默认值、新增和复制才按既有规则计算名称，不借本批实现全局名称传播。

创建或改父另外验证来源节点自己的父链，书签为空或指向其它根也不能造环。此私有拓扑读取只取ID/父键，保留真实Actor、项目与软删，单独跳过页面常量以检查树拓扑；不对外返回隐藏名称或节点。选中关联的完整路径继续逐跳应用全部目标条件。64层允许，第65层拒绝。

显式非空重选仍需目标list，清空不读目标；图依赖复核不额外要求目标list，但保留数据范围。内部Import按来源import动作进入，不能由请求伪造。structureOnly等私有标志不在原请求合同中，传入JSON时拒绝；候选/独立路径始终按原两页list规则。

## DECIMAL默认值结构修复

实库同时发现元数据DEFAULT 1与MySQL反查1.00被当作结构差异，导致建表后核验失败。MySQL适配器现仅对DECIMAL纯数字默认值做精确文本归一，比较与列指纹使用同一规则，不通过.NET decimal/double转换，不丢高精度。真实金额差异、会被舍入的0.014与0.01、字符串格式及有无默认值仍不同。原始SHOW CREATE快照继续保留用于并发结构漂移检查，DDL声明与业务默认值不改写。

## 更新与边界

已有C#应用配套更新Data结构比较及生成器，再生成相关Service、Controller、DTO/VO并构建，保留手写partial。此功能没有新增业务DDL或回填；已缺少自动名称列的表仍按[自动名称合同](cascade-tree-storage-contract.md)先预览并显式同步。默认值格式相同不再产生伪DDL，真实变化仍须预览执行。

当前仍是固定普通冗余selfTree、无来源父参数且唯一可读目标页的范围。跨表、来源父范围、非冗余、全局名称传播、用途SQL整体投影、原浏览器/设备、同条件性能和完整MySQL首版继续实施；候选500项/路径64层及FullApplication门槛保留。不合并main或部署生产。
