## 缺陷与修复

V448 从合同菜单进入甲合同。后台回读已选客户被后端以 403 拒绝，独立宿主把这次请求弹成全局「操作失败」，挡住了明细「查看」。此轮没有发出明细更新。

共享候选运行时将分页和已选回读错误交回调用控件。原选择器已有独立的失败状态和主动展开提示，后台回读失败继续保留原 ID。后端来源页、目标页权限检查及 403 保持原样。页面、弹出层和控件由原生成源头提供。
