## 代码归属

共享 `OriginalBusinessButtonExecutor` 位于 Agent 所在的现有 Web 基础程序集，但处理器不会自动进入 Agent 目录。`IOriginalBusinessButtonHandler` 显式声明固定按钮 ID 和原发布路径，返回原 MVC/R 结果；普通项目按自己的手写业务注册，不自动安装固定样板。

平台现有兼容 Controller 对已注册业务按钮调用执行器，其他配置按钮走原路径。FullApplication 携带原中央接口 Controller 模板及 Scoped 注册，受管更新允许该精确宿主文件。没有 HTTP 内部转发、外部 URL 或客户端 SQL 执行。

请求先核对真实 Web 身份并拒绝 Agent 身份绕行，再核对唯一处理器、发布按钮及路径、当前账号实际按钮授权。普通按钮不附加页面 query/update 或超级门槛；发布的 VisibleWhenWritable 仍要求原页面修改权。客户端显示规则不作为授权。

物理记录必须通过与 Agent 共用的正式生成 Service 证明：唯一生成 Controller 标记、页面/表/程序集和 Service 注入关系、准确 Reader 签名以及当前请求 Scope 的唯一实例。实体 ID 与原外层 ID 冲突、指数/浮点/非正 ID、错误路径、重复处理器或缺少生成服务都拒绝，不能执行手写业务。字符串 ID 不经 double。

## 原三按钮样板

`tools/acceptance/sample-host/SampleContractButtonHandler.cs` 是手写业务适配，通过已有 HostCustomization partial 注册三份固定处理器，仍调用同一个 SampleContractAgentBusiness 及生成 Service。

- 预览保持只读，返回原内容及摘要。
- 原详情提交完整实体，处理器只取原 ID、名称、金额和备注计算已有摘要；可以沿用显式 expectedDigest。其他展示字段不会进入生成更新 DTO，不作为权限或项目来源。
- 浏览器金额 JSON 会丢尾零。按发布金额字段 Scale 恢复表示；超小数位不舍入放行，缺详情原值要求重新打开详情。绝不改用服务端最新行计算有效摘要。
- 实际锁后摘要和状态由原 Business 重新判断，过期返回 HTTP409/R409，缺失保持404。正常处理及负金额回滚仍走原外层事务、共同生成更新和对象规则。
- 原单层 R 结果直接交给原 customButtonHandler，保留原刷新与错误提示行为。
