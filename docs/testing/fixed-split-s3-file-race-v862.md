# V862 固定候选分库 S3 文件竞态与撤权

2026-11-10。以产品提交 `86775982` 的固定 Production 宿主复验平台库与业务库分开部署。运行时源码与开发提交 `c2bb3fed` 一致。逐文件核对 51 份宿主文件、11 份元数据及 7 份 SDK 探针产物。Server-200 使用本轮独占 MySQL 双库、Redis 和 SeaweedFS 桶，全部样本均为合成数据。

| 核对项 | 实测结果 |
| --- | --- |
| 绑定先进入等待 | 放锁后绑定返回 R200，删除返回 R500。业务库保留一条有效引用，原下载和独立 SDK 的对象长度及 SHA-256 一致。 |
| 删除先进入等待 | 放锁后删除返回 R200，绑定返回 R500。整笔客户更新回滚，备注和空附件保持原值。独立 SDK 读取被删对象返回 404，另外两份原附件仍在。 |
| 真实等待 | 每组先观察到一条、再观察到两条同库等待连接。对同一文件行的 `FOR UPDATE NOWAIT` 返回 MySQL 3572。两组均核对提交后状态与文件引用归属。 |
| 原会话撤权 | 从平台库撤销普通读者的页面查询权限后，其原会话的详情和受保护下载均返回 R500。普通编辑者仍能读取原字节，业务库快照和两份 S3 对象保持原值。 |
| 隔离与回收 | 合成文件及引用均在业务库，平台库对应记录为零。四个会话均已注销。应用删除对象后，SDK 核对空桶、删除并确认桶不存在。独立检查确认双库、账号、所有权记录、Redis、SeaweedFS、临时私有配置、存储目录和两条转发已清理。 |

58 个真实 HTTP 请求均使用原协议，含 38 个业务成功、15 个预期拒绝及 5 个字节校验。十项离线探针检查及 24 次真实 SDK 操作通过。旧探针的离线回执仅返回检查数，准备脚本依据实际十项结果补齐回执结构后才启动实库；固定产品与探针代码未改。

本轮补齐 V04 在固定候选上的分库普通角色文件竞态与撤权证据。其余拓扑组合、实际发行域名和完整发布验收仍按 [MySQL 首版交付节点](../mysql-first-release-milestone.md) 核对。
