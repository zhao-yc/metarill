# 共享非冗余来源父范围（B78）

2026-10-27，起点`b8a9f50`。本批接通普通R0共享跨表来源的固定主子页面父范围，原接口、页面、组件、样式及主子操作保持。固定后端／原完整包范围已经完成并通过最终回归；正式身份、复杂文件及其它组合继续按独立边界验收。

## 实现

共同国家／地区不重复落库时，父归属必须通过真实独立末端的当前路径判断。生成器复用B75的整组SQL范围、B76的请求状态和原有逻辑父范围服务，使同一条记录可在根、中间层、独立城市、独立仓库，以及“逻辑国家＋物理国家外键”的原页面范围下操作。

`SharedCrossTableParentCompilation`在共享组尚未发布到生成缓存时，只沿已经固定的读取定义解析父表；复用原非冗余父表对物理主键、项目键、标量FK、非全局／非视图／非自身父表的检查，避免递归调用尚未完成的写计划。普通关联的来源父解析同时识别已证明的跨表层位，修复仅按列名前缀找不到共同国家的缺口。目标关联的父解析边界保持原规则。

创建／更新／复制继续先协调完整逻辑路径、检查父范围，再整组打包。整组省略时不重新编码，原始物理祖先空位不会被当作关系变化。写后仍在当前事务中核对实际来源、身份字段和逻辑父路径；临时实体合法但数据库重挂到了另一个真实父节点时，整笔拒绝。删除钩子改变原始位也须在通知前拒绝。

父ID沿用原`parentId`／`parent_id`协议及规范正整数校验，不经过浮点数。一个父上下文同时约束逻辑祖先和物理外键时，两者都必须满足；源码、SQL和执行器不接收客户端自选目录或方言。

## 固定验证范围

四种所选ID／目标父键交叉、两种短主叶、一种固定派生目标，共七模型。每个模型有五个父页面：国家、地区、原主控件末级、仓库、国家与物理外键共同归属。短主叶的地区页面保留原控件。额外的物理外键是验收模型元数据，不修改平台实际业务结构。

名称不能冒充父外键，来源主键、虚拟项目身份、未知父表及精确权限等未证明范围仍拒绝，包创建失败不得留下输出目录。页级改变存储定义、全局／来源自参与及其它拓扑沿用原门槛。跨表非空Excel继续按B14；共享父范围的复杂文件、正式身份／空库和原浏览器等未新增通过结论。
