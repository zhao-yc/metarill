沿用原读取协议：目标失效后，来源自身的已选ID保留供回显，不可读名称隐藏且不能通过名称筛选泄漏；来源仍可按自身字段统计。多层同时存储、非法格式或两个真实路径祖先冲突属于坏存储，继续在读取／统计中拒绝。写入另做完整目标范围证明，不能把读出的旧ID当作写许可。
