# 数据库复选的固定派生名称

## 本次功能

原MultiCheckBoxDatabase保留嵌入式复选、全选、findNameId路由及id/name/value/text四字段数组。R0来源选择普通R0目标，目标name可通过固定单值联接派生，例如target.name来自company.name；来源只存target_ids，显式或自动target_names仍为只读逻辑数组。目标公司改名后按当前投影显示，不建立新的物理名称缓存。

旧实现只认可物理name，直接移除门禁会在候选、保存、导入和导出查询IsIgnore属性。本批把这些读取统一到生成时证明、静态初始化的固定目标计划；数据层逻辑数组同用原目标别名域，不把来源展开成重复行。普通请求只绑定参数。

候选权限保持原来源页开放动作任一可用的规则，不新增目标列表权限要求；身份来自真实宿主。原真实来源父、项目、软删和复选whereSql的物理字段／表单条件仍全部执行，不拿目标页面条件代替控件条件。名称排序使用同一派生表达式，再按ID稳定排序；全选超过5000项整次拒绝，不返回截断集合。

写校验与名称导入加入原事务，用固定计划当前锁读。来源依赖变化重验原选择，ID输入的显式null与空数组保持区别；空关系的逻辑名称均沿原投影返回空数组。名称导入逐项唯一匹配，歧义或任一无效行使整批回滚；原票据XLSX导出核对每个名称能唯一返回同一ID，跨父或表单条件不同不能复用宽范围名称。

## 升级与边界

本批没有业务DDL或数据回填。已有应用先同步同版Core/Data运行时，再通过原三个按钮预览／应用正规再生成受影响产物；派生数组的数据层门禁已扩展，不能只复制生成Service而沿用旧Data源码。更新保护手写partial、AppID和私有配置。需要改元数据的模型仍先修改定义，再预览结构，不允许启动自动改库。

只覆盖普通R0来源／目标的固定单值字符串name；冗余派生缓存、全局／级联／数组名称、其余复杂联接与传播回填继续保持门禁。原前端与模板不变。真实生成HTTP固定测试身份不代表正式Web认证、Fresh、浏览器、跨端或性能验收。

前批B46的12张失败空表未由本批访问或删除；两组精确清理授权继续等待，不能以本批新样本清理冒称历史零残留。整个复杂关系与MySQL首版目标继续，不合main、不部署生产。
