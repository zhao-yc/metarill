# 自关联级联写入与受管名称

生成Service现接通自关联树的新增、修改和复制验证，沿用原级联请求与完整实体回传。原页面、组件、样式、选择与清空操作保持，读取接口见[级联读取合同](cascade-tree-read-contract.md)。完整级联仍受能力门禁限制。

## 元数据与请求边界

叶子必须是已声明的字符串或int64物理_id列，名称使用同前缀_name物理字符串列；未显式配置时由共用selfTree存储规则派生。关联表声明必须与级联定义一致，目标需要固定且唯一的可读普通页；目标项目、软删和固定条件沿读取计划执行。实际库缺名称列时须先预览并显式应用结构计划；生成不执行DDL，显式冲突继续拒绝。其他类型也明确走级联拒绝分支，不能从普通字符串/long关系枚举中漏过。

同前缀名称由服务器维护，从可写DTO和写入schema移除；原完整表单可回传已声明的名称回显，HTTP边界忽略该值。内部严格DTO拒绝直接提交名称。普通物理列和冗余联接列都受保护；原字段输入/只读外观按保存的元数据保持，不因为服务器托管而改成新页面。

## 生命周期与事务

默认值和手写BeforeSave之后，最终关联通过当前事务逐跳ForUpdate读取整个祖先链，只投影固定id/name/parent。不存在、已删除、跨项目、页条件排除、断链、循环和无效ID都拒绝源保存，不能只核对叶子存在。

新增、复制及显式提交关联时重算叶子名称。省略关联和受管名称保持原值；手写钩子显式登记名称刷新时仍以最终关联重算，不能保存伪造名称。复制重新验证当前目标并获取新名称，目标失效时没有新增记录。这里只同步本次源对象，不宣称目标改名的全局冗余传播已完成。

非空引用要求目标list权限；普通源新增/修改/复制沿原动作权限，不额外要求来源list。清空仍核对当前身份，但不读取目标，不增加目标list门槛。字符串空文本保留为空文本，可空整数沿现有Optional转换为空值；显式null保留null，省略不回退成清空。服务器名称随清空同步，明确的物理长度上限在写前检查。

当该字段就是同表树的父列时，最终父路径包含本对象即拒绝，防止选择自身或后代形成新环；合法迁父和恢复根节点可用。同表的其他关系字段涉及被修改实体的合并后候选范围，目前明确保留缺口，不读旧实体后放行新值。

所有校验、源持久化、观察者和名称同步在同一事务。当前读不会使用准备阶段已建立的RR旧快照；祖先锁保留到源提交。后段故障撤销源字段及名称，不增加performance_schema或全局观测权限。
