# V306 样板合同事务 CI 复验

Windows 与 Ubuntu 的[生成测试第四组](https://github.com/zhao-yc/metarill/actions/runs/42054183286)各有七项样板事务失败。基于 cc56aae 的 Windows 隔离构建复现 7 失败、29 通过。生产关系维护在写入事务内通过同一读取器核对当前数据库名和 MySQL 会话报文上限。样板夹具此前拒绝该查询，合同业务在验证提交或回滚前退出。
