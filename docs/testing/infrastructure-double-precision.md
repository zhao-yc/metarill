# 基础设施入库浮点参数的位型保持

日期：2026-11-02。编号：A29。起点：`9931d5fed0677b202068fc3000228affdd9a14cf`。在准备真实持久化验收时核对SqlRowStore的实际参数转换，发现驱动接收之前仍存在文本中转。本轮修复此入口，不改变元数据、业务API或原页面。

## 真实离线失败

新增测试直接执行生产SqlRowStore.Coerce。未创建DatabaseSession、未读取私有数据库配置、未连接服务器：首轮1通过／3失败。中法两种区域设置的原double位型0410000000000000被归一为040FFFFFFFFFFFFF；boxed float 0.1f转double时也先缩成短文本0.1，再变为另一个double。

A26的二进制参数准备只保护驱动阶段，无法恢复此前仓储已改变的值；A27统一JSON／默认文本和A28工作簿修复均不覆盖此私有转换。因此保留各批原证据，不能据其通过推断所有写入口已无损。

## 修复合同

逻辑double字段收到typed finite double时直接保留原值，收到typed finite float时直接按数值提升为double。NaN／正负无穷仍统一返回原FormatException和固定提示，不将非法值交驱动。字符串、JSON数字／字符串、decimal及整数等其它输入继续走原有限数文本解析；省略、显式null及原空选择语义保持。

基础设施范围不扩大：SqlRowStore仍只用于元数据、认证、文件等基础设施，不取代强类型生成业务CRUD。没有新增通用ORM、实体、Mapper、Service或运行时文件。
