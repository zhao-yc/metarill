## 实现与范围

支持普通非冗余R0同表的直接父控件，以及指向同表其它节点或已有自身的独立书签；物理名称和固定单值字符串联接名称分别证明。派生树模型保留物理业务标识name，树显示另用display_label=company.name，不读取IsIgnore实体属性代替当前名称，不建立名称缓存或启动回填。

拓扑仍采用既有只读ID／父键的当前锁读。已有自身的派生名称在正常DML后按真实外键和数据库实际行复核；其它节点写前从固定投影当前读，写后验证完整路径。循环、64层、数据库舍入／截断、项目／软删／物理页面条件及目标权限均保留；导入同名路径仍明确拒绝并回滚，不能选任意一条记录。

完整包能力清单按真实目标声明sameTableSupported及derivedNameSupported，原uni-app页面、组件、布局和生成模板保持。更新仍经原三项生成／同步动作及LocalGenerationUpdater，手写partial只首次生成。

本批不放开R1派生名称、全局目标、凭据或数组名称、派生父结构／条件、隐藏名称、未知额外whereSql、未证明来源父范围或复杂混合组合。独立R0／R1目标既有合同保持。
