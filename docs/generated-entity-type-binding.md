# 生成实体与运行时同名

日期：2026-10-29；基线 ed08a6f。本项修复 C# 生成模板，不改 YZP 元数据、接口、前端页面或业务类名。

## 问题与处理

业务表名可转换成 RuntimeActor、DateTime、DatabaseSession 等合法 C# 类名。旧模板同时导入实体及运行时命名空间，普通 CRUD 的类型引用会产生二义性；实体命名空间内的 DateTime 字段和属性特性也可能被业务类型遮蔽。原始失败的真实编译日志保留。

生成模型增加完整实体类型信息，查询、投影、关系校验、导入导出和生命周期签名均使用 global:: 开头的实体限定名；生成文件不再宽泛导入实体命名空间。实体内部的日期、映射特性及派生规则装载状态单独限定框架类型。不是维护有限的冲突名称名单，也不通过重命名业务表绕过。

后端导出和本地助手候选包校验复用同一渲染入口。首轮完整包回归暴露两入口处理不同，已保留失败记录；修复后继续验证原预览、应用、归属与恢复规则，没有关闭候选校验。

## 跟进方式

成套更新生成器及其模板，按原元数据重新生成受管后端，再严格构建。数据库、数据回填、JSON/路由及前端操作均无需改变。已有手写 partial 仍只首次创建；CLR 类型身份和方法签名保持一致。已有手写代码若本来就存在同名歧义，应在手写位置明确限定两个类型，不能覆盖手写文件消除错误。

完整名称由编译器解析，不引入请求时反射或元数据解释；本项不据此宣称性能验收已通过。
