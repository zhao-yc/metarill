# V290 平台分库 S3 桌面浏览器验收

2026-11-05，固定 `250aab9` 和 V286 的 69 文件 Production 平台宿主。私有平台 H5 在原项目上登记了正式生成的两份示例页面，更新该示例页写入清单并配置回环 API。原平台页面、样式和附件控件保持原样，公共产品源码未改。HBuilderX 5.34 实际导出 160 个 H5 文件。

| 检查 | 实际结果 |
|---|---|
| 真实工作区 | ego lite 中以业务普通账号登录，通过原工作区界面选择专用设备和示例项目，从原「客户」菜单进入业务列表与详情。 |
| 原附件交互 | 在受保护字段的原附件控件上传 202 字节 ZIP，确认选择后保存。保存前未出现提示弹窗。关闭并重开详情，受保护字段显示附件，由原附件卡片下载，浏览器实际落盘文件保留扩展名，内容逐字节一致。 |
| 跨库和真实对象 | MySQL 独立确认业务库一条业务行、一条文件、一条有效引用，原备注保持，公开附件字段为空。平台库对应文件和引用均为零，普通角色仍在平台库。独立 AWS SDK 核对实际对象长度和 SHA-256。 |
| 退出和清理 | 由原菜单退出并回到登录页。平台库活动会话为零、撤销会话为一。精确删除同轮唯一核验对象，独立客户端读回 404，空桶删除后再核对。两座独占库、账号、Redis、SeaweedFS、转发、浏览器本站数据和下载副本均已清理。 |

测试脚本先以页面标题查找菜单，随后从同一已登录浏览器实际观察到菜单名称为「客户」。详情打开后按可见的受保护字段定位按钮并继续，没有重放登录、上传或保存。原上传计划、multipart、完成、业务保存、保护下载和退出各一次 HTTP 200。

构建命令为 `D:\HBuilderX\cli.exe publish web --project E:\git\metarill\.local\s3-platform-browser-v290\frontend --webTitle "Metarill V290 平台附件验收"`。本轮私有脱敏回执存于 `E:\git\metarill\.local\s3-platform-browser-v290`。

本轮覆盖平台分库原桌面浏览器的固定受保护附件链。公开附件的分库及同库 HTTP 证据分别见 V286 和 V287，平台同库浏览器、移动真机、其他 S3 品牌与同条件性能仍按各自门槛验收。
