没有关闭现有项目的导入／导出按钮，也没有改变平台元数据。已有配置包含尚未完成的用途时，仍明确拒绝 Full，并保留既有 BackendOnly 能力；不会静默删列、删除按钮或降级页面。

每个目标表及目标页必须明确发布到包内项目和后台，隐藏来源也检查目标发布归属。来源逻辑条件／精确权限、全局／非冗余目标、重复层位、共享辅助位和跨表／自树混合等尚未证明范围继续保留限制。

能力清单按页记录 `sourceMode=crossTable`、部分选择、多个控件及来源父范围；同时明确路径单元格导入、导出、自定义不同名属性、派生名称和名称反向传播未完成。清单不代替真实功能验收。

## 直接执行的验证

- 四种来源 ID／目标父键 string／int64 组合，均由正式打包器生成 FullApplication，使用包内基础源码独立构建；其中两组包含真实物理文件列。
- 包内采用 `web-database-v1` 正式认证配置，不切换开发认证；本批构建证明不当作真实 Web 登录验收。
- 双跨表、五个来源页、四种逻辑父范围的能力声明逐页核对。包内原列表／详情与生成副本逐字相同，级联组件与仓库原组件逐字相同。
- 真正挂载包内原详情和原级联 Vue 3 组件：逻辑回显、根／中／末层部分选择、超过 JS 安全整数范围的字符串 ID、双控件互不覆盖、清空、只读和原整 entity 回传。只替换网络响应与外部基础渲染；不是浏览器或真机。
- 本地更新按原三动作执行，手写 partial 原字节保留，重复更新为空操作；跨表只读时的普通标量导入另做完整包构建。
- 非空路径导入、路径列导出、隐藏坏链、目标页／表未发布、隐藏来源的目标归属、全局目标与未知上下文均在 stage 写入前拒绝。

七组既有模型与上批保留产物逐字比较：除能力声明及其归属清单外，后端和原页面均未改变；七组各两轮生成稳定，手写 partial 与输入元数据保持。比较器只读旧产物，在新的私有目录生成候选，不访问数据库。
