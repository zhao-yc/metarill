## V619 文件事务集成

从 2,841 文件的 Git 归档严格构建元数据测试项目，零警告、零错误。对 `ProjectFileRuntimeIntegrationTests` 运行真实 MySQL 测试，18 项执行并通过，失败和跳过均为 0。

| 组合 | 已验证 |
| --- | --- |
| 平台与业务库分离、共享同库 | 文件归属、文件引用与业务事务一致，公开路由按已发布项目选择文件数据 |
| 物理删除和逻辑删除 | 删除证明使用原业务事务，外层事务内禁止物理删除对象 |
| 对象故障和重试 | 物理清理失败后可重试，上传重试保留原对象，旧上传回滚移除本轮对象 |
| 文件和复杂关系 | 改名传播、多值改名、稀疏级联各与文件引用共同提交或回滚 |

库、账号和所有权记录清理后，从新 SSH 连接重新核验均已不存在。测试中的对象故障采用用例内的受控注入。该轮结果计入实库集成，浏览器、真实第三方存储和性能各按独立场景记账。

## V620 当前 Production 分库 HTTP

用同一版本的 CLI 在独占副本中为示例客户配置两列文件字段，访问级别分别为受保护与公开。通过原生成器生成 14 个后端归属文件，再严格发布 51 个 Windows Production 宿主文件。测试元数据仅用于本轮合成客户。

| 范围 | 真实结果 |
| --- | --- |
| 登录和权限 | 真实密码登录写者、只读者、无页面权限账号和平台所有者。三个普通账号的页面权限分别为 `is_all`、`is_query` 和空集合。只读者可读详情及已绑定受保护附件，修改被拒绝。 |
| 路由和物理归属 | 匿名可用发布项目提示下载公开附件。匿名受保护下载、无页面授权角色下载、未切换项目的平台所有者下载均被拒绝。公开请求缺少项目提示、指向平台或指向额外配置连接但未发布的项目也被拒绝。独立 SQL 核对客户、三条文件记录和两条引用位于业务库，平台端会话和本轮账号没有写入业务库。 |
| 事务失败 | 保存同时修改备注并绑定仍在待上传状态的文件，服务拒绝。客户、备注、三条文件记录和两条引用前后逐值一致，原受保护文件再次下载，内容字节和 SHA-256 一致。 |
| 删除与退出 | 被引用文件拒绝直接删除。删除客户后，两条引用失效，原只读下载被拒绝。三条文件记录转为已删除，本轮实际内容对象为 0。四个 Web 会话已注销，SQL 读回均已失效。 |

37 个请求均符合预期，包括 24 个成功的业务响应、3 个字节校验成功的文件响应和 10 个预期拒绝。按原 Web 协议记录 HTTP 200 与响应体 R500 的拒绝结果。三轮分别使用独占双库、临时账号、Redis 和回环转发。首轮测试客户端未正确释放 HTTP 连接，业务请求数为 0。次轮将业务库存在身份表误作串库。最终轮核对本轮合成行的实际位置，并确认业务库存在身份表且无本轮账号。三轮均独立核清库、账号、所有权记录、Redis 容器及配置目录、本机转发、运行时存储和私有设置。

此处为当前固定候选的本地文件存储和原 HTTP 验收。浏览器及 S3 证据仍按 [V529](platform-split-s3-mobile-layout-v529.md) 和 [双图矩阵](current-mobile-s3-picture-matrix-v549-v550.md) 各自的版本与范围记录。
