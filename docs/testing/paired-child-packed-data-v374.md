# V373–V374 同父明细多行写入数据层验收

2026-11-06，基线 `f9277dc`。把已验证的多行命令落实到 MySQL 关系维护数据层。仅有同事务结构证明、同一固定父候选、规范父键、原 ORM 参数、会话变量及连接重置支持时才会接管。每个命令允许 2 至 7 行，实际文本报文预算包含每一次参数替换；预算不足或绑定不匹配在发出命令前回退。

每行仍执行当前父候选、来源锁读、单行插入与原缓存更新及物理读回。首错状态阻止后续行访问实际主键。驱动在更新前接收独立预期值，随后核对受影响计数、实际来源 ID 和物理值，失败保留原 SQL 异常及 Excel 行号。每个事务使用一组私有会话变量，跨命令清空并复用，失败时连接重置负责回收。
