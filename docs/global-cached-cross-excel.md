# 全局缓存名称级联的Excel往返验证

2026-10-31，B110；产品来源保持48ea249，本批仅测试与文档。原页面、模板、接口、导入导出开关及公开Full门槛均未改变。

## 实际验证

复用B108/B109同一元数据，实际生成C#后调用原生成的私有导入解析器及公开导出方法。新增八个R1模型：缓存名称分别在根/中/末、全部全局角色，以及共享地区分叉和短级联；覆盖string/int64源键、父键和大于JavaScript安全整数的ID。目标名称来自已证明的全局R1物理缓存，不额外联查原始字典名称。

- 完整路径、根/中层尾空路径、空值、导出后再导入逐级ID保持。
- 共享两个控件按两种JSON顺序解析，冲突整行拒绝；清空主控件仍保留仓库路径的共同祖先。
- 固定状态、逻辑删除、父键范围实际参与读取；来源异项目记录不能进入导出。
- 同父缓存名称重名、无法唯一解释的旧简写和未知名称拒绝；导出也拒绝无法唯一还原的文本。
- 每次导出使用一次适配器快照，导出阶段不新增ForUpdate；ADO写入/联网均拒绝。原读取表达式真实执行，不将未知SQL静默视为通过。
- 每份模型重复生成保留手写partial，输入元数据不变；公开前端/Full的未验Excel门槛继续拒绝。

联合回归27项全部通过、零失败/跳过：新增8、原共享8、来源角色11。核对原共享编译辅助函数后，新增八个独占生成工程显式将编译警告视为错误，再次定向8项全部通过；与前8项重叠，不累计为额外模型。外层测试命令同样带-warnaserror。

首轮新增测试变量重名未编译；第二轮八模型都在错误的SQL轨迹断言处失败。实际来源项目条件是强类型表达式，异项目种子已被排除；移除错误轨迹断言及未使用的SQL解析分支，保留真实排除检查。没有因此修改产品授权、范围或SQL编译器。原失败日志/TRX保留。

## 边界与证据

这是受控ORM/ADO传输上的实际生成方法验证，不是MySQL原生SQL、锁、隔离、完整DML、正式Web/OAuth、文件/批量回滚或浏览器验收；R0实际Excel读取继续待验。B14和完整发布门槛不标完成。原27项中R0/派生来源组合只做既有编译范围，不能转记为真实解析通过。

实际命令在固定DOTNET_HOST_PATH下对Metarill.Generation.Tests执行Release、--disable-build-servers、-warnaserror，并按GlobalCachedCrossExcelGenerationTests、CrossTableExcelSharedGenerationTests、CrossTableExcelSourceRoleGenerationTests筛选。日志在交付根忽略目录 `.local/global-cached-cross-excel-{first,second,final,strict}.log`，后三轮TRX在 `.local/TestResults` 同名前缀。最后保护核对776项原前端/模板/元数据和生成文件逐字一致；本批未重新运行平台CLI再生成。

本批没有数据库或云对象操作。独立B106正式四库验收仍以其固定执行器、专属租约及结果为准，不由本测试替代，也未把此处新模型混入该冻结来源。
