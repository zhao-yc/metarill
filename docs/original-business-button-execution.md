物理记录必须通过与 Agent 共用的正式生成 Service 证明：唯一生成 Controller 标记、页面/表/程序集和 Service 注入关系、准确 Reader 签名以及当前请求 Scope 的唯一实例。实体 ID 与原外层 ID 冲突、指数/浮点/非正 ID、错误路径、重复处理器或缺少生成服务都拒绝，不能执行手写业务。字符串 ID 不经 double。

## B492 业务按钮读取和锁定的文本父键

生成服务的按钮根记录读取和写事务排他查询对已发布的物理文本父键使用规范十进制及二进制等值比较，与 B491 的派生规则读取一致。同页有文本及整数父列时，两个条件同时参与记录匹配。正常路径仍先核验已发布按钮和真实身份，非法父键在提交 ORM 命令前拒绝。

以 b723f451 为基线，三个生成模型均遗漏固定文本父键过滤。修复后验证非冗余单文本父键、非冗余文本和整数同父、冗余单文本父键。使用实际生成服务捕获读取的 SQL 与约束参数，并在合成事务检查根查询保留排他锁及同一个文本谓词。3 个生成模型和 5 项相邻回归通过，API 严格编译无警告，717 个受管文件再生成一致。

已有生成应用可用同版生成器更新后端。原列表和详情的中央按钮请求只有按钮和记录标识，尚不携带所在父范围。候选方案仅由带父范围的页面在原路径查询串附上 parentId，保留原正文和操作，由生成服务核对实际父范围。协议调整待确认。本批未运行实际 MySQL 锁竞争、正式浏览器及性能验收。

## B493 业务按钮写事务核对实际父级

带父范围的业务按钮在生成服务调用锁定或直接更新时，先验证当前按钮权限，再使用发布页面已有的父记录校验。普通项目父记录按真实项目和软删除状态进行当前锁读。父范围校验通过后才锁实际业务记录，后续仍按 B492 核对文本或整数父字段，同一个事务完成检查及写入。仅使用标准生成服务的手写业务也能得到两条入口的一致校验。

基线 e07e4730 的三个物理父范围模型进入按钮锁定时，ORM 首条记录查询直接指向子表。修复后捕获两条真实生成写入口的第一条 ORM 命令，确认它验证项目、父主键、软删除及排他锁，且发生在同一事务的按钮当前权限验证之后。3 个模型及 21 项相邻回归通过。用正常生成入口同步了平台字段配置和页面配置两份服务，并更新归属摘要。平台按钮权限定向回归通过，API 严格编译无警告，717 个受管文件重复生成一致。

已有生成应用可用同版生成器更新后端。原 Web 按钮父范围传参方案继续等待确认。正式 MySQL 并发、浏览器及性能验收留待后续。

## B494 业务按钮执行前的父记录快照

带父范围的生成按钮在业务回调前先核验已发布按钮和当前身份，再在同一可重复读快照验证实际父范围并读取业务记录。普通物理父记录通过项目、真实标识和软删除条件核对，执行前读取不加排他锁。派生规则直接在同一事务装载。按钮写事务继续执行 B493 的当前权限与父记录锁。

以 b1dcb6a7 为基线，三个普通父范围模型的按钮执行前查询直接读取子表且没有共享读事务。修复后对真实生成程序集截获首条命令，覆盖非冗余单文本父键、同父文本与整数、冗余单文本父键。离线 Agent 回归单独核对公开动作进入父查询，再执行真实派生读取计划验证授权投影；外部 MySqlConnector 连接和真实锁竞争留待实库专项。3 个模型、21 项相邻回归及平台权限回归通过。

字段配置和页面配置服务通过正常生成入口同步。API 严格编译无警告，717 个受管文件重复生成一致。原 Web 子页按钮的传参方案等待确认，正式浏览器和性能验收留待后续。

## C114 固定条件与父级变量

发布目录使用既有固定条件解析器识别父范围。只有解析得到真实父变量时才要求父记录。等值、集合及带转义引号的文字可以包含同样的拼写，业务查询按字符串绑定。发布目录无法解析的旧条件沿用原父范围门禁。实际子页的原中央按钮请求协议继续按 C18 跟踪。

在基线 f92e4e9f，含父变量拼写的固定文本被误识为父范围。实际生成的 Agent 更新在记录读取前判定为缺失参数。修复后用同一模型验证无父级参数时，原按钮、Agent 显式动作和 Agent 标准记录写入均进入真实记录范围和只读预检。范围表达式的固定字符串经原参数化查询传入。另核对真实父变量两种写法和旧定义兼容分支。9 项生成、102 项 Agent 回归通过。API、CLI 严格编译，717 个受管文件再生成一致。正式 Web／MySQL 验收按进度表跟踪。
