已配置路径在两个并发档均为零轮触线。四并发中 C# 的提交增时主要落在服务端 `waiting for handler commit` 阶段。共享锁允许多个事务同时进入提交，以上为各事务观测耗时，不能视为串行服务时间。两个受控运行同时改变了父锁模式和缓存写入路径，因此只证明这两项一起启用的效果。进一步区分两项收益需要保留排他父锁，仅启用已证明的单次写入。
