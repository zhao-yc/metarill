## 固定范围

来源为普通非冗余实体表，跨表控件的目标为独立、非全局的普通冗余实体。各级使用唯一固定可读页面、真实项目列、物理字符串名称、字符串或 int64 父键及目标页固定条件。来源与父键的四种类型组合均由元数据实际生成并编译，原 DTO、字符串 ID、type=2 选择回读、DisplayText 和页面路由保持。

每个控件只保存最深所选 ID：根、中层、末级分别使用各自的物理位，其余位为 null；多个独立控件各自保存一个选择。各级名称没有物理列，逻辑祖先和当前名称由 B35 的同一固定 SQL 读取计划恢复。不同目标表中的同号 ID 通过层位区分。

读取绑定由完整生成模型冻结实际目标页和常量条件，再传入精简关系目录。ReadPlan 静态初始化直接内联条件表达式，避免引用后声明的静态字段而丢失条件。目标不存在、越项目或不满足完整路径时，保留来源所选 ID，隐藏无法证明的祖先／名称；原筛选对象映射到逻辑 ID，在 SQL 分页和 COUNT 之前执行。

## 写入生命周期

新增沿原默认值、手写 BeforeSave、真实目标路径校验、必填及作用域校验，随后编码稀疏物理值，再进入写守卫和原 DML。正常写入后读取实际物理 ID 及身份范围核验，任何数据库改写先于观察器触发整笔回滚；不追加修复 DML。观察器收到的 ID 与真实稀疏存储一致，不把临时祖先当落库数据。

更新省略整项时不触及原选择，也不附加目标 list 动作。只提交部分 ID 时，先在原事务中以当前更新锁恢复旧逻辑路径，再合并明确字段；例如只清空末级会退到原中层，只清空中层会退到原根。整项全部明确清空时不依赖旧目标，最终所有位均为 null。原整 entity 的祖先和名称仍须经真实路径重算，不能采信伪造回显。

复制先要求旧稀疏存储可唯一解释，再按当前真实目标重新验证并编码。多位同时有值的旧数据明确拒绝复制，不静默挑最深位。手写钩子越界、归属变化、观察器失败及数据库写后改写均整体回滚，目标路径锁持有至原事务结束。

## 更新与回退

本次只修改生成器源头，不修改原前端、共享页面模板、平台元数据或正式生成产物。普通已支持项目无需 DDL；开发中的 R0 crossTable 应先预览并审核各级可空物理 ID 位，再显式同步和再生成。启动不自动改表，不自动删除历史名称列，不替业务数据转换或补回丢失的选择。旧多位非空模型必须先审查历史含义并制定显式转换；不能直接套用稀疏读取。

生成 `.g.cs` 可更新，手写 partial 保留。回退保留数据库列和历史数据，退回原未支持门禁；不自动 DROP 或补写业务库。此批不合 main，不部署生产，提交自身 CI 按 SHA 另核。
