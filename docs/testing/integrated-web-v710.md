# V710 集成候选桌面管理端与独立应用移动 Web

2026-11-09。用固定产品 `cfdfb2fe` 的两份 [集成 Linux 发行包](current-integrated-child-append-v707.md) 在 Server-200 独占 MySQL 8.4.11、Redis 与 Caddy 验收。独立核对新旧两个发行包的前端源文件逐字相同，平台 500 份、独立 Full 389 份。沿用 V696 已核对的原 H5 产物及同一受控回环地址，重新验证两端全部 H5 文件摘要与实际返回的首页。构建来源见 [V696](fixed-release-browser-v696.md)。

固定 311 份载荷在运行前后逐份核对，含 98 份后端宿主、5 份元数据及构建配置、平台 H5 156 份和独立应用 H5 52 份。平台分库、共库及独立应用的实际表数为 24／13、25、13，独立应用结构预览保持空库，显式安装后全表与已发布目录一致。

| 平台管理端 | 1280×840 | 原表单登录、选择 Metarill 项目、加载原菜单、退出 |

MySQL 独立检查平台及独立应用的三份会话均已注销、两个普通角色生效、只读样本保持、编辑记录的最终内容与软删一致。浏览器仅清理两个独占站点并关闭本轮任务空间。独立新 SSH 核对本轮临时库、账号、容器、网络、文件及配置已回收，本机两条转发关闭。

本轮为固定发行包的受控同源 Web 验收。实际发行域名、公开证书、更多角色组合及真实 Tiny Cloud 单独跟踪。MySQL 首版性能及最终验收见 [首版清单](../mysql-first-release-milestone.md)。
