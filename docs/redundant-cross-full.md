# 固定R1跨表完整应用包（B62）

本批接通冗余（R1）固定物理名称跨表链的FullApplication：独立目标、来源参与单层、来源重复层位、各角色独立物理名称、两个独立控件同页及隐藏有效控件。保留原uni-app宿主、页面、样式、交互和模板，继续使用同版生成后端与Foundation。一个控件用途通过不代表整个项目可打完整包，其他字段／页面仍接受原完整审计。

## 按用途证明

原先统一限制R1跨表完整包，现改为逐页检查：本表、来源／候选页及后台明确属于包内项目；每条隐藏或可见跨表链完整可写，所有层的物理ID／名称均有按控制列／key编译的缓存传播绑定；原组件与页面的key、前缀、分隔符和显式JSON属性映射一致。

原映射检查提取为CrossTableFrontendProof，与R0共用同一算法和原拒绝规则；没有重写控件或扩大DTO写白名单。页级角色覆盖、来源父范围／精确权限、R1跨表与自树同页、非冗余／派生／全局目标及其他未证明组合继续拒绝。实际导入／导出用途按原开关与列选择判断，未确认的路径Excel不能因控件隐藏、exportMethod或省略开关绕过。

隐藏有效控件仍完成内部复制／默认值／钩子的证明，不因此暴露ID或名称。隐藏坏同伴与虚拟级联明确拒绝，避免静默丢弃后伪称完整包。失败在创建完整包stage前报告，既有输出不覆盖。

## 原运行时与请求合同

完整包实际从自己的Core／Data／Exports／Files／Security及Host源码构建。通过原本地更新的生成配置、同步运行时、生成全部页面三个动作更新，再核手写partial字节保护。原组件和公共运行时字节保持；新Vue探针从包内加载运行时，既有探针维持原默认路径，R0相邻完整包同时回归。

原详情和真实yzp-cascade-tree组件实际解析、编译和挂载；只受控网络、外部底层渲染，验证回显、中文层key、根／中部分选择、长字符串ID、清空、只读、双控件隔离及整entity保存。它是Node/Vue逻辑探针，不是原浏览器或设备验收。

真实HTTP／MySQL以服务返回的完整VO重新提交：独立链、重复来源默认名称、三层同来源的独立名称字段分别运行。只读countryName／areaName／placeName／显示文本由原LegacyPageWriteContract剥离并以真实路径重算；客户端伪造名称不能落库，私有creating标志拒绝且不写入。没有放宽内部类型DTO或Service权限，固定授权器测试不等于正式网页登录。
