2026-11-05，Windows 和 Ubuntu 的生成测试第六组分别在两项原列表统计及一项普通浮点统计失败。原程序集本机复现三项失败，其余 21 项通过。两类失败均发生于统计夹具进入新 MySQL LIKE 路径时，分别缺失正确的方言身份和 ORM Ado 元数据。
