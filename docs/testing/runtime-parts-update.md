## 实现范围

原设备项目配置保留is_java/java_path/is_uniapp/uniapp_path。C#完整应用更新器新增固定GenerationRuntimeParts(Backend,Frontend)，只表示两端是否选择，不接受路径列表、SQL或任意动作。

- 普通三个单项目请求仍为v1；新增可选字段为null时不序列化。独立旧字段顺序测试核对请求及计划字节/摘要，不能令原确认或持久记录因新增null字段失效。
- 选择分端时，请求和预览计划明确为v2，且只允许一个sync-runtime动作、至少一端；两bool字段必须明确出现。旧CLI不认识新字段/版本时拒绝，不会静默退回两端更新。
- 原始候选仍按完整可信来源生成和严格校验。预览同时约束新增、替换及删除；未选端的源码和旧归属保留，受保护手写文件/原壳不被覆盖。未启用前端时不补建缺失前端壳。
- 根构建文件及src/后端宿主归后端，frontend/归前端。归属清单作为明确的内部记账项合并，可规范排序；未选端清单的原文件记录保持，不能直接用候选整包清单接管。不能以manifest标签伪装另一端源码写入。
- 应用时按原范围重新预览并核对确认摘要。只读状态查询、持久计划及原事务恢复共用范围检查，v2不是仅在预览界面过滤文件。其他配置/页面依赖仍明确返回，不自动增加动作；认证profile迁移不能借分端运行时完成。

本切片只涉及生成基础设施和测试，未修改原页面、样式、组件、交互、前端生成模板或生成产物，也没有执行数据库结构或数据写入。
