# 非冗余字段存储归属与固定读取

物理字段判定及结构/仓储/文件/索引工作台已接线；普通单值非冗余CRUD现已接入正式生成Service、原VO及保存回显。多值、级联、选择、导入导出、传播维护等仍未完成，完整应用发布门槛继续保留。

## 一个存储计划

`MetadataStoragePolicy` 根据整张表的已发布配置编译 `MetadataStoragePlan`，沿用原V8存储规则：

| 项目 | 冗余实体表 | 非冗余实体表 |
| --- | --- | --- |
| 普通业务列、真实关系ID、基础审计ID | 保持物理存储 | 物理存储 |
| 显式虚拟字段 | 不持久化 | 不持久化 |
| 显式联接字段 | 保持原物理存储 | 读取派生 |
| 管理员审计姓名 | 保持原存储 | 读取派生 |
| Title/Tab布局项 | 保持原规则 | 纯布局 |
| 级联祖先ID、各层名称 | 保持原规则 | 读取派生，仅末级所选ID物理存储 |

原始业务`_id`没有明确关系声明时不猜测目标或名称列。自动辅助名与普通业务字段同名明确报错，不能静默吞掉该业务字段；旧App审计姓名必须有明确用户关系。自树与跨表级联分别使用原声明，损坏或重复配置拒绝，不退化成普通物理列。

物理列计划复制字段属性和扩展JSON，不经反序列化让同名扩展键覆盖已验证属性。源元数据后改不能污染仓储已编译列名；这不是允许在线热改物理模型，发布新模型仍须正规预览、生成和更新。

## 实际接线

- MySQL结构编译只使用计划内物理列。启用索引不能引用非物理列；已有未声明历史列不自动删除，切换模式也不会隐式删除数据。
- 基础设施SqlRowStore在构造时编译物理列白名单，普通SQL不重新解释关系元数据；字段值继续参数绑定。
- 文件发布上下文提前编译物理列。派生FileLibrary不拥有本对象的引用增删；父范围只能以真实物理外键、项目列和软删列形成。
- 索引工作台候选与保存复用同一完整表计划，并保留原先所有模式都禁止显式联接/布局索引的限制。冗余模式合法审计列仍可保存配置；非冗余审计显示及级联祖先列不再误入候选。
- 基础设施物理合成把冗余模式计入结构定义，业务声明不能用切换模式改变保留表的物理含义。

公开生成入口在写文件前验证整个批次；普通单值用途编译固定读计划，仍缺接线的用途明确拒绝。缺少显式辅助列也可能需要自动名称，不能以此绕过。无派生项、无关系的纯物理非冗余表保留既有生成。完整包同样报告准确缺口，原前端只读渲染不能代替后端查询实现。

## 固定数据层读取

数据层新增`MySqlNonRedundantReadCompiler`与`MySqlNonRedundantReader`。编译阶段按当前发布项目解析物理字段、明确单值关系、显式联接路径及原自动名称，将依赖变成固定表达式和LEFT JOIN；执行阶段不重新解释元数据。不同角色指向同一表、同表父关系各自拥有别名，真实派生字段循环拒绝。普通业务ID没有关系声明时仍只作物理值，不猜表。

读取计划没有公开SQL构造器或JSON反序列化入口；请求只能使用已编译字段和固定比较枚举。根范围与每个目标的物理项目列、软删除列分别进入WHERE/ON，目标不可见时保留源行且名称为null。项目谓词固定，执行值由宿主已认证Actor参数绑定；数据层不自行授权。字符串和int64项目列使用不同驱动参数，长ID字符串按int64解析，超界/小数ID在连接前拒绝，不经double。LIKE字面包含转义百分号、下划线和转义符；这是数据层原语，原页面各筛选合同仍需生成适配，不能据此宣称已完成接口兼容。

相同表达式及完整过滤范围用于COUNT、排序后分页和SUM。求和只接受已编译数值列，无值保持null；不会按当前页求和。读取加入当前DatabaseSession事务，目标变更可在本事务读取，尾部故障由原事务回滚。无外层事务时COUNT和明细是同连接的两条命令，不额外承诺并发快照一致性，也未作性能对照。

验证包括20项离线边界和1项真实MySQL用例。实库由正式SchemaService预览/应用两个随机自有表，验证同表双关系、自关联、跨级显示、目标软删和项目隔离、派生名称的字面过滤、排序/count/分页、空后续页保留总数、派生数值完整范围求和、当前事务读取和故障回滚、源元数据后改不污染计划。该用例多次重跑不累计为多个实库场景；每轮只在结构和行摘要一致时清理自有两表，并以新会话及独立连接逐表复核不存在。数据访问全工程离线82通过/6跳过，跳过不计实库。

## 正式生成的普通单值CRUD

生成侧调用数据库中立的`NonRedundantReads`，数据库品牌判断及SQL留在Data适配层。项目只生成一份私有`GeneratedNonRedundantReadCatalog`静态快照，随已有`GeneratedRegistration.g.cs`下发，不增加本地助手的文件写入路径；各页在静态初始化时编译自己的不可变计划，普通请求不反序列化元数据。生成校验也提前编译同一计划，非法字段依赖在写文件前失败。

原可读列和自动关系名称进入VO；用于筛选、默认排序、真实Actor项目和父范围的隐藏依赖独立登记，不因参与SQL而返回。源对象的项目/父条件仍在服务附加，客户端filters不能替代。普通页读取沿原父键谓词，新增/复制仍复用原真实父对象校验；本批不把它们说成覆盖所有选择页、双父关系或完整权限体系。

持久化实体保留显式派生属性供代码使用，但FreeSql标记`IsIgnore=true`，主对象更新前的`FOR UPDATE`只读物理列。DTO不接收派生写值，原完整表单的只读别名由LegacyWrite剥离；复制只复制物理业务列。新增/更新/复制完成同事务观察者后，以相同项目/父范围重新读取VO作为回显；不存在时事务失败。回显不额外要求list/detail动作，保持原创建权限下的响应行为。

正式生成已接普通单值List关系、明确联接字段及自动名称，原查询白名单、日期范围、集合筛选、已选ID、排序、配置不分页和分页边界继续生成固定请求转换。原`map.statistics`保留SUM和等于2百分比口径；完整范围聚合在SQL执行，当前页统计仍折叠原VO。

尚未开放：SelectPage控件、导入导出、全局/派生候选名称、多值、级联、布局、JSON数组、页级控件覆盖和固定安全模块的非冗余用途。它们在写文件前明确报错；完整包及用途投影的门槛继续保留，不能用已生成的普通CRUD取消整体未完成项。前端源码、原模板页面、样式和操作均未更换。

## 非冗余type=2独立选择页

原`selection/selected`路由、请求和行数组响应继续复用。独立type=2页的非冗余已选回读改走同一静态固定计划，再投影本页原VO及派生名称；不会改为物理实体查询，也不会把页后补名当作SQL过滤。原ParseIds限制原始最多200项、正整数字符串及去重首次顺序；返回数量必须完整命中，混合其它父/项目、软删或失效项整体拒绝，错误不带合法子集。

分页、数量、详情和已选回读统一使用选择页现有真实父记录检查，包含空选择；父对象必须属于当前Actor项目且未删除。父校验只读、不申请记录写锁，普通非选择页的既有父谓词不变。type=2的PageRequest仍限最多200个已选ID及页码1000000，原列表动作授权在控制器先执行。隐藏项目/父列继续只作依赖，不扩成VO字段。

当前验证以同一正式生成HTTP/MySQL场景扩展，覆盖去重顺序、派生字段、空选择、混合失效项整批拒绝、旧坏父数据下四读取入口拒绝、原始数量与页码上限及list拒权；仍使用固定测试授权器，不代表原网页登录或浏览器。普通CRUD/统计/候选/事务回滚同时回归。原type=2页面Node探针另执行真实生成脚本，网络及宿主事件替身不冒充浏览器。

这是独立选择页，不表示非冗余MultiSelectPage字段、SelectPage名称筛选、全局选择、复杂双父绑定或完整应用包已经支持；相应门槛继续保留。前端源码与原模板没有改动。
