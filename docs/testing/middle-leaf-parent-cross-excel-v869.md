# V869 中层和末层父范围级联 Excel

2026-11-10。固定 d13e21ab 的生成器，将同一非冗余三层跨表链分别绑定中层和末层父范围。隔离准备包包含 700 份清单文件，69 份 Release 宿主严格构建。Server-200 独占 MySQL 和 Redis，首次预览 16 项且仍为空库，显式安装后重复预览为零。

| 场景 | 实测结果 |
| --- | --- |
| 中层父范围 | 原普通身份可追加当前父的中层及完整路径。空级联保留请求所绑定的中层父 ID。仅到根的非空路径、私添中层父字段和越过父范围的路径被拒绝。第二行越界时，独立 MySQL 确认合法首行也回滚。 |
| 末层父范围 | 复核原 Java v8 的 appendNonRedundantImport，父字段取请求上下文且从逐列导入中跳过。使用原模板允许的名称与金额列导入，末层 ID 由请求绑定。第二行私添级联列返回 400，整个批次回滚。 |
| 原导出与回导 | 两种父范围各下载两份实际 XLSX。请求中的选中 ID 同时包含两边记录，每个工作簿仅包含对应父的记录。四份文件通过原 SheetJS 解析，中层四行直接回导。末层的展示路径保留在导出中，回导时按原模板只提交两列，成功回导两行。 |
| 物理读回与清理 | 独立 MySQL 核对最终 12 行、字符串长 ID 和稀疏层位。21 个真实 HTTP 中有 4 个预期 400。独占库、账号、所有权、Redis、私有配置与两端转发均独立确认释放。 |

本轮使用内部准备包，覆盖中层和末层固定父范围的实际运行行为。公开 Full 门禁扩展和公开包正式复验仍待完成。根父范围的公开包证据见 [V868](public-root-parent-cross-excel-v868.md)。
