# 来源父范围与固定目标级联树

普通冗余来源页已有标准父归属Scope、ValidateParents和导入Core，却被级联读取编译器整体拒绝。本批解除这一重复门禁，复用同一生成计划；原页面、组件、样式、交互和接口不变。目标仍须是唯一、名称与父列可读、无目标父参数的普通页面；没有把来源父键当成目标范围。

## 两种父概念与权限

列表、数量、统计、已选、导出请求中的parentId，以及明细/新增/更新/复制/删除的原query参数，约束来源记录所属父组。它进入固定页面谓词，真实项目仍来自Actor；新增/复制/导入先确认父记录存在、未删除且属于当前项目，并在原事务中锁住父记录。

原级联候选只传levelKey和selectedPath.parentId，后者是目标树本层父节点；路径回读仍只传leafId。候选不读取来源记录，也不新增来源parentId要求；来源页和固定目标页list权限、目标项目/软删/页面条件继续生效。来源行展示、筛选和Excel复用既有读取权限；显式普通关系写入需目标list，内部导入维持来源import动作。

原HTTP完整表单中的来源父字段只能回显当前上下文：与query父键不一致直接拒绝，不能覆盖归属；匹配值经规范化剥离，再由Service绑定。跨父组更新/复制/删除不能命中别组记录，跨父详情不返回行；已选列表混入越界ID时整批拒绝，不能以过滤后部分成功替代既有合同。

## 导入导出与事务

导入保持requestJson和parentId；来源父字段不作为可写Excel列，覆盖匹配限定在同一来源父组。同名记录位于另一个父组时不被覆盖。完整路径逐层名称解析、默认值、省略/null、固定目标条件和整批回滚沿用原级联实现。

真实XLSX仅包含当前来源父组，树单元格保持根至叶完整路径。后行无效、观察者故障及非法父记录都不允许部分写入；父记录当前读锁保持至事务结束。

## 更新与边界

已有C#项目更新生成器，再生成对应Service、Controller、DTO/VO后构建，保留手写partial；本批无需新增DDL、回填或前端修改。现有元数据父条件继续作为单一事实来源。
