## 实现范围

共享控件共同使用国家／地区等槽位时，每个物理名称缓存仍只登记一次。新增可选的 `CrossTableGlobalPages` 映射保存当前控制列的全部全局层目标页，避免共同缓存去重后，独立仓库控件失去共同祖先的页证明。映射只在真正的全局共享控制列发布；普通关系及原单控制列定义不增加空 JSON 属性。

编译器按当前完整固定链逐层验证：全局声明、模型与页面发布归属、R1 物理目标、物理标量名称、规范主键和父键；映射必须完整且只能包含当前控制列的全局层。直接层页与映射冲突、缺层、额外层、空标识、错表页或未发布页均拒绝。共享去重还要匹配当前页面各控件自己的完整映射，不能从另一分支猜页。编译后计划只保留原不可变执行绑定，不持有输入字典。

生成写入继续调用原共享协调器、各控件固定目标页和事务内当前读，不增加前端协议。全局来源、来源自参与、全局 R0 目标、动态目标范围和来源精确权限等未证明组合仍按各自门槛拒绝。全局共享控制列的页级覆盖不能改变固定存储和传播定义。

文件父范围由同一编译链收齐全部分支。只有明确发布的全局目标省去目标项目等值条件；纯固定条件、软删除、真实祖先、来源项目、页面权限和文件引用所属项目继续保留。读取沿用原快照，写入及物理删除前使用原事务的 `FOR UPDATE`；不能以浏览器提交的祖先值代替数据库实际父链。
