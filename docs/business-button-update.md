# 业务按钮的共同生成更新核心

2026-10-28，C18。这里完成的是普通业务表的标准字段更新与内部来源传递；不代表三个Agent业务动作、真实文件/并发/回滚或完整首版已经验收。

## 已实现

生成器为具有固定actionType=1业务按钮的页面增加 `UpdateButtonRecord{pageId}Async`。它接收同页严格Update DTO，由服务端传入固定按钮，先校验真实Actor和已发布按钮，再进入普通更新/导入复用的同一个私有更新核心。普通更新关闭时不生成对应普通Service入口和HTTP动作，固定按钮仍可使用其内部更新入口；不为此额外授予page query/update。

仍使用原字段存在性与白名单、审计、BeforeSave partial、对象/关系/必填/归属校验、准备/最终守卫、Mapper及观察者。新入口只处理同页DTO声明的字段，不是任意字段或任意表写入工具。普通入口与导入仍保持自己的原授权来源，不能借按钮入口降低权限。后台、账号和角色等特殊对象继续保留原守卫及对象操作规则。

内部 `BusinessButtonId` 显式进入准备、最终校验及观察上下文，构造参数保持，且不参与JSON输出。业务DTO没有新增来源属性，提交该属性会由严格DTO拒绝；没有新增Controller路由。安全协调器要求准备与最终来源一致。该来源不替代真实身份、发布归属和当前权限的核验。

文件观察器用实际按钮检查这次更新来源；只接受既有记录更新，空按钮、无主键、创建、删除、导入、复制及未知来源状态在授权前拒绝。其余文件规则保持：同一事务/连接、实际记录与父范围、字段开放、类型/数量/大小/扩展名、文件所属项目及保护文件读取证明。普通文件入口仍使用原页面动作。
