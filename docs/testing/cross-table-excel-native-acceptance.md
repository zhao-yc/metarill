## 用例

一个新库和临时账号承接八组普通物理目标：R0／R1来源存储分别交叉末级字符串／整数引用及目标父字符串／整数引用。保留32张原业务表、32页、八个原Excel入口、显式祖先及受保护附件，连同安全／文件／Agent基础设施计划共43表。页面模板、样式和操作均不改。

执行器首先验证专属批准状态、用途、产品来源、随机编号、固定包根、完整文件集合及实例，再执行零表启动和显式预览／重复结构安装、真实Web初始化与普通账号登录。每组验证：

| 场景 | 断言 |
|---|---|
| 完整／根／中层／唯一旧短写／数字名称 | 原中文表头导入，独立会话读取真实ID；R0只保留最深槽且不存名称，R1保留已选祖先。 |
| 歧义与范围 | 无效层、同父／跨层重名、隐藏目标、外项目目标、显式祖先冲突、隐式字段名整批拒绝，业务及文件物理摘要保持。 |
| 省略／清空 | 覆盖仅更新金额时路径不变；明确空路径清空，然后恢复完整路径。 |
| 原XLSX往返 | 用真实下载票据读取生产XLSX路径文本；将这些路径放入原导入列工作簿，通过原chooseImportFile本体及仓库SheetJS读取，再把实际回调JSON提交原importDatas接口，复核物理ID。不是把手工构造JSON冒称原Excel回读。 |
| 已写入后回滚 | 批次第一行真实保存并同步附件引用；第二行手写BeforeSave必须在同一事务读到第一行及1条文件引用后才拒绝。独立连接比较全部业务表／文件表，包括墓碑，确认整批撤销；另保存成功行及下载原文件流对照。 |

手写钩子只用于独占合成样本，没有替换生成CRUD、身份、Controller、SQL、权限或文件观察者。它只读取当前事务并在预期第二行抛出故障；观察记录写到包外私有证据。原生产包和运行时没有故障入口。
