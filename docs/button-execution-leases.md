# 原按钮跨实例执行租约（2026-10-29）

本批继续 C18，沿用固定 Java 样板中 ConfigButtonControllerSys 的按钮粒度、30分钟有效期、忙时立即返回及只释放本所有者的规则。前端页面、确认、提示和刷新协议不变。

## 实现

`IBusinessButtonExecutionGuard` 是 Core 合同，`DatabaseButtonExecutionGuard` 是统一执行守卫。普通业务按钮中央入口、平台配置按钮/旧直调别名及显式Agent动作共同消费它。标准CRUD及读取接口保持原路径。

发布项目与按钮ID确定作用域，不把账号、记录ID或客户端工作区加入键。同按钮不同用户/记录仍互斥。平台使用 TargetDatabaseSessions 按真实发布项目选择协调库，独立应用固定本项目及本库；缺少数据库实现时明确拒绝，不降级为进程内信号量。

MySQL适配器以预期库及固定用途/项目/按钮计算64字符SHA256命名，使用独立不入池连接执行参数化 `SET SESSION wait_timeout` 和 `GET_LOCK(...,0)`。取锁忙时不调用业务，返回原“按钮正在执行中，请稍后再试”；这个连接不加入或关闭业务事务，业务仍使用原Service/Business的事务。

命名锁本身没有TTL。本批同时设置独占连接的服务端空闲时限和本地单次计时器；协调连接不承担其它业务命令。取锁响应交付耗时计入有效期，计时回调延迟时仍可由单调时钟识别到期。取消、异常及到期都只关闭自己不入池的连接，不重连、不借其它连接执行RELEASE，不会删除后继所有者的锁。清理失败沿原行为记录提示，不能把已经完成的业务改写成回滚，也不能授权自动重发。

30分钟到期释放不代表原业务已结束，长任务仍需自己的业务状态约束。该实现要求应用实例连接同一个MySQL写实例，拒绝配置中的多地址负载分担；多写服务器不是本批验收范围。

## 入口与账本

- 原页面业务按钮先完成Web、发布按钮、可见规则及真实生成记录范围证明，再持租约调用显式手写处理器。
- 平台配置按钮与原首页直调别名使用相同真实数据库按钮ID，保持原管理员/配置归属规则，不添加身份门槛。
- Agent显式动作先按原规则登记任务，再持同一按钮租约执行；忙或协调故障继续原unknown、查询任务和不可自动重试规则，不把“尚未进入回调”改造成可自动重发承诺。
- 调用者把守卫放在完整动作事务之外，回调要等待原Business提交/回滚结束后才返回；普通Service不以按钮锁代替行范围和事务。

## 实际证据

真实MySQL只使用Server-200既有 `metarill_business_test`、独占随机锁及自己的连接变量，未创建库/表/账号、未授予权限、未读写业务记录。先固定服务器UUID，再启动引用本轮真实Data工程的独立进程。

复验1项零跳过通过，覆盖不同进程同键忙拒绝、不同按钮可独立执行、正常释放、进程崩溃释放、关闭本地到期回调后的真实服务端2秒到期，以及旧所有者晚清理不能释放后继者。最后用新连接重新核验固定实例和全部随机键空闲。生产30分钟参数另由传输合同验证；服务器到期路径用缩短租约验证，未等待30分钟作耗时测试。

首轮子程序已有编译产物且无存活Worker，但主测试未回收输出；精确停止该轮测试树并保留记录。修复SDK服务器复用和输出回收边界后，复验前用新连接核零首轮三个键。首轮不能记为实库通过，复验回执、独立核零和TRX分别保留于 `.local/button-execution-leases-20261029`。

这仅证明租约组件在真实MySQL的行为；完整应用多实例Web/OAuth/业务并发、跨连接权限/事务、文件与回滚场景及同条件性能仍待。B98冻结产品、执行器和待回复范围没有修改或扩用，主目标保持进行中。

## 升级与受管更新

首次接入及已有应用跟进都需成套同步Core、Data、Agent、Runtime和宿主注册并重新构建；原按钮Reader与手写partial保留。候选完整包不能通过同时裁掉源文件和清单来伪装支持租约，更新器要求Core合同、Data租约合同、MySQL实现和统一守卫四个必要文件。旧目标仍可预览显式运行时升级。

本批没有表、字段或索引变化，无DDL/回填和前端操作变更。未来数据库在适配器完成独立实现及真实验收前继续明确拒绝该租约能力。

## 原理来源

- [MySQL 8.4命名锁函数](https://dev.mysql.com/doc/refman/8.4/en/locking-functions.html)：锁归属会话、会话结束释放、64字符限制及单mysqld范围。
- [MySQL wait_timeout](https://dev.mysql.com/doc/refman/8.4/en/server-system-variables.html#sysvar_wait_timeout)：独立连接的服务端空闲到期。
- [MySqlConnector连接池](https://mysqlconnector.net/connection-options/#connection-pooling-options)：池化连接关闭会回到池，本批协调连接显式关闭Pooling。
