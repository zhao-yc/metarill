# V777 安装示例的空代理名单

2026-11-09。从固定 Full 包的配置示例复制私有配置，使用空 `TrustedIps` 启动。旧宿主在绑定端口前抛出「反向代理地址必须配置为 IP 地址数组」。平台和生成 Full 调用同一段启动逻辑。

.NET 10 的 JSON 提供器把空数组暴露为空字符串。修复将空数组视为显式清空名单，屏蔽其下各配置来源。位于空数组之上的显式编号配置仍可添加确切代理地址。非空标量、无效地址和通配地址继续拒绝启动。没有受信代理时只用实际 TCP 对端。 [.NET 10 JSON 配置解析源码](https://github.com/dotnet/runtime/blob/v10.0.0/src/libraries/Microsoft.Extensions.Configuration.Json/src/JsonConfigurationFileParser.cs)
