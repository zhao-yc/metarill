# 固定候选条件计划

目标是保留原 V8 候选条件及原前端协议：配置在生成/发布时编译，请求只提供值，查询、已选回读、写入、复制及导入最终使用同一范围。本文区分已经完成的数据适配基础与仍须接入的产品入口，不能把计划类或离线通过当成整个功能完成。

## 已实现的基础

`FixedConditionPlan` 识别字段白名单上的 AND、分组、比较、IN、LIKE、IS NULL/IS NOT NULL、数值/字符串/布尔/NULL 和独立变量符号。字符串中的 AND、逗号、SQL标点和双单引号保持字面量，反斜杠保持字符。未知字段、语句、注释、函数或其它表达式明确拒绝，不忽略尾部；定义、项数、分组和集合大小有界。字段及变量目录和条件节点均冻结。

`FixedConditionSqlPlan` 在编译时固定字段逻辑类型与常量，在数据适配层用已校验标识符和参数占位符构建条件。运行时只绑定显式窄变量，总是 AND 到原查询，缺失或错误变量在修改查询前失败。LIKE 保留模式语义，区别于页面关键词的字面 Contains。=NULL、<>NULL 和 IN(NULL) 保持 SQL 三值语义，不偷换为 IS NULL。整数不经浮点转换，decimal 不静默舍入，非零 double 不下溢成零。逻辑 double 仍是浮点类型，不承诺任意十进制文字无损表示。

真实 MySQL 适配层已经验证高位 ID、LIKE、IN、比较、空值、字符串注入样本、参数化 count，以及整数/文本两种项目列；样本只使用本轮自有随机表。这些适配层验证本身不授予页面或记录权限。下述 List 常量分支另外通过了正式生成 Controller 的 HTTP/MySQL 验证。

## 已接入的 List 常量条件

原 List 字段及页面级 controlDetail 覆盖可以在既有项目/父范围上增加物理标量常量条件，支持比较、IN、LIKE、IS NULL/IS NOT NULL、AND 分组及字符串中的 AND/逗号。生成阶段验证完整语法、物理字段、逻辑类型及字面量，常量候选目标必须与外键及显示来源一致；生成 Service 中的静态不可变计划在装载时再次核对同版运行时，请求只绑定真实 Actor 项目和已经验证的目标父，不重复解释配置 SQL。

原数组候选、分页/count、已选回读使用同一 OptionsScope。新增、明确字段更新、默认值、标记提交字段的手写钩子和复制重新核对最终真实实体；目标父依赖字段改变时，即使没有提交关联外键也重验。写入通过同事务 FOR UPDATE 当前读检查真实父和选中目标，避免已有 RR 快照的计数误拒绝及父删除绕过。读候选不取写锁，普通写入仍沿用本页动作，不增加目标列表权限。

名称/数字导入使用同一候选范围；原目标父拓扑、默认及已锁定实体上下文保持，不能依赖 Excel 属性顺序。后行失败回滚整批。条件本身是候选限制，不额外改变来源记录详情及文件读取权限。

正式生成、编译及实际 HTTP/MySQL 已覆盖旧数组与专用已选、分页/关键词/count、默认与钩子、更新失败回滚、复制、合法与非法导入、乱序父依赖和父变化重验。另用两个普通连接验证 RR 当前值、父删除、目标/父锁等待、无关目标可写及提交释放；未新增全局或列级观测授权。原前端、请求槽及平台元数据不变。

## 仍须接入的完整路径

页面级扩展 WhereSql、formParameters/账号扩展变量和额外单选/多选条件仍保留拒绝检查；不能把 List 常量接线推广为所有控件或完整复杂 SQL 已完成。后续必须完成：

- 页面固定查询、关系选项、单选/多选目标及文件来源采用同一条件证明；配置来源、字段、排序、页级覆盖和已发布目录不能由请求替换。
- 原 formParameters 槽按已编译的依赖取值；身份变量由宿主建立，不能用客户端对象覆盖 current_*。账号变量只捕获已声明的窄字段，不能保存整账号或凭据。
- 写入按真实实体及当前锁定对象验证，关联外键或依赖字段变化都须重验；复制、默认值和手写钩子不能绕过。不能为了候选联动额外增加目标维护权限。
- 导入拓扑包含全部条件依赖，保持原追加/覆盖匹配规则，后续错误回滚整批；已选回读与普通候选不能采用不同范围。
- 参数化 SQL 必须在同一完整范围内完成分页/count/统计和写前当前锁定，不能先分页再过滤；未证明语法不得去掉条件继续生成。
- 最后通过正式生成包、真实 Web/MySQL、原浏览器和所需并发组合，才逐项放开能力门槛。复杂原生 SQL 仍需明确数据库方言及完整执行证明。

本阶段没有改前端、接口、平台配置、平台/现有业务库物理结构或现有生成产物，不需要 SQL 迁移。使用 List 常量条件的项目必须配套同步已列出的条件运行时和重新生成的 Service；其余未接线路径不能手工删掉旧拒绝检查。
