# 自关联级联候选与路径读取

本批补齐原 `yzp-cascade-tree` 的自关联树读取入口，保留组件、页面、样式、事件及请求结构。它是完整级联能力的一个切片；已接线的生成Service写入与名称维护另见[写入合同](cascade-tree-write-contract.md)，不能据读取单独宣布完整级联或应用包可用。

## 原协议

生成页继续使用 `POST /api/admin/auto/{表}/{页}/cascadeTreeOptions{字段ID}`，正文为 `levelKey: selfTree-层号` 和 `selectedPath: { parentId }`；根级parentId为空文本。响应为原 `R.data` 数组，每项保留字符串 `id/value`、`name/text` 和 `hasChildren`。

路径地址仍为 `cascadeTreePath{字段ID}`，正文只传 `leafId`，响应为 `path: [{id,name}]` 与 `displayText`。空叶子返回空路径，但仍检查权限。ID数字不经过浮点转换，兼容高位字符串ID；未知请求字段、重复parentId、非标量/非正整数及无效层号拒绝。

## 固定编译与查询

元数据及非空页级明细覆盖决定固定目标；读取不解释客户端表名、排序或SQL。当前仅接 `selfTree`、普通冗余物理表、主键id、字符串名称、字符串/int64父列及blank根模式。目标需要唯一且名称/父列可读、无父参数的普通页面；目标父参数、非冗余、跨表、特殊安全服务、歧义目标及额外查询范围继续留明确缺口，不回退宽查询。

来源页和固定目标页均要求list权限，Service复核真实Actor。每次查询使用目标页固定常量、真实项目及软删范围，未明确全局的目标必须有项目列。候选和每跳路径只读取id/name/parent三列，hasChildren仅投影父键；隐藏业务列及条件依赖不进响应。

非根候选先确认完整可读祖先链。不存在、越权、软删、被页条件排除的祖先、循环或超过 64 层均整体拒绝。单层候选的最新范围见 B220。

## B222 空请求与空名称

原自树候选允许省略 `levelKey`，`selectedPath` 可为空对象、`null` 或省略。已提供的层号仍需符合自树格式，父对象只接受合法 `parentId`。候选和公开路径对数据库空名称输出空字符串，同时保留节点 ID、顺序和子节点标记。`displayText` 跳过空白名称。

写入和名称维护继续使用内部路径的真实名称。Excel 导出沿原规则拒绝无法无损反查的完整路径。30 项定向回归通过，包含字符串和整数父键的实际生成候选及路径调用、大整数 ID、空白层和 Excel 回归。专项实库、浏览器和性能留待后续。已有应用更新 Core 和生成器后重新生成。
