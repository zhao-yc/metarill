# V916 同合同性能的历史通过轮与当前轮对照

2026-11-10。对照 [V819 历史通过轮](append-layout-mysql-performance-v819.md) 与 [V899 当前正式轮](current-exact-child-performance-v898-v899.md)。校验两份实际发行 Full ZIP 和压测镜像载荷清单，从 ZIP 提取七个公共程序集，逐文件验证为各自实测镜像中的载荷。V819、V899 的 8 份基准专用文件摘要逐项一致，其中包括实际加载的 Application.Host、观察器和项目元数据。

七个程序集共比较 8,849 个归一化方法体。Data 的 3,057 个方法体全部一致。唯一差异是 Core 的 `PageImportException.MessageFor` 增加了覆盖导入重名提示，本轮追加导入成功样本未触发。当前两次隔离诊断均重现退化，见 [V915 隔离对照](current-child-isolated-control-v915.md)。

两轮原始测量分别按归档摘要校验。每轮均完成 1,200 笔正式请求及 32 笔预热，每端 4,928 条物理新增行。Java 镜像、容器限额、回环传输及两档各自的三轮交替次序一致。两份八行 XLSX 仅 8 个合成行标签中的运行编号不同。将这 8 处限定前缀归一化后，工作簿内 10 项内容摘要均相同。

| 四并发三轮中位数 | V819 历史轮 | V899 当前轮 |
| --- | ---: | ---: |
| Java p95（毫秒） | 517.56 | 509.62 |
| C# p95（毫秒） | 526.07 | 584.57 |
| Java 吞吐（批／秒） | 9.194 | 9.411 |
| C# 吞吐（批／秒） | 9.252 | 8.984 |
| C# 容器 CPU（毫秒／批） | 22.68 | 22.28 |
| 触线轮次 | 1／3 | 2／3 |

当前轮的 C# p95 上升、吞吐下降，C# 容器 CPU 用量未呈现同向增长。历史轮记录的 6 项 MySQL 设置与当前相同，当前新增核对的 7 项 binlog、持久化及组提交设置在历史回执中缺失。两轮也发生在不同的实例负载窗口，已有证据无法复原完全相同的数据库背景条件或解释绝对时差。回退至 V819 的 Data 层没有已测到的代码变化作为依据。

保留现行实现及既定门槛。后续针对锁内缓存和提交开销的候选，仍须独立验证父范围、缓存物理值、末行失败整批回滚及无观测正式回放。V899 继续作为当前同合同性能发布判断。
