# MultiSelectPage 冗余字段子集

本增量恢复可由现有元数据证明的 `MultiSelectPage` 冗余字段。它复用已完成的 `type=2` 独立选择页和原弹层交互，不将整个多值控件标为完成。`generation-capabilities.json` 按固定表、列、来源页、目标页 ID 输出 `supportedControlSubsets`；范围无法证明的字段仍列入 `unsupportedControls`，界面保留原值并只读提示。

## 原协议与存储

旧 YZP v8 `UniappService.java:1099-1158` 将目标生成列表嵌入弹层，传入 `selectedIds`、`selectedNames`、`selected-name-field`，由 `onPopSelect(row[])` 接收完整行并映射 ID/名称；`onPopClose` 仅关闭。`JavaService.java:2276-2346,2765-2807` 和 `runtime/dto/ArrayStringDeserialize.java` 表明 `_ids` 实体保存 JSON 数组文本，HTTP 边界使用数组，同时接受旧已编码 JSON 数组字符串。不能改为逗号存储，也不能把长 ID 转为 JavaScript 数字。

当前请求仍区分省略、`null` 和 `[]`。数组输入保存 JSON 文本，合法已编码数组文本保存原字节；响应中的 ID 和名称为数组。只接受最多 200 个不带前导零的正整数长 ID 字符串；重复、超出 Int64、非字符串、非法 JSON、对象和标量整体拒绝，不截断。名称允许 `null`，数组顺序与 ID 相同。

## 严格启用条件

[MultiSelectCompilation](../backend/src/Metarill.Generation/MultiSelectCompilation.cs) 仅解释已存元数据，页面非空控件明细按旧规则覆盖字段明细。未知合法键保留在原元数据，不执行其中脚本或 SQL。

- 来源表明确 `isRongyu=1`，来源页开放 ID 字段读取，字段是已声明的字符串 `_ids` 列，目标为本批生成的真实 `type=2` 页，关联表声明与页面一致。
- 名称字段必须在真实目标页可读投影内，且为字符串或 ID；ID 名称直接投影原 long，由现有响应边界转为字符串，不让数据库翻译格式化函数。联接派生列、多值列或隐藏名称不得通过实体全列绕过。
- 字符串名称按旧规则定位已声明的名称辅助物理列，例如 `target_ids` 对应 `target_names`。辅助列必须在来源页可读、非系统且非联接列；生成器不偷偷创建表字段。名称选 ID 时无需辅助列。
- 目标页必须有明确项目归属或显式全局定义。目标父只接受同父合同，或来源页唯一可读且关联父表 ID 明确的外键；父表仍须真实存在、未删除且属于当前项目。多父、不唯一和未知父不猜测。
- 控件条件只能重复目标页已安全编译的范围；额外控件范围、任意 SQL、与目标页不同的排序仍拒绝。客户端不能指定表、页、名称列、SQL、连接或项目来替换固定合同。

非冗余表含该控件时在写入生成产物前明确拒绝，因为其读计划与传播尚未实现。该行为避免错误地产生名称实体写入。服务校验按固定表级关系生成，页面可读/可写仅决定 DTO、VO 与界面。隐藏 ID、仅名称投影页不会额外返回 ID；普通保存省略 ID 且未改父依赖时保留原关系，父依赖变更及复制仍完整验证既有 ID。原 `List`、单选和无多选表的构造及注册合同保持原样。

## 写入、权限与事务

[MultiSelectFieldRenderer](../backend/src/Metarill.Generation/MultiSelectFieldRenderer.cs) 生成固定目标校验方法。生成新增、更新和复制进入已有源事务后，使用同一个真实 `RuntimeActor` 验证目标页 `list` 权限，再以强类型参数查询目标项目、软删和父范围，只投影真实可读的 ID/名称。任一所选项不存在、失效或越权时整体拒绝，源行及文件引用保持原状。

名称辅助列从所有页的可写集合排除，直接提交名称会由严格 DTO 拒绝。名称只从当前源事务派生，加入同次源写入；不创建目标记录、不修改目标名称。普通更新省略 ID 不刷新或覆盖历史名称；显式 `null` 同时清空 ID/名称，`[]` 同时保存空数组；显式再次提交同一 ID 仍重新读取名称。改变已声明目标父时即使省略 ID 也重新校验范围，防止换父绕过，但不刷新历史名称。

此增量只承诺操作时的范围校验，不提供跨表读写的串行化承诺；并发目标变更后再次提交仍须校验。反向名称传播、历史回填和关系名称导入尚未交付。

新增 Service 授权依赖只为已启用的冗余多选表注入。`GeneratedRegistration` 及独立包的现有 `IRuntimeAuthorization` 注册均需实际装配；不能以空授权或客户端项目作为后备身份。

## 原弹层交互

[MultiSelectUiRenderer](../backend/src/Metarill.Generation/MultiSelectUiRenderer.cs) 固定导入本批目标列表，保持原 props、完整 `row[]` 和关闭事件。`type=2` 列表不会打开 CRUD 详情，因此编译时不导入/注册不可达详情组件及弹层，允许自身选择与相互选择且避免静态模块初始化环；普通列表保留原详情依赖。[multiSelectFieldMixin](../frontend/metarill_uni_admin/common/yzp_runtime/multiSelectFieldMixin.js) 只把字符串 ID 写入修改字段；名称仅回填当前显示，保存时仍以服务端重新读取为准。数组与历史 JSON 文本以原逗号形式只读展示，缺少名称保留 ID。

取消不写实体、不触发保存；同 ID 确认仍显式提交 IDs。父记录、目标父、项目/身份、只读状态或生命周期改变后，旧草稿及迟到回执不能写回。目标页跨页已选和确认时完整回读沿用 [独立选择页合同](selection-page-mode.md)，失效项整体失败，不能依旧缓存名称静默通过。

平台配置编辑器已通过专用管理员候选接口按 `controlKind:"MultiSelectPage"` 查询真实 `type=2` 页面，复用当前项目及父表归属校验，未放宽普通页面范围。独立 FullApplication 的明确运行时资产清单现已包含 `common/yzp_runtime/multiSelectFieldMixin.js`，由完整包闭包检查验证装配。
