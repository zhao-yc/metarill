## 最后一类客户复制

8,400 个正式请求、224 个预热，逐步核对原新增、复制、读回和删除。两端各 616 对物理写入和软删除记录独立复算，12 个正式资源窗口核对完成。复制审核的最后一步需要前一审核的 JSON。执行器原先仅保存标准输出，结果收回后从原标准输出补齐文件，离线复跑复制审核。
