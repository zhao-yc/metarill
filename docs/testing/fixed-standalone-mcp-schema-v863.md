# V863 固定独立 Full 的 MCP 请求结构与权限

2026-11-10。固定产品 `86775982`，逐份核对公开 FullApplication 的 661 份生成文件与 51 份 Release 宿主文件。Server-200 使用本轮独占 MySQL 和 Redis。首次结构预览报 13 项且数据库保持空库，显式安装和安全初始化后，重复预览为零差异。

| 核对项 | 实测结果 |
| --- | --- |
| 真实协议与普通身份 | 编辑者和只读者通过原 Web 密码登录，各建立真实 MCP Streamable HTTP 会话。两个会话只发现三个公共工具，结构工具只接受 pageId 和 operation。匿名请求及注销后的两份旧令牌均返回 HTTP 401。 |
| 请求结构 | 编辑者的创建与更新结构和固定生成 DTO 字段逐项相同。更新要求 ID，写入 DTO 拒绝额外属性。列表和详情结构在两角色间相同，父参数位置符合原合同。只读者无法发现创建、更新、删除或复制的请求结构。 |
| 实际写入与读回 | 只读者更新、编辑者未确认更新及携带未知字段的更新均拒绝，独立连接读回原行不变。已确认更新省略备注时保留物理旧值，明确传 null 时写为 SQL NULL。列表与详情均返回同一个超过 JavaScript 安全整数的字符串 ID。 |
| 同一会话逐次权限 | 测试夹具只改本轮合成编辑角色的精确权限行。收窄为查询后，原会话可查详情，但不能发现更新结构或更新记录。撤销查询后，原会话无法枚举该页、描述详情或读记录。另一个普通读者仍可读。 |
| 清理 | 独立连接核对两份 Web 会话已注销、合成记录保持。之后核验独占库、账号、所有权记录、Redis、私有设置、临时存储与本地转发均已回收。独立严格 SSH 确认远端 TCP 和 UDP 端口均已释放。 |

44 个真实 HTTP 请求包含 16 次成功工具调用、13 次预期工具拒绝、3 次预期 HTTP 401、2 次协议通知和 10 次登录、权限读取、工具发现及注销等请求。另有五次独立 MySQL 行读回。该轮使用真实协议请求，与此前的 SDK 传输测试互为补充。

V863 覆盖公开独立 Full 的真实普通 Web 身份。C15 的 Agent 身份和平台当前候选仍分别跟踪。角色权限通过独占夹具调整，角色工作台点击链引用 [V840 固定完整管理包](fixed-management-native-v840.md) 的独立证据。
