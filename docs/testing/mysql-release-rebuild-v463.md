## CI 生成产物校验

原校验只运行 git diff。独立 Git 夹具增加一个未跟踪的生成文件后，旧命令仍返回 0。新校验先比较生成目录和前端与 HEAD 的差异，再枚举同一范围的未跟踪文件，保留仓库忽略规则。

直接运行工作流中的实际校验段，七种场景与预期一致。它拒绝新增后端文件、新增前端文件、已暂存新增文件、已跟踪文件漂移和删除，允许完全一致的目录与仅含忽略依赖缓存的目录。
